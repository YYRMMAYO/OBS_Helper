## 5. 已知边界

- 计时器为**清洁室独立实现**：不复制 `MeTimer.cs` 源码；原项目咩License 1.1 仅通过署名 / 许可证副本保留信息，不改变本项目 MIT。
- 浏览器叠加层只绑回环，不提供局域网访问。
- 手机远程需要先配对；重置需要确认。
- 捕获排除仅 Windows 10 2004+ 显示器采集；Win7 用窗口采集或第二屏。
- 未做 Authenticode 签名，SmartScreen 可能提示未知发布者。
- 音频电平表依赖 OBS 推送；旧版 OBS / 未连接时不显示。
