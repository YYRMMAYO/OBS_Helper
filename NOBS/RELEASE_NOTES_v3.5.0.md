# V3.5.0 发布说明

## 一句话摘要

V3.5.0 把界面真正变成「整窗背景 + 半透明面板」的 3.5 形态，同时补齐手机连接页、功能中心与虚拟主播模板的可用性；插件、手机摄像头、小窗与提词器也都做了用户可感知的修复。

## 新增功能

- **全局背景 UI 重构**：壁纸层从内容区提升到窗口根层，覆盖左侧导航、顶栏与页面；图片模式下卡片 / 导航 / 顶栏使用半透明表面，默认 / 纯色 / 高对比模式保持不透明。重构前的界面已保存为 tag `ui-baseline-v3.4.2`。
- **毛玻璃导航与顶栏**：当前壁纸在内存中缩小并高斯模糊，导航 / 顶栏叠加主题色薄层；只在换壁纸 / 换主题时生成一次，不增加每秒渲染开销。
- **简约视觉系统**：默认主色从青绿改为靛蓝，卡片阴影降低、按钮圆角收敛、导航按「概览 / 直播 / 工作台 / 帮助与系统」分组，整体间距放松，减少视觉疲劳。
- **可自定义外观**：设置页新增界面圆角、图片模式面板不透明度与字体选择；字体列表包含系统默认、微软雅黑、思源黑体、HarmonyOS Sans、MiSans、阿里巴巴普惠体、得意黑、霞鹜文楷等免费商用字体（需系统已安装）。
- **启动动画**：启动时显示深色品牌面板 + 进度线，主窗口出现后淡出；自检模式不显示。
- **手机连接页重排**：新增 Hero 区（一句话说明 + 服务状态 + 生成配对码 / 停止服务）、四等宽分段导航、配对卡与设备卡的统一间距；窄窗口下不再挤出屏幕。
- **功能中心体验优化**：新增「现在能做什么」状态条（OBS / 手机服务 / 媒体服务 / 提词器），先告诉用户当前可用状态，再展示模块；每个模块仍可一键打开对应页面。
- **插件广场**：GitHub 加速器引导 + 「我已开启，重新检测」；已安装列表合并「本应用管理」与「本机检测」，用户自己放进 OBS 的插件也会出现。
- **手机摄像头**：mediamtx 固定 v1.21.3 + SHA-256，一键安装；未连接 OBS 也能先启动媒体服务，连接后自动补建来源。
- **虚拟主播模板**：扩到 10 套（新增歌回、学习陪伴、双人联动、手部机位），修正杂谈模板人物与聊天框重叠。
- **小窗控制重构**：新增保存回放、场景切换、麦克风 / 桌面音频静音、提词器、工作室模式与主窗口入口。
- **手机远程改提词稿**：手机「提词」页新增编辑框与「保存到电脑」，旧稿自动备份最近 5 份。
- **指引文档重写**：新增「5 分钟上手」，补充插件加速、手机摄像头、虚拟主播模板与手机改稿；中英同步。
- **图标语义修正**：按 Tabler Icons（MIT）风格补齐 / 替换导航与功能模块图标，修掉「功能中心 = 模板」「工具箱 = 加号」这类图文不符。

## 修复的问题

- 以前「已安装」只读本应用清单，用户用 OBS 自己装的插件完全不可见，页面还显示「还没有插件」；现在两个来源合并展示，并标注来源。
- 以前手机摄像头在未安装 mediamtx 时按钮不可用，且未连接 OBS 会直接启动失败；现在可一键安装，启动与 OBS 连接解耦。
- 以前虚拟主播「杂谈」模板人物区域与聊天框重叠约 400px；现在左右分区，落地即可用。
- 以前小窗只有录制 / 推流 / 虚拟摄像头三个按钮；现在全屏游戏时也能切场景、静音、存回放。
- 以前手机只能播放 / 暂停提词器，改一句话也要回电脑；现在手机可直接改稿并同步。
- 以前背景图片只覆盖内容区，导航与顶栏是实色；现在整窗覆盖，视觉不再割裂。

## 兼容性与升级

- 安装目录、程序集名、数据目录（`%LocalAppData%\OBS_Helper`）均未改变，可覆盖升级。
- 设置、场景模板、提词稿、手机配对记录、壁纸库保留。
- 增量包：V3.5.0 与 V3.4.2 的版本号连续，可生成增量包；实际是否生成以 CI 的基准资产为准。
- 系统要求：Windows 10 / 11；Win7 兼容构建仍可运行，但手机 Wi-Fi 摄像头不支持 Win7。
- 更新通道：V 构建只检测 `V*` 标签；X 系列（`X1031`）只检测 `X*` 标签，两者不会互相提示。
- 新应用图标仅用于 X1031，V3.5.0 继续使用原图标（按需求「图标暂不同步 V 系列」）。

## 已知边界

- 手机摄像头仍需用户在手机上安装支持 SRT / RTMP 的推流 App；浏览器在局域网 HTTP 下不能直接调用摄像头。
- 虚拟主播模板的 OBS 落地以 JSON 校验与坐标断言为准，未逐套做真机截图验收。
- 插件加速器是第三方工具，本应用不捆绑、不自动安装。
- 毛玻璃用「壁纸缩小 + 高斯模糊」实现，不是 Windows Acrylic / Mica 系统材质；效果与性能在普通集显上更可控。
- 字体选择只引用系统已安装字体，不随包分发字体文件；推荐字体需用户自行安装并遵守其许可证。

## 下载与校验

- 安装包：`OBS_Helper_Setup_3.5.0.exe`
- 便携包：`OBS_Helper_Portable_3.5.0.zip`
- Win7 兼容包：`OBS_Helper_Setup_3.5.0_win7.exe`
- 增量包：`OBS_Helper_Update_3.5.0.zip`（基准资产可得时）
- 资产 SHA-256 由 CI 在 Release 正文末尾自动追加，也可用 `SHA256SUMS.txt` 校验。
