## 一、总体结论

本版以 **impeccable 设计技能**（pbakaus/impeccable，含 Anthropic frontend-design / Emil Kowalski / Vercel web-design-guidelines 参考）为基准，对 WPF 界面做了一次 **Operate 模式**下的克制优化：不推翻既有主题体系（浅/深/跟随系统、高对比、字号档、减少动画），而是补齐深度、状态与图标规范，并新增用户可自定义的背景。全部通过构建、单元测试与应用自测，无遗留问题：

1. **卡片深度**：所有卡片/卡片按钮/Toast/下拉面板获得「带偏移 + 柔和模糊」的真实投影（DropShadowEffect），深浅主题分别取 0.10/0.35 与 0.16/0.50 不透明度，替代此前「扁平 1px 边框 + 未启用的 ShadowOpacity 资源」。
2. **按钮真实状态**：主/次/幽灵/危险按钮的悬停与按下从「统一透明度过场（0.88/0.72）」改为真实色阶（BrandHover/BrandPressed、DangerHover/DangerPressed、Surface2/3），键盘焦点环保留。
3. **矢量导航图标**：侧边栏 10 个导航项补齐统一描边（1.8px、24×24）的矢量图标（房子/放大镜/气泡/脉冲/加号/层叠/显示器/仪表盘/书本/滑杆），选中态图标与文字同步变品牌色。
4. **分类卡片去「左彩条」**：首页分类卡删除 craft-floor 明令禁止的 4px 彩色左边条，改为「语义色圆角图标芯片 + 彩色数量文字」双重编码。
5. **字形图标 → 矢量**：返回箭头、下拉箭头、状态药丸（●✓▲✕ℹ）、模板页状态图标（emoji）全部替换为统一风格矢量 Path。
6. **自定义背景（新功能）**：设置 → 外观新增「自定义背景」：默认 / 纯色（6 组预设色板）/ 图片（本地文件 + 压暗遮罩保证可读），仅存本机、不上传；高对比模式强制回退默认底。

## 三、设计依据（impeccable craft-floor / Operate）

- 深度 = offset + blur（拒绝零偏移色晕）；间距「小组紧密、大组宽松」；文字对比 ≥4.5:1（沿用既有 Muted/Danger 修复）。
- Operate 模式：150–250ms 状态动效（沿用 160ms MotionDuration）、一致组件词汇、强调色只用于主操作/选中/状态。
- 禁用清单逐项对照：卡片左侧彩色描边（已删）、emoji 充当图标系统（导航/状态图标已矢量）、纯透明度悬停（已改真实色阶）。

## 四、遗留说明

- 分类卡片图标仍来自 problems.json 数据里的 emoji（知识库内容图标，属内容而非界面 chrome），未强行矢量化；后续若统一品牌图标集可再迭代。
- qwen-vision 视觉验证插件存在 GBK 编码缺陷（模型输出含 emoji 时崩溃），已在其全局配置注入 `PYTHONIOENCODING=utf-8`（重启后生效）；本版视觉结论来自修复前的成功采样 + 运行时像素采样。
- 自定义背景图片未做内置裁剪/缩放设置，统一 UniformToFill + 遮罩；复杂需求留待后续。
