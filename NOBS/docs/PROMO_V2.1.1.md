# OBS 排障助手 V2.1.1 宣传文案

> **一句话**：面向直播新手的 OBS 排障工具，现在更新更快、知识库更全、安装包不再残留。

---

## 版本定位

**OBS 排障助手（OBS Helper）V2.1.1** —— Windows 原生 WPF 版。
纯离线可用、隐私优先、零第三方依赖；本次更新聚焦**「更新体验」**与**「知识库」**两个方向。

## 这一版有什么新东西

### 1. 增量更新：以后更新不用再整包下载 🚀

以前每次更新都要重新下载 50MB+ 的完整安装包；现在——

- **应用内「增量更新」**：只下载自上一版本以来的**变更文件**（实测 2.0.0 → 2.1.1 增量包仅 **1.27MB**，不到整包的 3%）
- 下载后**逐文件 SHA-256 校验**，任一步失败自动回退完整安装包，绝不把应用改坏
- 安装版自动申请一次管理员授权完成替换并自动重启；便携版直接应用
- **2.0.0 / 2.1.0 用户都可直接增量升级**到 2.1.1

### 2. 知识库分离更新：问题库可以独立更新 🧠

- 问题库不再锁死在程序里——**应用之外也能随时更新**，不用等发版
- 启动时静默自动更新（6 小时节流，不打扰）、设置页「检查知识库更新」、更新弹窗「仅更新知识库」三入口
- 远程双通道：GitHub raw 主通道 + Release 资产兜底

### 3. 知识库扩充到 110 条：更懂你遇到的每个问题 📚

v1.4 → v1.5，**95 → 110 条**（10 大分类），2026 年 8 月网络调研增补 15 条高频问题：

| 新增主题 | 覆盖内容 |
| --- | --- |
| 随机音画不同步 | 直播几小时后音频/视频突然错位、音频缓冲上限 |
| 麦克风声音处理链 | 降噪 → 门限 → 压缩 → 限制 的正确顺序与参数 |
| 串流密钥安全 | 密钥泄露处置、OAuth 连接账号、打码截图 |
| 虚拟摄像头排障 | 会议软件找不到/黑屏/不刷新设备列表 |
| 捕获源互相干扰 | 同一场景多个捕获源黑屏闪烁 |
| 关键帧间隔 | Keyint 2 秒设置与平台转码花屏 |
| 动态码率 | 网络波动时保流畅 |

### 4. 安装包自动清理：下载目录不再堆旧安装包 🧹

- 启动后自动扫描临时目录 / 下载 / 桌面，删除**旧的**安装包与增量包（每类保留最新一份）
- 只识别 `OBS_Helper_*` 命名产物，**绝不触碰你的其它文件**

### 5. 可靠性加固（V2.1.0 → V2.1.1）

两轮交叉检验（重点覆盖更新链路）后修复 6 处细节：

- 外部知识库损坏时不再误报「加载失败」，内置种子静默兜底
- 增量包临时文件不会被安装包清理误删
- 解压防 zip-slip、自举进程校验暂存目录防篡改
- 发布产物净化（无 BOM JSON、排除运行时文件）
- 新增 `-DeltaBaseVersion` 支持跳版本增量发布
