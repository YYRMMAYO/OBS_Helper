## Windows 桌面 exe 打包（用户追加需求：打包 exe）
- 新增工程 `F:\OBS\OBS_Helper.Win`（.NET 10 WinForms + WebView2 桌面壳）。
- 做法：将 `publish/wwwroot`（Blazor 静态站）整体复制到 `OBS_Helper.Win/wwwroot`，用 WebView2 的 `SetVirtualHostNameToFolderMapping("app.obshelper.local", wwwroot, Allow)` 映射到 https 虚拟主机，避免 file:// 的 CORS；`MainForm.cs` 的 `Load` 事件中 `EnsureCoreWebView2Async()` 后 `Navigate("https://app.obshelper.local/index.html")`。
- 坑：WebView2 控件在命名空间 `Microsoft.Web.WebView2.WinForms`（初版误引 Core 导致 CS0246）；包用 net10 时 WinForms 引用仍正常（WPF WindowsBase 警告无害）。
- 图标：纯 Python 把 obs-icon-512.png 包装成 appicon.ico（PNG 负载，无第三方库），csproj 设 ApplicationIcon/ApplicationHighDpiMode。
- 发布：`dotnet publish -c Release -r win-x64 --self-contained true -o OBS_Helper.Win/dist`（自包含，含 .NET 运行时，dist 约 169MB；exe 仅 160K 宿主）。
- 安装包：Inno Setup 6 脚本 `OBS_Helper_Setup.iss` → `installer/OBS_Helper_Setup_1.0.0.exe`（53MB，含开始菜单/桌面快捷方式，默认装到 Program Files，需管理员）。
- 便携版：`OBS_Helper_Portable_1.0.0.zip`（dist 压缩）。
- 注意：运行需目标机有 Edge WebView2 Runtime（Win10/11 通常自带）；无则启动报错并提示安装。
- 关键修复：MainForm.cs 增加 `using Microsoft.Web.WebView2.WinForms;`

## 本轮（续）：修复启动报错/白屏 + macOS 改造 + 问题收录 + 打包
- **启动报错/白屏根因**：WebView2 默认 user-data 目录在 exe 同级，安装到 `C:\Program Files` 时标准用户无写权限 → `EnsureCoreWebView2Async` 抛异常 → 弹错+白屏。修复：user-data 改到 `LocalApplicationData\OBS_Helper\WebView2`（必写）；渲染进程崩溃自动 Reload；失败给出明确提示。同时 `App.razor` 包 `<ErrorBoundary>` 防组件级白屏。
- **macOS 改造（需求2）**：`MainLayout.razor` 副标题 → `macOS · Windows 通用`；`Diagnostic.razor` 第③节改为「关于 macOS 端」并补充屏幕录制/麦克风/相机/辅助功能权限与 Apple 硬件编码器建议。
