**OBS帮助助手**（V2.9.6 前的名字是「OBS 排障助手」，同一个软件、同一条升级链路）是面向直播新手的 OBS Studio 排障与录制助手：**纯离线可用**——208 条问题的知识库、排障指引、日志分析规则全部内嵌在程序里，不联网也能查；连上本机 OBS 之后还能做一键体检、远程控制场景 / 录制 / 推流、部署录制环境。**V2.9.4 起**，从「配好 OBS」到「开始录制」被收进首页一张卡；**V3.1.0 起** OBS 没开也能一键拉起并开录；**V3.1.1** 补齐了提词器的手动上下移动与窗口位置微调；**V3.3.0** 新增「虚拟直播」工作台（Live2D 形象 · 6 套直播间模板 · 16 个平台开播引导）、插件广场一键安装 / 回滚 / GitHub 搜索导入，以及无障碍模式与老年模式；**V3.4.0** 把手机接进直播工作流：扫码遥控 / 监看 / 提词 / 补光 / 快传、手机当 Wi-Fi 摄像头与麦克风，并交付弹幕聚合、本地实时字幕、复盘/切片、多平台转推、MIDI/灯光与团队协作。

这是原 Blazor WebAssembly + WebView2 版本的**原生 WPF 重构**（源码在 [`NOBS/`](NOBS/)），功能一比一对齐，但去掉了浏览器内核这一层：冷启动直接起窗口、自包含单目录发布、无需安装 WebView2 与 .NET 运行时。**V2.9.2 起支持中文 / English 即时切换**，**V2.9.3 起连随包离线内容也是中英双份**（知识库 208 条 / 插件目录 57 条 / 场景模板 12 套 / 排障指引全部英译，切语言即时生效）；**V2.2 起内置插件广场**（57 个精选插件 + 本机只读体检，v1.4 目录已全量复核）；**V2.1 起支持增量更新与知识库独立更新**。

> **兼容性**：主构建面向 **Windows 10 / 11**（.NET 10）；另有一套 **Windows 7 SP1 兼容构建**（.NET 6，最后一个支持 Win7 的 .NET 版本），安装包与便携包都在 Release 里，按系统选一个即可。

## 5 分钟上手

1. **装上**——从 [Releases](https://github.com/YYRMMAYO/OBS_Helper/releases) 下载安装包或便携版。便携版解压即用、自带 .NET 运行时；安装向导第一步会让你选语言（简体中文 / English，默认中文）。Windows 7 SP1 用户选文件名带 `_win7` 的那一套。
2. **连上 OBS**——在「控制台」页的连接卡里填 OBS 的 WebSocket 端口与密码（主构建默认 4455 / obs-websocket 5.x；Win7 兼容构建默认 4444 / 4.x 旧协议）。打开 OBS 的「工具 → WebSocket 服务器设置」即可看到端口和密码；密码只保存在本机、**双层加密**。连上后顶栏徽章变绿，控制台、体检、录制等页面才会真正「活」起来。
3. **录一段**——首页的「简单录像」卡里选一档预设（快速录像 / 会议 / 网课 / 游戏高码率），点一次就完成：录前自检 → 备份当前配置 → 落地录制项 →（OBS 没开就拉起并等就绪）→ 开始录制。录制中能看到已录时长与剩余可录；停止后会提示文件大小，可一键打开目录或转成 MP4。
4. **出问题先查**——点首页的「搜索问题」，或在「搜索」页边打边搜；也可以用「问我一下」用大白话描述现象，或在「诊断」页对连上的 OBS 做一键体检，或直接分析 OBS 日志（离线、先脱敏）。体检与日志结论都能导出 Markdown 报告，反馈问题时可一键复制报错材料。
5. **直播中随手控**——「控制台」切场景、显隐元素、静音、开始 / 停止录制与推流；把窗口关到托盘、呼出迷你小窗，或用全局热键 `Ctrl+Alt+R/S/C/V/K/M/O` 随时操作。开了「提词器」就用 `Ctrl+Alt+T` 呼出、`Ctrl+Alt+P` 播放 / 暂停。
6. **把手机变成外设**——打开「手机联动」页扫码配对，手机即可遥控 / 监看 / 提词 / 补光 / 快传；同一局域网内使用，所有能力默认关闭、可随时撤销。

> 除「免费 AI / 云端诊断引擎」外，其余功能（知识库、日志分析、体检、插件目录、模板、提词器、壁纸）**全部离线可用**；联网只发生在你主动发起 AI 诊断时，且请求前会先对日志脱敏。

## 功能详解

### 学习与排查

- **新手教程**——首次启动的四步分步引导（连上 OBS → 出问题先查这里 → 一键体检 → 开播与装修），讲到的入口都是真实导航名；V2.9.1 起升级为「跳转式引导」：每一步自动把界面切到对应页面，卡片贴右下角、遮罩只压到约 17% 黑，页面看得见。`设置 → 新手引导` 可随时重看，无需重启。
- **知识库**——208 条问题（知识库 v2.3，14 个分类），按分类组织；每条包含**现象、可能成因、分步解决、小贴士、相关问题**，步骤可勾选且进度自动记住。内置中英两份内容，切语言即时跟随。
- **搜索**——边打边搜，跨标题、现象、成因匹配。
- **问我一下**——用大白话描述现象（例如「录出来的视频一卡一卡的」），自动匹配最可能的问题条目。
- **排障指引**——通用排查思路速查手册，从「先看什么」到「按什么顺序排除」。
- **知识库独立更新**——问题库 / 插件目录与应用版本解耦：启动时静默自动更新（6 小时节流）、设置页「检查知识库更新」、更新弹窗「仅更新知识库」三个入口；GitHub raw 主通道 + Release 资产兜底，中英各一条通道。

### 智能诊断与日志分析

- **一键体检与录前自检**——连上 OBS 后在「诊断」页一键体检：先跑**录前自检（只读）**核对录制格式是否防崩溃的 MKV、录制路径与磁盘空间、编码器、音频采样率与麦克风设置，再按「快速自检清单」逐项排查；结果给出「通过 / 警告 / 失败」与可执行建议，并可**导出 Markdown 报告**。
- **三种诊断引擎**（详见下方 [智能诊断引擎](#智能诊断引擎)）：本地规则引擎（默认，纯离线）、内置免费 AI（智谱 / Pollinations 两条通道，免注册）、你自己的云端大模型（OpenAI 兼容接口 + function calling）。
- **日志分析**——离线解析 OBS 日志：**34 条规则 + 5 条派生判定 + 3 项量化比值（共 42 条线索）**，已按 OBS 32.2.2 的真实日志核对；日志在分析前**先脱敏**。除逐条规则外，还能做三类分诊：**掉帧主因三分类**、**编码过载按当前设置分诊**、**双显卡错位检测**。
- **日志 × 插件联动**——分析提取加载失败 / 崩溃肇事模块，能对上插件广场条目时一键跳转；AI 类插件标注公开开销，并结合系统监控给性能预算提示。
- **体检工具箱（8 张专项卡）**——色彩、采样率、黑屏专项、音频深度、虚拟摄像头、磁盘写入、编码顾问、节点探测；适合在「看起来都对，但就是不对」时逐项排查。

### 录制、推流与提词器

- **简单录像（首页一键开录）**——三档预设只回答「录什么」：**快速录像**（1080p / 60fps，通用推荐）、**会议 / 网课**（1080p / 30fps，文件小、CPU 友好）、**游戏高码率**（1080p / 60fps + 自动分段，长录制不产生单个巨型文件）。点一次走完：录前自检 → 整份备份 → 落地 →（OBS 没开就拉起并等 obs-websocket 就绪）→ 开始录制。录制中显示**已录时长**（暂停不计入）与**剩余可录**（按码率 × 1.5 冗余估算，低于 10 分钟提示低空间）；停止后读回文件大小，装了 ffmpeg 可一键无损转封装 MP4，没有时给出 OBS 自带「重新封装录像」的路径。
- **一键部署录制环境**——按「录制向」逐项列出推荐值与当前值：录像格式 → Hybrid MP4、录像质量 → HQ、录像目录、画布与输出 → 1920×1080、帧率 → 60、音频采样率 → 48kHz。**全部先自动备份、可一键回滚、每项可单独取消**；连上 OBS 走 obs-websocket（即时生效），OBS 已退出则改当前配置集的 `basic.ini`（写盘前备份、**写盘后重新读回逐项校验**）。明确不碰推流参数、输出模式、编码器族与码率——那些属于用户自己的选择。
- **一键启动 OBS + 默认 WebSocket**——OBS 没开时，首次给出一次说明并记住选择（继续并记住 / 每次都问 / 我自己开），之后一键直达；OBS 在跑但没连时主动连接（单飞、可超时、可取消、OBS 退出立即返回）；连接成功后自动落地设置并开录。失败按「找不到 OBS / 启动失败 / 端口未开 / 握手失败 / 需要密码 / 密码错误 / 超时 / 取消 / OBS 退出」分类，每类都给至少一个可执行出口；录制前可选 **0 / 3 / 5 / 10 秒**倒计时（0 = 关闭，默认关闭）。
- **提词器**——独立置顶窗口：无边框、可拖动缩放、自动滚动，速度 / 字号 / 行高 / 透明度 / 左右边距可调；支持水平 / 垂直镜像、点击穿透（全局热键 `Ctrl+Alt+L` 关闭）、3-2-1 倒计时、阅读参考线；脚本可编辑 / 粘贴 / 导入 `.txt` `.md` 并自动保存草稿，**纯本地、不联网**。热键：`Ctrl+Alt+T` 呼出 / 隐藏、`Ctrl+Alt+P` 播放 / 暂停。脚本里用 `## 场景名` 分段即可做**场景联动**：切场景时只滚动提词器、不自动切 OBS 场景。捕获排除：窗口采集 / 游戏采集天然不包含提词器；显示器采集在 Windows 10 2004+ 尝试 `WDA_EXCLUDEFROMCAPTURE`，不支持时明确给出窗口采集 / 第二屏的替代方案（**不承诺「绝对不会被录到」**）。
- **提词器手动上下移动（V3.1.1）**——四条互不依赖的路径：工具栏 `⤒`（回到开头）/ `▲`（上移一行）/ `▼`（下移一行）；在正文按住鼠标上下拖动（拖动期间自动滚动暂停）；鼠标滚轮一格约 72 px；键盘 `↑` / `↓` 一行、`PgUp` / `PgDn` 一屏、`Home` / `End` 首尾、空格暂停 / 继续。点一下正文即可激活窗口；`Ctrl + ↑ / ↓ / ← / →` 以 10 px 步长移动窗口并始终夹在虚拟屏幕内；位置 / 尺寸在拖动或移动后 600 ms 自动保存。滚动终点按「最后一行正好停在阅读参考线」计算，不再滚进底部 220 px 留白。
- **录像文件命名模板**——`{date}` `{time}` `{datetime}` `{scene}` `{profile}` `{resolution}` `{fps}` `{ext}` 等变量；非法字符净化、同名冲突自动加序号，改名失败保留原文件。
- **录制守护与静音提醒**——后台录制守护 + 实时日志尾随预警；录制 / 推流中静音超过 8 秒或音量低于 -55 dB 超过 10 秒时托盘提醒（**只提醒，不自动改音频状态**）。
- **回放缓存与录制打点**——`Ctrl+Alt+V` 一键保存回放缓存；`Ctrl+Alt+K` 在录制中打点（OBS 官方暂不提供的能力），停止后可用于定位章节。
- **直播控制**——控制台里开始 / 停止推流、查看实时码率 / 帧率 / 丢帧统计，可设**定时停止**；「搭建」页提供 6 步开播流程（准备与权限 → 场景与来源 → 音频校对 → 推流设置 → 开播自检 → 多平台 / 竖屏）与 B站 / 抖音 / 快手 / 视频号 / 小红书 / YouTube / Twitch 等主流平台的接入指南。

## 智能诊断引擎

连上 OBS 后一键体检，三种引擎可选：

| 引擎 | 原理 | 成本 |
| --- | --- | --- |
| **本地规则引擎**（默认） | 确定性离线规则匹配，与日志分析同源 | 免费、纯离线 |
| **免费 AI（内置）** | 两条通道——**智谱免费模型**（国内直连最稳，密钥构建时加密内嵌）与 **Pollinations**（国外免 Key 公共通道）。本地限频：智谱 **10 次/天**、Pollinations **20 次/天**，独立计数、互不挤占，每天 0 点恢复 | 免费、免注册 |
| **云端大模型** | OpenAI 兼容接口 + function calling，接入你自己的 API Key（双层加密保存在本机） | 你的 API 费用 |

云端 / 免费失败时**自动回退本地引擎**，并在结果中说明原因。免费档为单轮普通对话（不做知识库工具调用）；需要多轮深度排查或更高频使用，请接入你自己的云端 API。

## 版本通道：V 系列与 X 系列

| 通道 | 版本号样式 | 定位 | 更新来源 |
| --- | --- | --- | --- |
| **V 系列**（`master`） | `V3.5.2` | **稳定优先**：功能收敛、经过完整回归与发布验证，适合日常直播 / 录制 | 正式 Release 页 · 蓝奏云 · 应用内增量更新 |
| **X 系列**（`master`） | `X1031` / `X1031Y2` | **独立大版本**：`X` + `MMdd` 日期码，含 X 专属图标；更新检查只看 `X` 标签 | X 系列 Release 页 · 应用内更新 |

- **两个系列共用功能与数据目录**：安装目录、程序集名、`%LocalAppData%\OBS_Helper` 都不变，升级链路一致。
- **通道过滤在解析层完成**：V 构建只认 `V3.5.2` 这类 V tag，X 构建只认 `X1031` 这类 X tag；两类 tag 挂在同一个仓库里，也不会互相被当成新版本。
- **X 版本号规则**：`X` 后面的四位是日期 `MMdd`（`X1031` = 10 月 31 日）。同一天再次发版时追加 `Y1`、`Y2`、`Y3`…；更新检测先比日期，日期相同再比 Y 序号，所以 `X1031Y2 > X1031`、`X1101 > X1031Y99`。
- **X 更新提示**：检测到新版本后，更新弹窗会直接从 GitHub Release 拉取本版更新说明并展示；拉取失败时不影响检查与下载。
- **X1031 范围小于 V3.5.0**：X1031 含需求 1–9 与新图标，但不含全局背景 UI 重构、手机连接页重排与功能中心体验优化；V3.5.0 含这些 UI 内容，但按需求继续使用原应用图标。

- **批量状态查询协议修正**：改用 `RequestBatch`（op 8 / 9）与数字执行方式；连接后的录制 / 推流 / 虚拟摄像头状态、音频静音与音量恢复实时刷新（此前批量请求被 OBS 回 204 或 4004，全部静默失败）。
- **迷你小窗**：「还可录约 X 分钟」改为整数显示，不再出现一长串小数。

## 隐私与安全

所有数据只存在本机：

- **偏好**（外观、语言、收藏、步骤进度、连接设置、热键键位、自动切换规则、托盘行为、壁纸库）→ `%LocalAppData%\OBS_Helper\prefs.json`——明文 JSON，**均不含任何凭据**；
- **OBS 密码与 AI API Key** → `%LocalAppData%\OBS_Helper\secrets.dat`——**双层加密**：值先经 AES-256-GCM（密钥由本机 `MachineGuid` 经 PBKDF2-SHA256 派生）加密，整个文件再经 DPAPI（绑定当前 Windows 用户 + 应用熵）加密；换机 / 换用户无法解开，即使文件被离线窃取也无法还原。

**数据安全（V3.0 起）**：写入设置、知识库、模板、录制归档等用户文件统一走事务通道——写前快照、原子替换、校验读回，失败自动回滚；任何写入先解析绝对路径并确认落在目标目录内（路径越界护栏）；机密独立加密存储，不与普通配置混放。

**发现了安全漏洞？** 请勿在公开 Issue 里披露细节 —— 走仓库 **Security → Report a vulnerability** 私密通道，或发邮件到 **752139192@qq.com**（标题加 `[SECURITY]`）。完整策略见 [SECURITY.md](SECURITY.md)（中英双语）。中文或英文都可以。

只有在你**主动开启**「免费 AI」或「云端诊断引擎」并发起诊断时才会联网，且请求前会先对日志脱敏。OBS 配置备份 / 导出默认不含推流密钥（可勾选包含），密码与 Token 自动脱敏。


```
  OBS_Helper.Wpf/OBS_Helper_Setup.iss  Inno Setup 脚本（按 TFM 传 MinVersion / 输出名，UTF-8 带 BOM）
```

换肤与换语言走的是同一条路：**把当前主题的调色板 / 当前语言的文案整体写进 `Application.Resources`**，
XAML 一律用 `DynamicResource`（主题键直接用、文案键写作 `Loc.<键>`）引用，
所以两者都是整窗即时生效的，不需要重建窗口或重启。
代码里拼出来的文案由 `LocalizationService` 广播事件、主窗口把当前页面原地重放一次刷新。

## 质量基线与已知边界

- **1670 项单元测试全部通过**（V3.4.0：连续 3 轮全量 + 双目标构建 + Headless 自检 + 静态检查）；测试工程直接链接纯逻辑源文件，不引用整个 WPF 工程；
- **Headless 自检 36 项全部 PASS**（覆盖 28 条路由用例 + 8 项非路由检查：新手引导覆盖层（含逐步跳转校验）、迷你小窗、文案资源解析、语言切换往返、逐页语言重放、内容回退提示条、D7 连接态护栏、双构建协议分支），**主构建与 Win7 兼容构建各跑一次**；
- CI 接入 XAML 资源引用、中英文案键对等、无障碍静态检查、Headless 自检与增量包端到端升级（全文件 SHA-256 比对）等门禁；[`NOBS/docs/reviews/`](NOBS/docs/reviews/) 下保留分视角审校记录，并如实标注哪些结论有机器证据、哪些只是人工核对；
- **已知边界**：① Windows 7 真机未验证（只做到目标框架可编译 + 安装包 MinVersion 正确下发），旧协议（obs-websocket 4.x）也未对真实 OBS 27 验证；② 英译未经母语者校订、未逐条核对英文版 OBS 菜单路径；③ 一键部署的两条通道按协议 / 键名实现并有单测，但未对真实 OBS 跑过端到端落地；④ 无障碍只做到代码级适配 + 静态检查，未经 NVDA / Narrator 实测（详见 [`ACCESSIBILITY.md`](ACCESSIBILITY.md)）；⑤ 发布产物未做代码签名，SmartScreen 可能提示未知发布者；⑥ .NET 6 已停止安全更新，兼容构建是「必须跑 Win7」时的退路，新机器请用主构建。
