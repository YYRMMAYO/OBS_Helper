# 指引文档、功能中心与手机连接页

## 1. 内置指引（troubleshooting.md）

### 1.1 现状

- 落款「1.6.0」，比当前版本落后 8 个版本以上；
- 没有手机联动、插件广场、虚拟主播、手机摄像头、提词器；
- 新用户打开后不知道「第一步做什么」。

### 1.2 新结构

```text
0. 5 分钟上手（新）
   1) 连接 OBS → 2) 生成配对码 → 3) 选一个场景模板 → 4) 试录 10 秒
1. 快速自检
2. 黑屏 / 无信号
3. 编码过载 / 卡顿
4. 音画不同步
5. 推流失败
6. 插件广场与 GitHub 加速（新）
7. 手机联动与手机摄像头（新）
8. 虚拟主播模板与 Live2D（新）
9. 提词器（含手机改稿）（新）
10. 安全与隐私
11. 仍无法解决
```

- 中英同步：`troubleshooting.md` / `troubleshooting.en-US.md`。
- 版本落款改为 `V3.5.0`，并说明 X 系列仅影响更新通道，不影响使用方法。

### 1.3 验收

- 目录结构可被 `MarkdownView` 正确渲染；
- 所有链接为 https；
- `check_docs.py` 不因版本号 / 锚点失败。

## 2. 功能中心（FeatureHubPage）

### 2.1 体验问题

- 卡片只说明「有什么」，不说明「现在能不能用」；
- 用户点「手机摄像」后跳到手机页，仍要自己找 Tab；
- 自动回填、手机连接等入口分散。

### 2.2 优化

1. 顶部新增「现在能做什么」状态区（4 个状态 chip）：
   - OBS：已连接 / 未连接；
   - 手机服务：运行中 / 未启动；
   - 媒体服务：已安装 / 未安装；
   - 提词器：有稿 / 无稿。
2. 每个模块卡片增加「适用场景」一行（不是版本号）。
3. 手机模块的快捷按钮直接带 Tab 参数（已支持）；补充「先看三步引导」。
4. 空状态 / 失败状态给下一步按钮，而不是只显示文字。

## 3. 手机连接页（MobileLinkPage）

### 3.1 视觉重构

- 顶部 Hero：标题 + 一句话说明 + 服务状态徽标 + 「生成配对码」主按钮；
- 分段导航改为胶囊式 `SegmentButton`，四个 Tab 等宽；
- 配对卡：二维码左侧、说明与配对码右侧；二维码容器圆角 + 白底；
- 设备列表：每台设备一张紧凑卡片（名称 / 角色 / 最后在线 / 撤销）；
- 摄像头：四步引导 + 安装按钮 + 状态色；
- 多机位 / 设备快传：与卡片网格统一间距。

### 3.2 可用性

- 未启动服务时，Hero 显示「服务未启动」并解释「生成配对码会自动启动」；
- 每个失败状态都有可点击的修复动作；
- 键盘可访问：Tab 顺序 = 状态 → 主操作 → 次操作；
- 窄窗口（< 900px）下二维码与说明纵向排列。

## 4. 验收

- 1280×800 与 1024×700 下无横向滚动；
- 所有按钮有可访问名称；
- 切语言后页面文案即时刷新；
- `check_accessibility.py` / `check_resources.py` 通过。
