## 一、整体结论

本版为「免费 AI 通道」新功能发布，经三遍交替审查（构建自检 → 代码审查），无遗留问题。

- **功能**：新增「免费 AI（内置）」引擎——无需注册、无需 API Key，通过内置的免费 OpenAI 兼容端点发起诊断；**本地端强制限频**（每台机器每天最多 20 次 + 两次请求间隔至少 10 秒，计数持久化，跨天清零）；额度用尽或免费服务不可用时自动回退本地引擎并标注原因。
- **安全加固**：API Key 存储升级为**双层加密**（AES-256-GCM 机器绑定密钥 + DPAPI），旧数据自动迁移、fail-closed 解密，杜绝明文泄漏与离线窃取还原。
- **兼容**：原有「云端大模型（自带 API Key）」与「本地的搜索助手」两条路径完全保留，未改变既有行为；版本号升至 **V1.7.0**。

## 二、方案选型

需求：为应用内置一个「免费 API」通道，用户无需注册 / 自备 Key，由应用本地强制限频；同时保留用户自备 API 的能力。

调研结论（2026-08 联网核实）：

| 方案 | 是否免 Key | 结论 |
| --- | --- | --- |
| OpenRouter 免费模型（`:free`） | 否（需注册拿 Key） | 可作为「用户自带 API」的推荐平台，但不符合「零配置」诉求 |
| KeylessAI 公共代理 | 是 | **已不可用**：端点超时、GitHub 仓库删除，明确弃用 |
| Pollinations.ai（`https://text.pollinations.ai/openai`） | 是 | **采纳**：OpenAI 兼容、无需鉴权，实测返回标准 `chat.completion`；免费档不支持 function calling（传 tools 返回 402），故免费通道设计为单轮普通对话 |

免费通道为共享公共服务，故在应用内强制单机限频（20 次/天），避免单用户拖垮共享端点，也符合「低频使用」的产品定位。

## 三、实现要点

### 1. 免费引擎（`Services/Ai/FreeDiagnosticEngine.cs`）

- 与云端引擎共用提示词（`CloudDiagnosticEngine.BuildSystemPrompt / BuildUserPrompt` 改为 `internal`）。
- 请求**不携带** `tools`（免费端点不支持 function calling），单轮返回；模型默认 `openai`，可在设置页修改。
- 走 `HostBridge.AiChatNoAuthAsync`，https / SSRF 防护与云端一致，但**不拼装 Authorization 头、不触碰任何密钥**。

### 2. 本地限频（`Services/Ai/FreeRateLimiter.cs`）

- 计数持久化在 `%LocalAppData%\OBS_Helper\prefs.json`（`obshelper.ai.freequota`，非机密），跨重启生效。
- 按本地日期（yyyyMMdd）统计，跨天自动清零恢复；**双重限频**：每日上限 `MaxFreePerDay = 20`，且任意两次请求间隔至少 `MinIntervalSeconds = 10` 秒（突发连打直接拒绝、不扣日额度），两者都在发出请求前强制检查，线程安全。
- `TryConsumeAsync` 返回 `FreeConsumeResult`（Allowed / DailyQuotaExceeded / TooSoon），编排层对每种结果给出对应回退文案。

### 3. 编排与回退（`Services/Ai/DiagnosticOrchestrator.cs`）

- 新增 `Free` 模式分发：额度用尽 / 请求失败 / 格式异常 → 一律回退本地引擎，`FellBackToLocal=true` 且 `Error` 携带原因（UI 已有回退提示逻辑，复用）。

### 4. 无密钥转发（`Services/Host/HostBridge.cs`）

- `AiChatAsync` 重构为「校验 + 取密钥 + `AiChatPostAsync`」；新增 `AiChatNoAuthAsync` 复用同一 `AiChatPostAsync`（可空 Authorization 头）。安全约束（https-only、SSRF、响应体限量、超时）全部保留。

### 5. 机密存储双层加密（`Services/Host/HostBridge.cs`，安全加固）

- 第 1 层：DPAPI（CurrentUser + 应用熵）加密整个 `secrets.dat`（既有设计）。
- 第 2 层（新增）：每条机密值进 DPAPI 前先做 AES-256-GCM，密钥由 PBKDF2-SHA256（100k 迭代）从本机 `MachineGuid` 派生；即使文件被**离线窃取**（只有口令级 DPAPI 可破），也拿不到 MachineGuid 解不开第二层。
- 兼容与迁移：旧版明文值读取时自动识别，下次写入自动升级为 `v2:` 格式；`v2:` 前缀严格校验（段数 / 长度 / Base64），旧值恰好以 `v2:` 开头不会被误删；解密失败 fail-closed（不把密文当密钥用）。
- 派生密钥进程内缓存（MachineGuid 不变，避免每次读取都跑 100k 迭代）。

### 5. UI

- 设置页：新增「免费 AI（内置）」段选钮与面板（模型名可改、本地限额实时展示「已用 X / 20 次」）。
- 诊断页：引擎标签与导出报告引擎名支持 `free`；免费引擎无诊断项时只要有结论即可导出报告。

## 五、遗留说明

- 免费通道是共享公共服务，可用性与延迟由其自身决定；应用侧已做「失败即回退本地」兜底。
- 限频为**本地强制**（每日 20 次 + 10 秒间隔双防线）：防止单机高频使用；若未来有合规需要可升级为服务端配额。
- API Key 已做**双层加密**（AES-256-GCM 机器绑定密钥 + DPAPI），离线窃取文件也无法还原；加密存储不可用 / 密钥不符时按「未配置」处理，用户重填即可。
- 自备 API 的推荐平台（OpenRouter 免费模型、ModelScope、智谱 GLM-4.7-Flash 等）已在「云端大模型」路径中接入，用户自选。
