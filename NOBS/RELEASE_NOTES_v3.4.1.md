# OBS帮助助手 V3.4.1 发布说明

发布日期：2026-10-31 · 基线：V3.4.0（`aaaf619`）

版本主题：**手机页可用性修复与重做**——解决 3.4.0 手机页面“只有空按钮、没有文字”的问题；补齐刷新恢复、跨品牌浏览器兼容与开源依赖的一键下载 / 一键配置。

## 修复

### 手机页空白（严重）
- 根因：手机端词表是 `Dictionary<string, (string Zh, string En)>`，`System.Text.Json` 默认不序列化元组字段，注入页面的 `I18N` 全部变成 `{}`，所有文案为 `undefined`，页面只剩空壳。
- 现在显式投影为 `{ key: [中文, English] }`，并新增单测回读注入的 JSON 与词表逐项比对，防止回归。
- 页面启动时校验词表；一旦注入异常，直接显示可读提示，不再呈现“只有空按钮”的假界面。
- 页头新增版本标识（如 `v3.4.1`），可据此确认手机加载的是新页面还是仍连在旧实例上；电脑端「手机联动」页也显示当前版本。
- 刷新页面后不再出现空壳：会话 token 持久化（`localStorage`，失败时回退 `sessionStorage`），刷新后自动重连；缺少凭据时显示“请重新扫码”，不再是无说明的空白界面。

### 停止录制 / 推流误报失败（OBS 501）
- OBS 在「已经停止 / 正在停止」时可能对 `StopRecord` / `StopStream` 返回 501（状态事件滞后的竞态）。
- 现在停止操作以 OBS 的真实状态为准：本地状态已停止时先核对再决定是否发请求；请求失败后刷新输出状态，确认已停止就按成功处理，不再误报“停止失败”。
- 刷新使用 OBS 的 `GetRecordStatus` / `GetStreamStatus`，不会凭本地缓存猜测。

### 手机端“OBS 未连接”误报
- 旧实现把任意 OBS 请求失败都映射成 `MOB_OBS_OFFLINE`，所以明明连着也会提示“OBS 未连接”。
- 现在区分三类错误：真正的未连接、OBS 拒绝操作（附 OBS 原始错误码/说明）、手机命令执行异常；错误信息不再张冠李戴。
- 提词器属于应用内能力：OBS 掉线/重连期间仍可播放、暂停、调速、翻页，不再被“OBS 在线”前置条件拦截。


- 修复启动/状态翻转时 `ShowBalloonTip` 正文为空导致的 .NET 未处理异常（“气球状提示文本必须有非空的值”）。
- 所有托盘气泡统一走安全封装：正文为空回退标题，并吞掉托盘实现异常，通知失败不再影响主程序。

### 手机端功能
- 推流按钮支持开始 / 停止切换（停止需二次确认），录制、虚拟摄像头、演播室按钮显示真实状态。
- 监看预览可正常显示：CSP 的 `img-src` 放行 `blob:`（原实现被浏览器拦截，预览永远空白）。
- 主题按钮此前未绑定点击事件，已修复为“自动 / 浅色 / 深色”三态循环并记住选择。
- 提词页新增上移 / 下移；只读角色会禁用所有操作控件；音量拖动期间不会被每秒推送打断。
- 连接断开、未配对、OBS 未连接均有明确提示；连接中显示“正在读取 OBS 状态…”，不再出现无说明的空白分区。

### 手机端界面重做
- 简约卡片式布局，单一强调色，正文 17px / 行高 1.5，分节标题与状态数字清晰可读。
- 深色主题不再使用纯黑（底色 `#1a1e24`），支持跟随系统；浅色 / 深色切换即时生效。
- 360px 起竖屏完整显示五个页签，390px、平板宽度自适应；触控目标 44–52px；适配刘海屏安全区。
- 兼容性兜底：补齐旧内核缺失的 `closest` / `NodeList.forEach`；旧浏览器或脚本加载失败时显示可读提示，而不是空白页；仅剩不支持 `fetch` / `Promise` / `WebSocket` 的老旧内核会看到明确的升级提示。

## 新增

### 开源依赖中心（插件页）
- 新增「开源依赖 · 一键下载 / 一键配置」卡片，覆盖 FFmpeg、rclone、whisper.cpp、MediaMTX 四项，显示许可证、用途与当前状态。
- **一键下载**：直达官方 GitHub Releases 页面，不用自己搜索；清单补全 SHA-256 与体积后会自动改为“下载 + 哈希校验 + 解压”。
- **一键配置**：在本机有界搜索同名 exe（sidecar 目录、PATH、下载 / 桌面 / 文档、Program Files），校验文件名后写入设置并立即生效；找不到时再弹出文件选择。
  - FFmpeg / rclone 路径持久化到 `prefs.json`，重启后仍有效；
  - whisper.cpp 路径供字幕页读取；
  - MediaMTX 复制到 sidecar 安装目录，不改系统 PATH、不写注册表。
- 配置只记录本机已有文件，不静默安装、不静默更新、不联网抓取未核验的二进制。

## 验证

- 单元测试：1684 项全部通过（含新增的手机页 i18n 回读、刷新 / 权限 / CSP、依赖中心查找与配置测试）。
- 手机页实测：配对后刷新可恢复；无凭据刷新提示重新扫码；禁用 `fetch`、主脚本语法错误两种场景均显示兼容提示；监看预览正常加载；360 / 390 宽度、浅色 / 深色均通过。

## 已知限制

- 应用重启后监听端口会变化，手机需重新扫码（token 按 `host:port` 隔离，属预期安全设计）。
- 依赖清单仍为 `manual`：在补全并核对二进制 SHA-256 前，不提供静默自动安装。
