## V2.0.0 更新内容

本版以 impeccable 设计规范为基准，对界面做了一次「Operate 模式」克制优化，并新增自定义背景功能。

### UI 设计优化
- **卡片深度**：所有卡片 / 卡片按钮 / Toast / 下拉面板统一柔和投影（带偏移 + 模糊），深浅主题分级
- **按钮真实状态**：主 / 次 / 幽灵 / 危险按钮的悬停与按下改用真实色阶，替代原来的透明度过场
- **矢量导航图标**：侧边栏 10 个导航项补齐统一描边矢量图标，选中态图标 + 文字同步变品牌色
- **分类卡片**：首页分类卡改为语义色图标芯片（去掉旧版 4px 彩色左边条，符合设计规范）
- **图标规范化**：状态药丸 / 返回箭头 / 下拉箭头 / 模板页状态图标由 unicode/emoji 换为矢量 Path
- **欢迎卡**：突出品牌强调色与主按钮，弱化视觉噪音

### 新功能：自定义背景
设置 → 外观 → 自定义背景，支持三种模式：
- 默认（跟随主题）
- 纯色（6 组预设色板，点选即换）
- 图片（选择本地图片，自动压暗遮罩保证文字可读）

仅保存在本机，不会上传；高对比模式自动回退默认底。
