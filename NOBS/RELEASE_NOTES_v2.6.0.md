# V2.6.0 发布说明 —— 录屏与直播工具箱

发布日期：2026-08-24

V2.6.0 基于 2026-08-24 的网络调研（Reddit r/obs、OBS 官方论坛 / 知识库 /
32.x 发布说明、中文社区），补齐「录屏侧」长期缺失的实用工具，
并把直播侧的高频决策场景（带宽、多路推流、版本升级）做成可计算的入口。
实施依据见 [`docs/OPTIMIZATION_V2.6.0.md`](docs/OPTIMIZATION_V2.6.0.md)。

## 一、新增「工具箱」一级导航

### 1. 录像工具（录屏用户最高频动作）

- **打开录像目录**：自动从 OBS 配置（global.ini → 当前 Profile → basic.ini）
  解析实际保存位置，未自定义时回退系统「视频」文件夹，一键直达；
  解决「录完找不到文件」。
- **MKV / Hybrid MP4 → MP4 无损转封装**：探测本机 ffmpeg 后以 `-c copy`
  秒级完成（不重编码）；未安装 ffmpeg 时给出 OBS 自带转封装与下载指引。
  同时覆盖 OBS 32.x 新默认格式 Hybrid MP4 的兼容性问题。

### 2. 场景化参数处方

内置「录网课 / 录游戏 / 竖屏短视频 / 直播带货」四套推荐参数组合
（分辨率 · 帧率 · 编码器 · 格式 · 码率 · 来源建议），一键复制。

### 3. 录前隐私清单

勿扰通知、桌面图标、窗口捕获缩小暴露面、浏览器无痕等五步清单，
附 Windows 专注助手 / 通知 / 个性化设置的直达按钮。

## 二、直播侧新工具

- **冲突软件扫描**：枚举运行中进程，识别 Nahimic / A-Volute（高危）、
  RivaTuner(RTSS) / AfterBurner / Overwolf / Voicemod（中危）、
  国产安全软件（提示级），逐项给出处置建议并关联知识库条目。
- **推流带宽计算器**：上行带宽 → 推荐码率 / 分辨率 / 帧率组合（65% 安全系数）；
  多路推流所需上行 = 路数 × 码率 × 20% 冗余，含余量偏小预警。
- **OBS 新版本情报**：拉取官方 GitHub 最新 Release（版本 / 日期 / 要点摘要），
  本地缓存 6 小时，离线时回退快照；帮助判断是否值得升级。

## 三、问题库扩充 v1.8 → v1.9（122 → 140 条）

按调研结论新增 18 条（A 高频缺口 / B 32.x 迁移 / C 低优补充）：

- **A 组**：Windows 更新后 OBS 异常、Hybrid MP4 兼容性、蓝牙耳机麦克风音质差、
  压缩器侧链闪避（说话时音乐变小）、日志导出与官方分析器使用、
  会议 / 网课录制捕获失败、定时与分段录制、隐私屏蔽、快手/淘宝/京东接入选型；
- **B 组**：插件管理器用法、SDR 转 HDR 滤镜、WebRTC 联播、NVIDIA RTX 音频滤镜、
  撤销 / 重做救场、升级前备份姿势；
- **C 组**：双 PC 推流搭建、USB 设备中途掉线、帧率与平台规格匹配。

所有 `related` 引用均校验为真实条目 id；随包热更新通道照常生效。

## 四、日志分析联动扩展

规则表追加两条：`LOG-HYBRID-MP4`（Hybrid MP4 输出提示）、
`LOG-VIRTUALCAM`（虚拟摄像头启动失败 → 关联既有条目）。

## 五、其他

- 新增单元测试 14 项（带宽顾问边界值 / 多档位映射 / 冲突扫描排序去重全量回归），
  全量 184 项测试通过。

---

### 升级与兼容性说明

- 工具箱全部功能只读探测或独立进程调用，不修改任何 OBS 配置文件；
- ffmpeg 探测仅扫描 PATH 与常见安装目录，不会下载或写入系统目录；
- 问题库 / 插件目录热更新通道不变，老版本用户启动后静默获取 v1.9 问题库。
