# V3.6.0 发布说明

## 一句话摘要

V3.6.0 新增**导播计时器**：控制窗与无边框置顶计时窗分离，倒计时归零后继续累计超时，支持多显示器、记录与 TSV、全局热键、OBS/手机联动和浏览器叠加层。同时补齐控制台音频电平表、一键脱敏诊断包、外链域名白名单、ColorCheck 路径护栏与备份跳过上报。全量 **1869 项单元测试**与 **37 项无界面自检**通过。

## 新增功能

### 1. 导播计时器（全新模块）

- **双窗口**：控制页负责输入与状态；计时窗无边框、始终置顶、可拖动/缩放，不抢主窗口焦点。
- **倒计时 / 顺计时**：倒计时默认 15:00；顺计时计划时长设为 0 表示不限时。
- **开始 / 暂停 / 继续 / 停止**：开始与暂停同一个按钮；暂停时计时窗变橙。
- **超时提醒**：倒计时归零后计时窗停在 `00:00:00`，控制页继续累计超时并变红；顺计时超过计划时长同样变红。
- **多显示器与显示选项**：主屏/副屏切换、位置记忆；透明度、字号、显示小时；屏幕被拔掉时自动回主屏。
- **记录与 TSV**：记录开始时间、模式、计划时长、实际用时与超时；按最新在上展示，可逐条删除、一键复制 TSV（Excel 友好），记录跨重启保留。
- **全局热键**：`Ctrl+Alt+J` 开始/暂停，`Ctrl+Alt+U` 重置，`Ctrl+Alt+H` 显示/隐藏计时窗。
- **OBS 联动**：可选「OBS 开始录制/推流时自动开始」「OBS 停止时自动停止」，默认关闭。
- **浏览器叠加层**：生成只绑定 `127.0.0.1`、带一次性 token 的网页地址，粘贴到 OBS「浏览器源」即可上屏；页面每 500 ms 拉取状态。
- **手机远程**：手机联动页新增计时器状态与「开始/暂停」「重置」按钮；重置需要确认。
- **捕获排除与点击穿透**：复用提词器的窗口能力；Windows 10 2004+ 的显示器采集可排除计时窗，Win7 走窗口采集/第二屏。
- **署名弹窗**：首次进入计时器页弹出一次性说明，写明功能设计参考、原作者、原仓库与许可证链接。

### 2. 控制台音频电平表

- 订阅 obs-websocket `InputVolumeMeters`，服务层解析并节流到 10 Hz；控制台每条音频输入下方显示实时电平条，静音/无输入时为 0，不额外占用 UI 线程。

### 3. 一键诊断包

- 帮助与反馈页新增「导出诊断包」：版本、系统、OBS 连接、录前自检、最近 30 条 Toast、当前会话日志尾部。
- 默认**不含路径与密钥**：所有文本先过日志脱敏，再把 Windows 绝对路径 / UNC 路径替换为 `<path>`；日志只保留尾部 200 行、最多 20 KB。

### 4. 外链域名白名单

- 知识库、插件目录与平台入口里的链接不再「只要 https 就打开」：只允许 https + 默认端口 + 已知域名（含子域名），拒绝带 userinfo 的 URL、本机/私网地址与未知站点；拒绝时写日志并返回可复制文本。

### 5. 备份与配置路径

- **ColorCheck 路径护栏**：`global.ini` 的 `basic.profiledir` 先收敛成叶子名，`../..` / 绝对路径不再能越界读取。
- **备份跳过上报**：备份/导出成功后，如果个别文件被 OBS 占用而跳过，界面会显示「跳过 N 个文件」及清单，不再笼统报成功。

### 6. 打包与文档

- Release 构建不再输出 pdb；便携包与增量包改用最优压缩。
- 审计文档 [`V3.6.0_AUDIT.md`](docs/V3.6.0_AUDIT.md) 与开发指引 [`V3.6.0_TECH_GUIDE.md`](docs/V3.6.0_TECH_GUIDE.md) 随仓库提供。
- 四份 README、版本号、自检项数、文案键数与文档数字同步校准。

## 修复的问题

### 1. 色彩体检可能越界读取配置

- **以前**：`ColorCheckService` 直接把 `global.ini` 里的 `basic.profiledir` 拼进路径，导入过恶意/异常备份包后，`..` 或绝对路径可能读到 OBS 配置目录之外。
- **现在**：先过 `ObsSafePath.SafeProfileDir`，非法值返回明确提示；正常 profile 名行为不变。

### 2. 备份「报成功」但漏文件

- **以前**：单个文件被 OBS 占用时只写调试输出，界面仍显示「备份已创建」，用户以为包是完整的。
- **现在**：记录 `LastSkipped`，备份与导出提示里如实列出跳过数量与前 8 个路径。

### 3. 外链只校验 scheme

- **以前**：任何 `https://` 链接都能交给系统浏览器打开，热更新内容被篡改时用户会被带到未知站点。
- **现在**：统一走 `ExternalLinkPolicy`；未知域名、非默认端口、userinfo、本机/私网一律拒绝。

### 4. 文档数字漂移

- **以前**：README / ARCHITECTURE / CODEBASE 仍写 96 个服务、24 条路由、28 条路由用例、36 项自检、3502 条文案键。
- **现在**：98 个服务、25 条路由、29 条路由用例、37 项自检、3589 条文案键，`check_docs.py` 通过。

### 5. 发布物带调试符号

- **以前**：Release 发布目录带 pdb，便携包与增量包使用默认压缩。
- **现在**：Release 不输出 pdb；zip 使用最优压缩。

## 兼容性与升级

- 版本号：`3.5.3` → `3.6.0`，可覆盖升级，无需卸载旧版。
- 安装目录、程序集名、数据目录（`%LocalAppData%\OBS_Helper`）均未改变；设置、书签、场景模板、提词稿、手机配对记录、壁纸库、已安装插件清单全部保留。
- 新增数据键：`timer.settings`、`timer.records`、`timer.attribution`；删除这些键即可恢复计时器默认值，不影响其他设置。
- 新增全局热键默认 `Ctrl+Alt+J/U/H`；与既有热键冲突时设置页会显示注册失败原因，可改键或关闭。
- 系统要求不变：Windows 10 / 11；Win7 兼容构建仍可运行，但计时器叠加层、捕获排除与手机远程不建议在 Win7 使用。
- 增量包：`3.5.3` → `3.6.0` 版本连续，可按 CI 基准资产生成；基准不可得时使用完整安装包。

## 已知边界

- **计时器为清洁室独立实现**：功能设计参考 [咩计时 meTimer](https://github.com/zanjie1999/meTimer)，未复制其源代码；原项目采用咩License 1.1（非商业限制），本项目计时器模块以 MIT 发布。署名与许可证原文见 [`third_party/meTimer/NOTICE.md`](third_party/meTimer/NOTICE.md) 与 [`LICENSE.md`](third_party/meTimer/LICENSE.md)。
- **本版未完成审计中的全部 53 项**：插件查询批量退避、首屏同步 IO 全量清理、安全模式启动、热键冲突一键重设、应用内更新日志、N 系列其余补强列入 V3.7；代码签名、真 LLM、在线主题市场、联机协作、手机浏览器直采、Twitch/YouTube 自动统计仍不提供。
- **浏览器叠加层只在本机回环**：地址带 token，适合本机 OBS Browser Source；不提供局域网/公网访问。
- **手机远程需要先配对**：只支持已配对设备；重置命令需要确认；未启动手机服务时不可用。
- **捕获排除依赖系统能力**：仅 Windows 10 2004+ 的显示器采集可排除，部分采集后端可能显示黑块；Win7 请用窗口采集或第二屏。
- **发布物仍未做 Authenticode 代码签名**：SmartScreen 仍可能提示「未知发布者」。
- **音频电平表依赖 OBS 推送**：OBS 版本过旧或未连接时不显示；电平条只读，不改变音量。
