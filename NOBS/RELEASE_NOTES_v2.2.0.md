# OBS 排障助手 V2.2.0 发布说明

> 发布主题：**插件生态（V2.2）** —— 依据《docs/ROADMAP_PLUGINS.md》调研路线图完整落地：
> 插件目录热更新 · 本机插件体检 · 日志 × 插件嫌疑联动 · 直达下载 · AI 性能预算 · 搭建向导

## 新增功能

### 1. 插件广场升级为「全链路」页面（P0-1 / P1-1 / P1-2 / P2-1）
- **本机已装插件体检（只读）**：扫描 OBS 安装目录（进程 / 注册表 / 默认路径三重定位，
  兼容便携版与用户级插件目录），枚举已装插件的 DLL 名称与文件版本；
  顶部新增「本机已装 N 个插件」面板，逐条标注 **「广场收录 / 未收录」**，
  收录条目可一键在下方广场中定位高亮。全程只读不改，结果仅存本机。
- **直达 Releases 下载**：每张卡片新增「⬇ 下载」按钮，直达该插件 GitHub Releases 最新版页面；
  并展示「最新 vX.Y.Z」角标。查询走 GitHub API，带内存 + 磁盘双层缓存（24h 保鲜）与
  在途请求合并，匿名限流内从容使用；任何失败静默不打扰。
- **AI 插件性能预算提示（P1-2）**：AI 分类的卡片标注公开开销参考
  （抠像约 +5~15% CPU / 100~300MB 内存，字幕约 +5~10% CPU / 200~500MB 等），
  并联动系统监控实时采样——空闲内存 < 500MB 或 CPU ≥ 80% 时给出个性化预警文案。
- **关注插件启动查新（P2-1）**：卡片可「☆ 关注」，应用启动时静默检查新版本
  （24h 节流，首次关注先建立基线不轰炸），有新版仅角落 Toast 不弹窗。

### 2. 日志分析 × 插件嫌疑联动（P0-2）
- 日志分析器新增「嫌疑模块」提取：`os_dlopen(...)` 加载失败、`Module '...' not loaded`、
  崩溃报告肇事模块等线索都会提取出具体 DLL 名。
- 命中的发现卡片上直接给出 **「🧩 在插件广场查看 →」** 跳转按钮（能对上广场条目时），
  未收录的也会显示嫌疑模块名便于排查；智能诊断页同步支持。
- 新增两条日志规则：检测到 StreamFX（停更插件）→ 给出迁移建议；
  检测到 obs-multi-rtmp → 提示已知问题与 Aitum Multistream 替代评估。

### 3. 插件数据外置到知识库通道（P0-3）
- 插件广场 7 分类 × 28 个精选条目全部外置到 `plugins.json`，
  与问题库共用同一套分离热更新机制：本地覆盖文件 + 内嵌种子 + 远程双通道
  （GitHub raw 主通道 / Release 资产 `OBS_Helper_Plugins_<ver>.json` 兜底）。
- 链接失效、新插件上架无需发版即可修复；设置页「检查知识库更新」会同时刷新两条通道。

### 4. 竖屏 / 多平台搭建向导（P1-3）
- 搭建页新增「进阶向导」区块，内置两条分步向导窗口：
  - **竖屏 9:16 双画布**（基于 Aitum Vertical 实测流程）：安装 → 认识竖屏画布 → 场景搭建 →
    同名场景联动 → 输出与开播 → 开播前自检；
  - **多平台同时推流**（基于 Aitum Multistream）：选型 → 安装 → 逐路配置与带宽预算 →
    私密直播逐路验证 → 开播监控与取舍。
- 步骤内按钮直达对应知识库条目与插件广场卡片。

### 5. 场景模板推荐插件标注（P2-2）
- 模板数据支持 `requiresPlugins` 字段；竖屏带货 / 短视频模板推荐 Aitum Vertical、
  双人访谈推荐 DroidCam、播客对谈推荐 Audio Monitor。
- 卡片上对照本机体检查看显示「✓ 已安装 / ⚠ 未安装 →」，未安装可直接跳转插件广场；
  落地前确认框会补充缺失提醒（仅提示不阻断）。

### 6. 知识库扩充（v1.5 → v1.6，110 → 112 条）
- **StreamFX 停更替代迁移指南**：模糊 → Composite Blur、遮罩 → Advanced Masks、
  描边辉光 → Stroke Glow Shadow、着色器 → obs-shaderfilter（对应 2025–2026 生态信号 3）；
- **obs-multi-rtmp 已知问题与替代方案**：带宽骤降 / 编码过载 / 杀软误报的处理与
  Aitum Multistream 迁移建议（对应生态信号 4）。

## 改进与修复
- 「下载」/「关注」按钮位于卡片内部，已处理 WPF Click 冒泡，点击不再误开项目主页。
- 目录换版后插件广场自动重建（分类状态复位），知识库双通道更新互不干扰、各自节流。
- 本地体检扫描失败 / OBS 未安装时给出明确指引文案，绝不抛异常。

## 质量保障（交付前交叉检验 ×2）
- 单元测试 140 个全部通过（新增插件目录解析 / DLL 匹配 / repo 归一化 /
  扫描核心 / 嫌疑模块提取共 20+ 用例）；
- 应用自检（16 条路由含参数化导航）17 PASS / 0 FAIL；
- 全量 diff 双轮复审：修复了嵌套按钮事件冒泡、目录换版后分类状态错位、
  problems.json 缩进回退导致的整文件 diff 等问题。

## 升级说明
- 2.1.x 用户可在应用内直接增量更新（体积小）；也可从 Release 页下载完整安装包 / 便携包。
- 知识库 v1.6 与插件目录 v1.0 支持独立更新，老版本用户启动后会静默获取。
