## 4. 已知边界

1. **未做每页双 XAML**：本轮采用统一视觉树 + 令牌/模板切换；技术方案中的双 Shell + 每页双视图留待后续版本（见设计指引 §10）。
2. **未用 NVDA / Narrator 实测**：换肤播报、编号读屏名称、焦点行为已按契约实现，但未做读屏实测；发布说明不得写「支持屏幕阅读器」。
3. **未做真机高 DPI 复核**：100% DPI 截图通过；125%/150%/200% 与 1366×768 需后续实测。`MinWidth` 已从 920 提到 1024。
4. **C 的 37 px 细体中文**：`Segoe UI Light` 不覆盖中文，实际回退到 YaHei Regular；Windows 10/11 中文环境字重可能比设计板更粗。
5. **自定义背景不属于设计 1:1 验收**：默认底验收；开启后 A 自动压暗、C 保持原色，壁纸的视觉一致性不做承诺。
6. **独立窗口只跟随语义色**：迷你小窗 / 计时窗 / 提词器未做 A/C 两套结构。

## 5. 复跑方式

```powershell
# 构建（主构建）
dotnet build NOBS/OBS_Helper.Wpf/OBS_Helper.Wpf.csproj -c Debug -f net10.0-windows

# 单元测试
dotnet test NOBS/OBS_Helper.Wpf.Tests/OBS_Helper.Wpf.Tests.csproj -c Debug

# 应用内自检（37 项）
$env:OBS_SELFTEST=1
dotnet run --project NOBS/OBS_Helper.Wpf/OBS_Helper.Wpf.csproj -c Debug --no-build -f net10.0-windows

# 双皮肤截图（输出到 %LocalAppData%\OBS_Helper\shots）
$env:OBS_SHOT=1
.\NOBS\OBS_Helper.Wpf\bin\Debug\net10.0-windows\OBS_Helper.exe

# 静态检查
python NOBS/scripts/check_resources.py
python NOBS/scripts/check_accessibility.py
python NOBS/scripts/check_docs.py
```

> `OBS_SHOT_LIMIT=<n>` 可只跑前 n 条路由，便于快速冒烟。
