## 5. 纯逻辑 API（`TimerCore`）

### 5.1 状态机：`TimerMachine`

```csharp
public sealed class TimerMachine
{
    public TimerState State { get; }
    public TimerMode Mode { get; set; }
    public TimeSpan Planned { get; set; }

    public void Start(DateTime now);
    public void Pause(DateTime now);
    public void Resume(DateTime now);
    public TimerRecord? Stop(DateTime now, int nextId);
    public void Reset();

    public TimerSnapshot Snapshot(DateTime now);
    public TimeSpan ElapsedAt(DateTime now);
}
```

规则：

| 操作 | 前置 | 结果 |
|---|---|---|
| `Start` | Idle / Finished | 记录 `_startedAt=now`，`_accumulated=0`，State=Running；Finished 重新开始视为新一轮 |
| `Pause` | Running | `_accumulated += now-_startedAt`，State=Paused |
| `Resume` | Paused | `_startedAt=now`，State=Running |
| `Stop` | Running / Paused / Finished | 计算 elapsed，生成记录，State=Idle，清空累计（记录在 Service 里落盘） |
| `Reset` | 任意 | 丢弃当前一轮，State=Idle |
| `Snapshot` | 任意 | 见 §5.2 |

`ElapsedAt(now)`：

- Running：`_accumulated + (now - _startedAt)`
- Paused / Finished：`_accumulated`（Finished 时在 `Snapshot` 里额外用 `now - _finishedAt` 累计超时）

> 计划中的「基于 Stopwatch 防漂移」在 `TimerService` 层实现：`Stopwatch` 提供单调时间，`DateTime` 提供记录时间；每次 Tick 用墙钟差校正休眠/唤醒造成的偏差（见 §6.3）。

### 5.2 `TimerCore.ComputeSnapshot`

```csharp
public static TimerSnapshot Compute(
    TimerState state, TimerMode mode, TimeSpan elapsed, TimeSpan planned,
    TimeSpan overtimeWhenFinished, bool paused);
```

- 倒计时：
  - `remaining = planned - elapsed`；`remaining <= 0` → `Display="00:00"`（显示小时则 `00:00:00`），`overtime = elapsed - planned`。
  - State=Finished 后 `overtime` 继续增长。
- 顺计时：
  - `Display = FormatClock(elapsed)`；`overtime = planned > 0 && elapsed > planned ? elapsed - planned : 0`。
- `IsOvertime = overtime > 0`。

### 5.3 格式化

```csharp
public static TimeSpan ParseDuration(string? text);       // "15:00" / "1:02:03" / "900"（秒）
public static string FormatClock(TimeSpan value, bool showHours); // 向下取整到秒
public static string FormatDuration(TimeSpan value);      // 记录用：1:02:03 / 02:03
public static string FormatSignedOvertime(TimeSpan value); // +00:35
```

- `ParseDuration` 只接受数字与冒号；非法返回 `TimeSpan.Zero`；上限 `99:59:59`。
- `FormatClock` 负数按 0 处理；小时位在 `showHours` 或 `>=1h` 时显示。
- 不用 `ToString(@"hh\:mm\:ss")`（>24h 会回绕）。

### 5.4 记录与 TSV

```csharp
public static IReadOnlyList<TimerRecord> OrderForDisplay(IEnumerable<TimerRecord> records);
public static string BuildTsv(IEnumerable<TimerRecord> records);
```

- 展示顺序：`Id` 倒序（最新在上），界面显示「1」为最新一条（与 meTimer 的「序号 1 在最前」一致）。
- TSV 表头：`序号\t开始时间\t模式\t计划时长\t实际用时\t超时`。
- 字段内 `\t` / `\r` / `\n` 替换为空格；空值写 `-`。
- 末尾带 `\r\n`（Excel 兼容）。

### 5.5 clamp 与几何

```csharp
public const double MinOpacity = 0.2, MaxOpacity = 1.0;
public const double MinFontScale = 0.6, MaxFontScale = 3.0;
public const int MinWindowWidth = 220, MinWindowHeight = 100;

public static double ClampOpacity(double value);
public static double ClampFontScale(double value);
public static int NormalizeMonitorIndex(int index, int count); // 越界 → 主屏/0
public static TimerRect ResolveBounds(
    TimerRect? saved, IReadOnlyList<TimerScreen> screens, int preferredIndex,
    double defaultWidth, double defaultHeight);
public static TimerRect FitToWorkArea(TimerRect window, TimerRect workArea);
```

`ResolveBounds` 规则：

1. 选择屏幕：`preferredIndex` 在范围内用它，否则第一个 `IsPrimary`，否则 0。
2. 没有 saved：默认放在该屏幕工作区左上角 + 24px 边距，宽高取默认值。
3. 有 saved：先夹到 `[MinWindowWidth, workArea.Width]` × `[MinWindowHeight, workArea.Height]`；位置夹到工作区内。
4. 完全落在所有屏幕之外（拔掉副屏）：回主屏默认位置。

### 6.2 生命周期

- 组合根：`AppServices.Timer` → `new TimerService(Store)`。
- 首次访问时加载 settings/records；不启动计时器。
- `DispatcherTimer` 200ms；仅在 Running/Finished 时运行，Idle/Paused 停止（减少空转）。
- 应用退出：`Dispose` 停止 timer、关闭窗口、停止叠加服务、保存。
- 单实例：`TimerWindow` 由 `TimerService` 持有，重复 `Show` 只激活已有窗口。

### 6.3 防漂移与休眠

```csharp
private readonly Stopwatch _monotonic = Stopwatch.StartNew();
private DateTime _lastWall;
private TimeSpan _wallCorrection;
```

- 每次 Tick：
  - `wallDelta = now - _lastWall`；`monoDelta = _monotonic.Elapsed - _lastMono`。
  - 若 `wallDelta - monoDelta > 2s`（休眠/时钟跳变），把差值加入 `_wallCorrection`。
  - 实际 elapsed = `machine.ElapsedAt(now) + _wallCorrection`。
- 记录 `StartedAt` 使用墙钟；实际用时使用修正后的 elapsed。
- 若检测到墙钟回拨（`wallDelta < 0`），只记日志，不把时间减回去。

### 6.4 持久化

| 键 | 内容 | 写入时机 |
|---|---|---|
| `timer.settings` | `TimerSettings` JSON | 设置变更、窗口移动/缩放结束、显示/隐藏 |
| `timer.records` | `List<TimerRecord>` JSON | 停止、删除、清空 |
| `timer.attribution` | `"1"` | 首次弹窗确认后 |

- 读取失败：记 `FileLogger.Warn("Timer", ...)`，使用默认值；不覆盖原文件。
- 记录写入原子性由 `LocalStore` 的临时文件替换保证。

### 6.5 OBS 联动（默认关闭）

- 订阅 `AppServices.Obs.StateChanged`。
- 维护 `_wasRecording` / `_wasStreaming`。
- `AutoStartWithRecording`：
  - 录制或推流从 `false → true`，且 State 为 Idle/Finished → `Start()`。
- `AutoStopWithRecording`：
  - 录制与推流都从 `true → false`，且 State 为 Running/Paused/Finished → `Stop()`。
- 事件回调里只改状态 + 保存；窗口刷新交给 `Changed`。
- OBS 未连接时不启动、不报错。

- 捕获排除：`WindowCaptureExclusion.SetExcludeFromCapture(this, enabled)`；Win7 降级提示。
- 点击穿透：`WindowCaptureExclusion.SetClickThrough(this, enabled)`；穿透后通过热键/右键托盘退出。

- 高对比/减少动画：跟随 `AppearanceService`；高对比用纯色背景 + 粗边框，减少动画关闭淡入。
- DPI：使用 WPF 设备无关单位；窗口位置用 `PointFromScreen`/`TransformFromDevice` 转换，避免 150%/200% 偏移。

### 7.3 无障碍

- 计时窗 `AutomationProperties.Name` = 「计时器，当前 05:12，运行中」；每 5 秒最多更新一次，避免读屏刷屏。
- 主页面按钮/输入/列表均有名称与 HelpText。
- `AutomationProperties.LiveSetting="Polite"` 只在状态变化（开始/暂停/超时）时触发 `LiveRegionChanged`。

## 8. 浏览器叠加层协议（`TimerOverlayServer`）

### 8.1 启动

- 仅当用户点击「复制浏览器叠加地址」时 `Start()`；不随应用启动。
- 只绑定 `127.0.0.1`，随机端口，随机 32 位 token。
- 失败返回 `null` + 错误码 `OBS911`；不影响主功能。

### 8.2 路由

| 方法 | 路径 | 响应 |
|---|---|---|
| GET | `/t/<token>/` | HTML 页面（内嵌 CSS/JS，无外部资源） |
| GET | `/t/<token>/state` | `application/json`：`{"display":"05:12","state":"running","paused":false,"overtime":false,"mode":"countdown","overtimeSeconds":0}` |
| 其他 | * | 404（不区分不存在/无权限） |

### 8.3 安全

- 响应头：`Content-Security-Policy: default-src 'none'; style-src 'unsafe-inline'; script-src 'unsafe-inline'; connect-src 'self'`、`X-Content-Type-Options: nosniff`、`Cache-Control: no-store`。
- URL 长度上限 256；只接受 GET/HEAD；无请求体。
- 页面每 500ms `fetch('./state')`；失败显示「连接中断」。
- 叠加页只读，不提供任何写操作。
