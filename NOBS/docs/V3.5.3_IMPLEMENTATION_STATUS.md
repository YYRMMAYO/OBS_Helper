## 2. 同步清单（X1031Y2 / X1031Y3 → V3.5.3）

### 2.1 来自 X1031Y2

- **插件一键配置**：精选插件卡片在应用内查最新 Release → 选 Windows x64 包 → 下载 → SHA-256 校验 → 解压安装；粘贴 `owner/repo` 回车即装。
- **下载前网络确认**：提示 Watt Toolkit（Steam++）加速或确认网络；失败时重新露出加速引导与下载页。
- **开源依赖一键配置**：FFmpeg / rclone / whisper / MediaMTX 应用内下载、校验、解压、定位 exe、写入设置。
- **本机插件管理**：卸载（先备份）、用户级 ⇄ 全局级迁移、接管管理、打开文件夹。
- **安全加固**：`installed.json` 路径护栏、GitHub 主机 / 摘要白名单、依赖与 sidecar / 增量包解压上限。
- **问题库**：208 条 / v2.3 / 14 个分类，中英对齐。

### 2.2 来自 X1031Y3

- **下载可用性修复**：放行 `release-assets.githubusercontent.com`，兼容 `github-releases.githubusercontent.com`；失败写 host / HTTP 状态 / 体积 / 异常日志。
- **依赖准备器与功能页接入**：字幕（whisper / 模型）、切片（FFmpeg）、转推（FFmpeg）、归档（rclone）安装后自动填路径。
- **手机摄像头状态机**：未安装 → 已安装未启动 → 已启动未收到推流 → 已收到推流 → OBS 已绑定；二维码 / 检测 / 防火墙按钮。
- **功能中心**：「运行环境准备」卡（5 个组件状态 + 一键按钮）；18 项能力标注「实验性 / 规划中 / 本地」状态位（稳定项不额外标注），并在说明中提示与完整实现的差距。
- **本版补齐**：Q05 录制结束自动归档（默认关闭）、C10 / E06 落盘、手机配对上限提示、历史录像文件索引、MediaMTX WebRTC 视频监看与 OBS WHIP 地址。
- **宣传 vs 实现审查**：18 项能力增加状态位（规划中 / 实验性 / 本地），`AI 回复建议`、`AI 导播`、`装修市场`、`团队协作`、`录制检索`、`构图检查` 等名称保持不变，靠状态位与说明提示边界；完整对照与 Y4 待办见 [`x1031_v350/12_X1031Y3_FEATURE_CENTER_READINESS.md`](x1031_v350/12_X1031Y3_FEATURE_CENTER_READINESS.md)。

### 2.3 明确排除

- **X 系列专属字标图标**（`Assets/appicon_x.ico`）不用于 V 构建：`build.ps1` 按内部版本主版本号判断，`3.5.3` < 1000 → `XSeriesIcon=false` → 使用 `Assets/appicon.ico`；安装包 `SetupIconFile` 同样取 V 图标。

## 5. 已知边界

- **未做 Authenticode 代码签名**：需要开发者本人的代码签名证书与私钥，仓库内没有该证书；SmartScreen 仍可能提示「未知发布者」。
- **依赖下载受网络影响**：本机实测 MediaMTX 依赖全包下载在 49% 时因网络过慢中止，但 302 → `release-assets.githubusercontent.com` → 写盘路径已验证。
- **手机端未在真实手机硬件上复测**：配对、推流检测、WebRTC 监看使用移动视口与本地服务验证；手机浏览器在局域网 HTTP 下仍不能直接调用摄像头。
- **宣传强于实现的边界仍在**：LLM 回复 / 搭档、真 AI 导播、在线主题市场、联机团队协作、Twitch / YouTube 自动观众统计、手机浏览器直接当摄像头仍未接入；详见发布说明与功能中心开发指引。
- **历史录像只做文件级索引**：不读取视频内容，不做历史字幕 / 语音检索。
- **功能中心审查是代码级初审**：未在真机 / 真网络逐项复现，标「未验证」的项不能当成验收报告。
- **Win7 兼容构建未在真实 OBS 27 上复测**：依赖一键配置、WebRTC 监看与手机 Wi-Fi 摄像头不建议在 Win7 使用。
