## 新增

### 录制守护（GAP-1，默认开启）
- 直播 / 录制中最怕的「静默失败」从此有人盯：三层异常信号监控，出事立刻托盘强提醒——
  - **断连告警**：WebSocket 断开且当时正在录制（OBS 崩溃 / 被关闭时用户在游戏中毫无察觉）；
  - **心跳超时**：录制中连续 3 次 `GetRecordStatus` 查询失败（约 6 秒），提示 OBS 疑似假死、
    卡在「正在停止录制」时不要强制关机；
  - **重连后确认**：自动重连成功后发现录制已被中断，明确告知并引导一键重启录制。
- 同类告警单次异常期间只弹一次；状态恢复正常自动复位。设置 →「后台与遥控」可关。

### 实时日志尾随预警（GAP-4，默认开启）
- 事中监控补全：后台只读尾随 `%AppData%\obs-studio\logs` 最新会话日志，
  直播中出现掉帧、编码过载、断流、插件加载失败等特征时即时托盘提醒，不用等下播翻日志。
- 匹配规则与离线日志分析器同源共享（一处维护）；命中前先脱敏；仅取警告级以上。
- 双重防打扰：同类告警 90 秒抑制 + 每小时全局 12 条限流；自动跟随 OBS 滚动到新日志文件，
  首次挂载从文件末尾开始，不重放历史。设置 →「后台与遥控」可关。

### 黑屏专项体检（GAP-2 + GAP-8）
- 工具箱新增「黑屏专项体检」卡片：社区标准黑屏排查链的可程序化部分逐项只读探测——
  - HAGS（硬件加速 GPU 计划）开关；
  - Windows 图形首选项中 obs64.exe 的 GPU 绑定（省电偏好 → 警告；双显卡未指定 → 警告）；
  - Xbox Game Bar 后台录制 / 游戏模式；
  - 显卡驱动版本与日期（按月龄判定「驱动较旧」并给出更新建议）；
  - 电源计划名称 + 是否电池供电（电池供电直接警告）；
  - 当前进程管理员权限参考项。
- 全部只读：「建议」项给出对应系统设置页路径，绝不替用户改注册表。

### 音频设备深度体检（GAP-3）
- 工具箱新增「音频设备深度体检」卡片：麦克风无声 / BGM 忽然变小的系统侧根因逐项排查——
  - 系统层面麦克风隐私权限（全局禁用 → error 级）；
  - 通信 Ducking 策略（通话时压低音量 → 警告，建议改「不执行任何操作」）；
  - Audiosrv / AudioEndpointBuilder 服务运行状态；
  - OBS 所选输入 × 系统活动录音设备宽松对照（设备漂移静默失效 → 警告并列出对不上的名字）。

### 虚拟摄像头体检（GAP-5）
- 工具箱新增「虚拟摄像头体检」卡片：DirectShow 驱动注册项 + win-dshow.dll 插件文件探测，
  输出排查树——驱动未注册 → 管理员启动重注册 / 重装指引；已注册 → 会议软件枚举缓存等实用提示。
  控制台页虚拟摄像头开关本就可用，本项补齐「找不到 OBS Virtual Camera」的诊断能力。

### 已知问题插件标注（GAP-6）
- plugins.json schema 新增可选字段 `riskNote`（旧 JSON 缺字段天然兼容）：
  本机插件体检命中已知风险插件时打黄标提示。首批标注：
  - **obs-multi-rtmp**：新版 OBS 上有带宽骤降 / 编码过载 / 杀软误报零星报告；
  - **Source Record**：旧版本可能引发「卡在正在停止录制」，先升级最新版。
- 字段走知识库外置热更新通道，名单更新无需发版。

## 质量

- 新增纯逻辑核心 5 个（RecordWatchdogCore / GraphicsEnvCheckCore / AudioDeviceHealthCore /
  VirtualCamCheckCore / LogAlertThrottle），全部配套 xUnit 单测：**241 → 280 项测试全部通过**。
- Headless 自检（`OBS_SELFTEST=1`）：18 条路由全部 PASS。
- 两遍独立交叉检验通过：修复录制守护「应然状态」锁存缺陷（手动停录后守护不再解除）、
  实时尾随首次挂载回放历史日志问题、长整型数组长度隐患、powercfg 中文输出乱码风险、

## 升级说明

- 旧配置无需迁移：两个新开关（录制守护 / 实时日志预警）默认开启，可在 设置 →「后台与遥控」关闭。
- 安装包 / 便携包 / 增量更新包照常发布；停留在更早版本的用户可通过应用内增量更新直接升级。
