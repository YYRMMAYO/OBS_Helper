# V3.3.0 无障碍与老年模式技术指引

> 配套主文档：[`PLAN_V3.3.0.md`](PLAN_V3.3.0.md)
> 本文回答三件事：**现在哪些无障碍设计可以改、无障碍模式怎么改 UI、老年模式怎么稳定落地**。
> **已确认（2026-10-25）**：无障碍/老年模式纳入 3.3.0 P0，作为其它新页面的横切前置能力。
> **结论先行**：无障碍不是“再加几个开关”，而是“设计令牌 + 纯逻辑模式组合 + 全量可访问名称/实时区域 + 键盘焦点 + 真实读屏测试”。3.3.0 应把无障碍/老年模式作为**横切能力先做**，否则新加的 Live2D/房间/开播/插件页面会重复欠账。

## 1. 现状审计（只列可核对的事实）

> 基线：`master` `6b0b57f`（V3.1.1）。行号会漂移，以文件内容为准。
> 现有 [`../ACCESSIBILITY.md`](../ACCESSIBILITY.md)（工作区上一级）已如实写明“未经 NVDA/Narrator 实测”；本文延续这个边界，不把静态核对说成实测。

### 1.1 已经做到的

| 能力 | 落点 | 事实 |
|---|---|---|
| 主题/强调色/字号 | `Services/AppearanceService.cs`、`Themes/Palette.xaml` | 浅/深/跟随系统；5 套强调色；4 档字号（0.92/1.0/1.12/1.28×），再乘系统文本缩放 |
| 系统高对比 | `AppearanceService.HighContrastEffective` | 应用内开关 OR `SystemParameters.HighContrast`，监听系统变更 |
| 系统文本缩放 | `AppearanceService.SystemTextScaleFactor` | 读 `HKCU\Software\Microsoft\Accessibility\TextScaleFactor`，钳 1.0~2.0 |
| 减少动画 | `AppearanceService.Apply` | `MotionDuration`/`MotionFast`/`MotionSlow` 归零；主窗过渡/Toast/引导/壁纸引用 |
| 状态不只靠颜色 | `Themes/Controls.xaml` 的 `StatusPill` | 图标 + 文字 + 颜色；连接徽章有文字状态 |
| 键盘焦点（部分） | `Themes/Controls.xaml` | 多数按钮/复选框/下拉/分段控件有 `IsKeyboardFocused`/`IsKeyboardFocusWithin` 触发器 |
| 危险确认框焦点 | `Controls/ConfirmDialog.xaml.cs` | `danger` 时默认焦点在“取消”；`Window.Title` 供读屏 |
| Toast 实时区域 | `Services/ToastService.cs` | 声明 `LiveSetting` + 主动 `RaiseAutomationEvent(LiveRegionChanged)`；有最近 30 条历史、悬停暂停、点击关闭 |
| 连接徽章 | `Controls/ConnectionBadge.xaml(.cs)` | 可 Tab、空格/回车激活、名称含状态 |
| 背景色板键盘 | `Views/SettingsPage.xaml(.cs)` | 可聚焦、可见焦点、回车/空格选择、可访问名称 |
| 图标按钮名称 | `MainWindow.xaml`、`TeleprompterWindow.xaml` 等 | 返回/提词器工具等有 `AutomationProperties.Name` |
| 静态检查 | `scripts/check_accessibility.py` | R1 无文字控件必须有名称；R2 实时区域声明+事件；R3 鼠标自绘按钮必须可聚焦+键盘激活 |

### 1.2 主要缺口（按影响排序）

| # | 缺口 | 证据 | 影响 |
|---|---|---|---|
| 1 | **动态卡片/状态没有可访问名称/实时区域** | 多数页面 XAML `AutomationProperties.Name` 为 0；问题卡、诊断项、日志发现、体检结论、插件卡、模板卡都是运行时构造 | 读屏用户不知道结果出现/更新；只能逐项 Tab 探索 |
| 2 | **没有全局焦点视觉样式** | `Themes/Controls.xaml` 有局部焦点触发器，但无统一 `FocusVisualStyle`；部分自绘控件焦点弱 | 键盘用户看不清当前焦点 |
| 3 | **没有 skip link** | `MainWindow.xaml` 左侧 13 项导航 + 长页面；`TabIndex` 全仓零命中 | 长页面要 Tab 很多次才能到内容 |
| 4 | **Toast 键盘出口不足** | `ToastService` 卡片是 `ContentControl`，鼠标点击关闭；无可见关闭按钮/不可聚焦 | 键盘用户无法主动关闭/回看 |
| 5 | **高对比语义面有限** | `Apply` 只推 `TextBrush`/`MutedBrush`/`LineBrush`/背景；语义色/柔和底不变 | 高对比下状态色/对比度仍可能不足 |
| 6 | **减少动画不跟随系统** | `SystemParameters.ClientAreaAnimation` 零命中 | 系统已关动画时应用仍动 |
| 7 | **高 DPI 最小宽度风险** | `MainWindow.xaml` `MinWidth=920`，内容区仅垂直滚动 | 150%/200% 缩放下可能横向不可达 |
| 8 | **迷你小窗键盘不可用** | `MiniControlWindow.xaml` `ShowActivated="False"` | 热键呼出后焦点不在小窗，键盘无法操作按钮 |
| 9 | **图表无文字替代** | `Controls/Sparkline.cs` 自绘，无 `AutomationProperties.Name`/数值摘要 | 读屏拿不到趋势 |
| 10 | **音频提醒只有托盘气泡** | `Services/Audio/AudioAlertService.cs` 调 `TrayService.Notify` | 听障用户错过“麦克风静音/音量过低” |
| 11 | **对话框/向导焦点与名称不齐** | 部分 `Window` 无 `Title`/无初始焦点；动态向导步骤无实时区域 | 读屏不知道对话框/步骤变化 |
| 12 | **无无障碍模式/老年模式** | `AppearanceService` 只有单项设置；无密度/简化布局 | 用户要逐项调，且无法整体切换 |
| 13 | **无读屏实测** | `ACCESSIBILITY.md` 自述 | 不能宣称“支持屏幕阅读器” |
| 14 | **无伪本地化/长文案测试** | 现有检查未覆盖 | 英文/大字号下可能截断 |
| 15 | **无 UIA 自动化测试** | 只有静态脚本 | 名称/控件类型/焦点回归无自动守卫 |

### 1.3 可以立即改、且收益最大的 10 处

1. 全局 `FocusVisualStyle`（3 px 品牌色 + 2 px 偏移）+ 所有自绘控件焦点。
2. 主窗 skip link（“跳到主内容”）+ 导航/内容焦点顺序。
3. 动态卡片统一基类/附加属性：`Name`/`HelpText`/`ItemStatus`/`LiveSetting`。
4. Toast 加可见关闭按钮、可聚焦、键盘关闭、暂停自动消失、历史面板。
5. 高对比补全语义色/柔和底/边框/焦点；用计算结果守卫 4.5:1/3:1。
6. 减少动画 = 应用内 OR 系统 `ClientAreaAnimation`；所有动效统一走 `MotionDuration`。
7. 布局从“固定 MinWidth + 无横向滚动”改为“断点重排 + 横向滚动兜底”。
8. 音频提醒加应用内视觉横幅 + 托盘 + 可回看状态，不只气泡。
9. Sparkline/进度/步骤列表加文字摘要/实时区域。
10. 无障碍模式/老年模式（见 §2、§3），用 `UiProfileCore` 统一计算。

## 2. 无障碍模式（Accessibility Mode）

### 2.1 定义

一个**可整体切换、可继续微调**的预设，不是把所有开关锁死。打开后默认应用一组“低风险、普适”的增强：

| 项 | 默认 | 说明 |
|---|---|---|
| 字号 | +15% | 与用户档位/系统缩放相乘，取较大值 |
| 行高/段距 | +10% | 正文更易读 |
| 密度 | Comfortable | 控件更高、卡片更松 |
| 焦点 | 始终可见 3 px | 键盘/开关控制用户 |
| 动效 | 关闭 | 同时跟随系统 |
| 状态 | 图标+文字+颜色 | 不只靠颜色 |
| 实时区域 | 开启 | 进度/错误/结果播报 |
| Skip link | 显示 | 键盘用户跳过导航 |
| 最小目标 | 44×44 DIP | 触控/开关/手抖用户 |
| 表单标签 | 输入框上方 | 不用 placeholder 当标签 |
| Toast | 可聚焦/可关闭/可回看 | 错误不自动消失 |
| 音频提醒 | 应用内视觉横幅 | 听障用户 |
| 文案 | 尽量短句、少缩写 | 认知障碍用户 |

**不强制**：
- 不强制高对比（有些用户不需要；系统高对比仍生效）。
- 不强制隐藏装饰/壁纸（但高对比下自动回退默认底）。
- 不强制改变主题深浅（跟随用户/系统）。
- 不隐藏功能；高级功能仍可达。

### 2.2 组合与优先级

```
系统下限：SystemHighContrast / SystemTextScale / SystemAnimation
   ↓
用户显式选择：主题 / 字号 / 高对比 / 减少动画 / 密度
   ↓
无障碍模式预设（只改未被用户显式覆盖的项）
   ↓
老年模式预设（字号/密度/简化取更大值）
   ↓
UiProfileCore 计算 → AppearanceService.Apply()
```

规则：
- 系统高对比 = 应用内高对比 OR 系统高对比；不能被应用关掉。
- 系统文本缩放是乘数，不能被应用降到 1.0 以下。
- 系统“减少动画”开启时，应用必须减少；用户不能强行打开（可提示“系统已关闭动画”）。
- 两个模式叠加：字号/密度取 max；无障碍特性取并集；高对比由用户/系统决定。
- 用户手动改某项后，该项标记为 `Explicit`，预设不再覆盖；提供“恢复预设默认”。

### 2.3 令牌表（建议值）

| 令牌 | 默认 | 无障碍模式 | 老年模式 | 说明 |
|---|---|---|---|---|
| `FontScaleFactor` | 1.00 | 1.15 | 1.30~1.40 | 再乘系统文本缩放；最终钳 0.92~2.56 |
| `FontSizeXs` | 11 | 12.5 | 14 | 说明文字 |
| `FontSizeSm` | 12.5 | 14 | 16 | 次要文字 |
| `FontSizeBase` | 14 | 16 | 18 | 正文/按钮 |
| `FontSizeMd` | 15.5 | 17.5 | 20 | 强调正文 |
| `FontSizeLg` | 18 | 21 | 24 | 小标题 |
| `FontSizeXl` | 22 | 25 | 28 | 页面标题 |
| `FontSizeH1` | 28 | 32 | 36 | 大标题 |
| `LineHeight` | 1.35 | 1.5 | 1.6 | 行高倍数 |
| `SpacingXs` | 4 | 6 | 8 | |
| `SpacingSm` | 8 | 10 | 12 | |
| `SpacingMd` | 12 | 16 | 20 | |
| `SpacingLg` | 16 | 20 | 28 | |
| `SpacingXl` | 24 | 28 | 36 | |
| `ControlHeight` | 32/36 | 44 | 48 | 按钮/输入/下拉 |
| `MinTargetSize` | 32 | 44 | 48 | 触控/开关 |
| `NavWidth` | 212 | 240 | 264 | 侧栏 |
| `MaxContentWidth` | 1100 | 1040 | 920 | 阅读行长 |
| `FocusRing` | 2 px | 3 px | 3 px | 品牌色 + 2 px 偏移 |
| `MotionDuration` | 160 ms | 0 | 0 | 统一资源 |
| `ToolboxColumns` | 1（当前） | 1 | 1 | 卡片单列；内部横向组改纵向 |

### 2.4 UI 改版（按页面）

| 页面/区域 | 无障碍模式改什么 |
|---|---|
| **主窗/侧栏** | skip link 第一个焦点；导航项高度 +；焦点环；当前页 `AutomationProperties.ItemStatus="当前页"`；侧栏可折叠（不是隐藏） |
| **顶栏** | 返回/设置/提词器按钮名称；窄宽时折叠为“更多”菜单（仍可键盘）；连接徽章状态播报 |
| **首页** | 卡片标题作为可访问名称；摘要作 HelpText；Tab 顺序按视觉；状态/数量用文字 |
| **搜索** | 搜索框 `LabeledBy`；结果数实时区域（Polite）；空结果有文字；结果卡名称含标题/分类 |
| **助手/诊断** | 进度/阶段实时区域；结果卡 `ItemStatus`（严重度）；“停止/重试”可聚焦；错误不自动消失 |
| **搭建/模板** | 流程卡片名称含步骤号/标题；平台 chip 可访问名称；模板卡名称含标题/画布/场景数；应用确认摘要可读 |
| **插件** | 卡片名称含插件名/版本/状态；安装进度实时区域；风险确认可分步；已安装列表 `PositionInSet/SizeOfSet` |
| **工具箱** | 分节导航可键盘；每节标题 `HeadingLevel`；结果列表文字摘要；长页 skip link/回到顶部 |
| **控制台** | 场景/来源列表项名称+状态；音频滑块 `LabeledBy` + 数值；按钮不只用图标 |
| **性能** | Sparkline 文字摘要（平均/峰值/区间）；数据表可展开；刷新状态实时区域 |
| **日志** | 发现项列表 `ItemStatus`；严重度文字；复制/导出按钮名称；长文本可选中 |
| **设置** | 无障碍/老年模式置顶；每个开关有说明；恢复默认；模式预览；分组标题 HeadingLevel |
| **对话框** | `Window.Title`；初始焦点；Esc 取消；危险操作默认取消；错误就地显示；可滚动 |
| **Toast** | 可见关闭按钮；可聚焦；键盘关闭；错误暂停消失；历史面板可键盘打开 |
| **迷你小窗** | 提供“键盘模式”（允许激活/焦点）或等价控制台入口；按钮名称/顺序 |
| **提词器** | 已有名称；补键盘滚动/焦点/退出提示；点击穿透时热键可达 |
| **新手引导** | 步骤标题/描述可读；当前步 `ItemStatus`；按钮焦点；跳过/上一步/下一步名称；减少动画 |

### 2.5 设置页改版

在“外观与无障碍”顶部加一个**模式卡片区**：

```
┌─────────────────────────────────────────────┐
│ 无障碍模式   [开/关]                         │
│ 字号更大、焦点更明显、动效减少、状态可朗读。 │
│ [预览变化] [恢复默认]                        │
├─────────────────────────────────────────────┤
│ 老年模式     [开/关]                         │
│ 更大的字、更宽大的按钮、更简洁的排版。       │
│ [预览变化] [恢复默认]                        │
└─────────────────────────────────────────────┘
```

下面保留现有单项：
- 主题 / 强调色
- 字号档位
- 高对比（说明“系统高对比也会自动生效”）
- 减少动画（说明“系统关闭动画时也会生效”）
- 密度（标准/舒适/宽大）——新模式引入
- 简化布局（开/关）——老年模式默认开
- 视觉提醒（音频提醒的应用内横幅）
- 字幕提示（引导到外部插件/模板）
- 恢复所有无障碍设置

每个开关：
- 有 `AutomationProperties.Name` + `HelpText`；
- 切换后 Toast/实时区域播报“已开启无障碍模式，字号已调整”；
- 不重启、不丢数据；
- 有“为什么/会影响什么”说明。

## 3. 老年模式（Elder Mode）

### 3.1 定义

老年模式是**给不熟悉复杂界面的用户**的预设，不等于“所有老年人都有视力/认知障碍”。它是可选的，不自动按年龄推断。

打开后：

| 维度 | 变化 |
|---|---|
| 字号 | 1.3~1.4×（可再乘系统缩放） |
| 行高 | 1.6 |
| 密度 | 宽大：卡片 20~24 px 内边距，控件 ≥48 DIP |
| 侧栏 | 264 px；导航项更大、可换行；图标更大 |
| 工具箱 | 常用工具置顶；“更多工具”折叠；每卡一个主操作；横向按钮组改纵向；说明文字更大 |
| 表单 | 标签在输入框上方；错误就近；必填标记文字；不用 placeholder 当标签 |
| 向导 | 一步一屏；一个大主按钮；上一步/下一步/取消固定位置；进度文字 |
| 装饰 | 隐藏壁纸/复杂动效；保留高对比选项 |
| 文案 | 更短句、少术语；关键动作配一句“会发生什么” |
| 确认 | 关键/不可逆操作二次确认；不重复弹窗 |
| 焦点 | 始终可见；对话框焦点陷阱；关闭后回到触发按钮 |

### 3.2 工具箱专项

当前 `Views/ToolboxPage.xaml` 是一个很长的 `StackPanel`，内部大量横向 `StackPanel`（按钮并排）和 `WrapPanel`（分节导航）。老年模式建议：

1. **顶部“常用工具”**：搜索问题、一键录制、连接 OBS、开播检查 4 张大卡。
2. **“更多工具”折叠**：默认收起，标题大字 + 说明；展开后按原分节。
3. **每节一张卡**：卡内只保留一个主操作 + 一句说明；次要操作放“更多”菜单/折叠。
4. **横向按钮组 → 纵向**：`Orientation=Horizontal` 的按钮组在老年模式改为 `Vertical`，每个按钮全宽/≥48 DIP。
5. **分节导航**：`WrapPanel` 改为单列列表，按钮 ≥44 DIP；点击后滚动到节标题并把焦点移到标题。
6. **结果列表**：每项标题 + 一句话 + 严重度文字；不要只靠颜色/小图标。
7. **文本输入**：标签在上，输入框更高；数值输入旁边给单位/示例。
8. **滚动**：只有页面级滚动；避免嵌套滚动；长结果可折叠。
9. **回到顶部**：底部固定/可键盘的“回到顶部”。

### 3.3 老年模式不做什么

- 不隐藏高级功能（只折叠，可展开）。
- 不自动开启高对比（用户可选）。
- 不改变用户数据/场景/设置。
- 不缩小功能集；只是降低密度和认知负担。
- 不把文字做成图片（读屏/缩放会失效）。
- 不用“老年=不会用”的文案；用“更宽大/更简洁”的描述。

## 4. 屏幕阅读器方案

### 4.1 名称/帮助/状态

| 属性 | 用途 | 示例 |
|---|---|---|
| `AutomationProperties.Name` | 控件名称 | “安装 Background Removal 1.3.0” |
| `AutomationProperties.HelpText` | 补充说明 | “将下载到 OBS 插件目录，安装前会备份” |
| `AutomationProperties.LabeledBy` | 输入框关联标签 | 搜索框绑定“搜索插件”TextBlock |
| `AutomationProperties.ItemStatus` | 列表项状态 | “已安装 1.2.0 / 可更新到 1.3.0” |
| `AutomationProperties.PositionInSet` / `SizeOfSet` | 列表位置 | “第 3 项，共 12 项” |
| `AutomationProperties.LiveSetting` | 实时区域 | 错误 Assertive；进度 Polite |
| `AutomationProperties.IsRequiredForForm` | 必填 | 推流码/模型选择 |

### 4.2 动态内容

- 所有运行时构造的卡片（问题/诊断/日志/体检/插件/模板/步骤）统一走一个 `AccessibleCard` 附加属性/工厂：
  - `Name` = 标题 + 关键状态；
  - `HelpText` = 摘要/操作提示；
  - `ItemStatus` = 状态/版本/严重度；
  - `LiveSetting` = 仅对“结果出现/更新”的容器使用；
  - 变化时 `RaiseAutomationEvent(LiveRegionChanged)`。
- 不要给每个卡片都设 `Assertive`；错误用 Assertive，进度/信息用 Polite，避免刷屏。
- 列表容器提供 `PositionInSet/SizeOfSet`；自定义 `ItemsControl` 需要 `AutomationPeer` 或 `ItemContainerGenerator` 支持。

### 4.3 焦点管理

- 页面导航后：焦点到页面标题（`Focusable=True` + `AutomationProperties.HeadingLevel=Level1`），并播报标题。
- 对话框：打开时焦点到默认按钮/第一个输入；关闭后回到触发按钮。
- 向导：步骤变化时焦点到步骤标题；进度实时区域播报；不要抢用户正在输入的焦点。
- 错误：焦点到错误摘要（可关闭），不要把焦点扔到页面顶部。
- Skip link：第一个 Tab 停靠点；回车跳到主内容；主内容容器 `Focusable=True` + 名称。
- 自定义鼠标控件：优先改成 `Button`；不能改时 `Focusable=True` + `KeyDown` 空格/回车 + `AutomationPeer`。

### 4.4 自定义控件

- `Sparkline`：`AutomationPeer` 返回 `ControlType.Chart`? WPF 没有 Chart 类型；用 `Image`/`Custom` + Name = “CPU 趋势摘要：最近 60 秒平均 32%，峰值 71%”；提供“查看数据表”。
- 状态药丸：Name = “状态：成功/警告/失败”；不要只画图形。
- 连接徽章：已有 Name/HelpText；补 `ItemStatus`。
- 进度条/环形：Name + `RangeValue`；步骤变化实时区域。
- 自绘图标按钮：Name + HelpText；不要用 ToolTip 代替名称。

### 4.5 对话框/窗口

- 每个 `Window` 设 `Title`；`WindowAutomationPeer` 读 Title。
- `ConfirmDialog` 已做：危险操作默认焦点取消；保留。
- `UpdateDialog`/`PasswordPromptDialog`/`SyncOffsetDialog`/`LaunchConsentDialog` 补：
  - Title；
  - 初始焦点；
  - 错误/进度实时区域；
  - 关闭后焦点返回。
- 迷你小窗：提供“键盘模式”（允许 `ShowActivated=True`/可聚焦）或明确“请用控制台/托盘”的等价路径；不能既不可键盘又无替代。
- 提词器：已有 16 个名称；补键盘滚动/退出提示、焦点顺序、点击穿透时的热键说明。

### 4.6 读屏播报文本规范

- 名称用**动作 + 对象 + 状态**，不要只写“按钮”。
- 避免把完整密钥/哈希读出来；用“已填写，长度 32”。
- 错误播报：一句结论 + 一个动作；详情可展开。
- 进度播报：阶段名 + 百分比/步骤；不要每 100 ms 刷一次。
- 语言切换后重新取文案；不要缓存 `Strings.T(...)` 到静态字段。

## 5. 听障支持

### 5.1 原则

- 任何“只用声音”传达的信息，必须有视觉等价物。
- 任何“只用颜色/闪烁”传达的信息，必须有文字/图标。
- 不自动播放声音；用户可选。

### 5.2 具体改动

| 场景 | 现状 | 改动 |
|---|---|---|
| 麦克风静音/音量过低 | 仅托盘气泡 | 应用内顶部/控制台持久横幅 + 状态区 + 托盘；文字说明“麦克风已静音 10 秒” |
| 录制/推流开始/停止 | Toast/托盘 | Toast + 状态区 + 可回看历史；不要只靠声音 |
| 错误/失败 | Toast/对话框 | 错误不自动消失；可复制；焦点可达 |
| 直播字幕 | 无 | 提供“字幕源”模板/引导：推荐 OBS LocalVocal 等外部插件；说明模型/语言/隐私；不内置 ASR |
| 观众字幕 | 无 | 模板可加“字幕/歌词”文本源；提供安全区/字号/对比建议 |
| 音频提示 | 部分 | 所有音频提示配文字；可选声音开关 |
| 闪烁 | 无 | 禁止 >3 次/秒闪烁；尊重减少动画；不用闪烁表达状态 |

### 5.3 字幕边界

- 不在 3.3.0 内置语音识别模型（体积/性能/隐私/多语言成本高）。
- 提供：
  - 外部插件（如 LocalVocal）安装/配置引导；
  - OBS 文本源/浏览器源字幕模板；
  - 字幕安全区、字号、对比度、延迟校准建议；
  - 隐私提示（本地模型 vs 云端）。
- 不在未测试的情况下承诺“自动字幕准确率”。

## 6. 运动/视觉/认知支持

### 6.1 运动障碍

- 所有主任务键盘可完成；不要求拖拽/双击/精确点击。
- 目标 ≥44 DIP（老年 48）；控件间距足够。
- 全局热键可改/可关；不与系统快捷键冲突。
- 迷你小窗键盘可达（或等价入口）。
- 提词器支持键盘滚动/位置微调（V3.1.1 已有）。
- 焦点不跳、不抢；对话框可 Esc；不自动关闭。
- 支持 Windows 开关控制/语音控制通过 UIA 名称（名称要与可见文字一致）。

### 6.2 低视力/色觉

- 高对比完整配色：正文/次要/线条/语义色/柔和底/焦点/禁用态。
- 对比度：正文 ≥4.5:1；大字 ≥3:1；焦点/控件边界 ≥3:1。
- 不靠颜色单独传达状态；图标+文字。
- 200% 文本 + 150%/200% DPI 重排；横向滚动兜底；不裁切关键按钮。
- 支持系统放大镜；不做自绘文本图片。
- 装饰性图标可隐藏；功能图标必须有名称。

### 6.3 认知/学习

- 一句一动作；步骤可见；进度可见；可返回。
- 不用术语/缩写；必须用时给解释。
- 错误就近显示；给出下一步。
- 不超时；不自动跳转；不自动播放长动画。
- 老年模式“简化布局”把高级项折叠但可展开。
- 一致的按钮命名；同一动作不要多种叫法。

## 7. 稳定性工程（这是“必须要稳定”的核心）

### 7.1 单一事实源

- `UiProfileCore`（纯逻辑）计算所有有效值；`AppearanceService.Apply()` 只写资源；页面只用 `DynamicResource`。
- 不在页面里硬编码字号/间距/控件高度/颜色；装饰性固定尺寸列白名单并接受审查。
- 模式持久化在 `AppearanceSettings`：`a11yMode`、`elderMode`、`density`、`simplify`、`visualAlerts`、`captionHints`、`focusAlwaysVisible`；缺字段用默认值，损坏回退默认。
- 模式切换只调用一次 `Apply()`；不重建页面、不重启、不丢滚动位置（尽量）。

### 7.2 纯逻辑单测

`UiProfileCore` 输入：

```
AccessibilityMode, ElderMode,
FontScale, HighContrast, ReduceMotion, Density, Simplify,
SystemHighContrast, SystemTextScale, SystemAnimationEnabled
```

输出：

```
EffectiveFontScale, EffectiveDensity, EffectiveHighContrast,
EffectiveMotion, ShowSkipLink, AlwaysShowFocus, MinTargetSize,
NavWidth, MaxContentWidth, ToolboxColumns, SimplifiedLayout,
LiveRegionVerbosity, VisualAlerts, CaptionsHint
```

测试矩阵：
- 默认 / 无障碍 / 老年 / 两者；
- 系统高对比/系统缩放/系统动画；
- 用户显式覆盖；
- 极端值（0.92/2.56、100%/200%）；
- 损坏/缺失设置；
- 模式开关幂等；
- 不产生负尺寸/NaN；
- 优先级符合 §2.2。

### 7.3 布局/渲染测试

- 在 STA 线程构造关键页面（`MainWindow`、`ToolboxPage`、`SettingsPage`、`PluginsPage`、`VirtualLivePage`），应用不同 profile，`Measure`/`Arrange` 到 920×620、1366×768、1920×1080；断言：
  - 关键按钮/标题在可视/可滚动范围内；
  - 无负 ActualWidth/Height；
  - 最小目标尺寸 ≥ 配置；
  - 文本不被裁切（可用 `FormattedText` 估算 + 实际 `TextBlock` 测量）。
- 可选 `RenderTargetBitmap` 截图做人工对比；不做像素级 CI（容易受字体/DPI 影响）。
- 200% 文本 + 150% DPI 手工实测（虚拟机/真机）。

### 7.4 可访问性树测试

- 用 `System.Windows.Automation`（框架程序集，不引 NuGet）或 `AutomationPeer`：
  - 关键页面/控件的 Name/ControlType/IsEnabled/IsKeyboardFocusable；
  - 动态卡片 Name/ItemStatus；
  - 对话框 Title/初始焦点；
  - Toast 关闭按钮可聚焦；
  - Skip link 是第一个 Tab 停靠点。
- CI 可跑 WPF STA 测试；若 CI 无法起桌面，至少跑 `AutomationPeer` 单元测试 + 本机脚本。

### 7.5 静态检查扩展（`scripts/check_accessibility.py`）

在现有 R1~R3 基础上增加：

| 规则 | 检查 |
|---|---|
| R4 | 所有 `Window` 有 `Title`（读屏对话框名） |
| R5 | 可交互自绘元素有 `FocusVisualStyle` 或焦点触发器 |
| R6 | 图片/图标有 `AutomationProperties.Name` 或 `Alt` |
| R7 | 不用固定 `FontSize` 字面量（装饰性白名单） |
| R8 | 有 `TextTrimming` 的文本必须有 ToolTip/HelpText |
| R9 | 主窗存在 skip link（名称/目标） |
| R10 | 错误/进度容器有 `LiveSetting` + `RaiseAutomationEvent` |
| R11 | 输入框有 `LabeledBy`/`Name`，不只用 placeholder |
| R12 | 状态色/语义色对比度计算（读取 Palette 资源，阈值 4.5/3.0） |

> 静态规则只覆盖“能静态判定”的部分；读屏实读、焦点顺序、真实布局仍需人工。

### 7.6 人工测试矩阵

| 维度 | 取值 |
|---|---|
| OS | Windows 10 22H2、Windows 11 当前版；Win7 兼容构建冒烟 |
| DPI | 100% / 150% / 200% |
| 文本大小 | 100% / 150% / 200% |
| 主题 | 浅 / 深 / 跟随系统 / 高对比 |
| 模式 | 默认 / 无障碍 / 老年 / 两者 |
| 读屏 | Narrator、NVDA（最新版） |
| 输入 | 键盘 only、鼠标、触控（如有）、开关控制（可选） |
| 语言 | 中文 / English / 伪本地化（长文案） |
| 动效 | 正常 / 减少动画 / 系统关闭动画 |

### 7.7 读屏手工脚本（每版跑）

1. 启动 → Tab 到 skip link → 回车 → 焦点到主内容 → 读出页面标题。
2. 侧栏逐项 Tab：每一项读出名称 + 当前页状态；回车进入；返回后焦点回到原项。
3. 搜索：输入 → 结果数播报 → 打开结果 → 返回 → 焦点回搜索框/原结果。
4. 诊断/日志：进度播报不刷屏；结果卡读出严重度/标题；错误可聚焦。
5. 工具箱：分节导航可读；结果列表有位置/数量；长页可回到顶部。
6. 插件：安装确认读出名称/版本/来源/风险；进度/失败/回滚播报；关闭后焦点回卡片。
7. Live2D/房间/开播向导：步骤标题/状态播报；失败错误可读；取消/重试可聚焦。
8. 设置：切换无障碍/老年模式，读出“已开启/字号已调整”；不重启；布局变化不丢焦点。
9. Toast：错误出现时播报；Tab 到关闭按钮；回车关闭；历史可打开。
10. 高对比 + 200% 文本：所有关键按钮仍可见/可聚焦；无横向不可达。

### 7.8 性能/稳定性

- 模式切换 <100 ms（资源写入 + 布局）；不阻塞 UI。
- 大字号/宽大布局下滚动流畅；避免每帧重算。
- 不因字体缺失/系统缩放极端值崩溃；所有尺寸 clamp。
- 所有模式都有“恢复默认”；损坏 prefs 回退默认并提示。
- 双 TFM 编译；Win7 上高 DPI/读屏差异如实标注。

## 10. 已知限制与不做

- 没有 NVDA/Narrator 实测前，不能宣称“完全支持屏幕阅读器”；只能写“已做代码级适配 + 静态检查 + 手工脚本，实测结果见文档”。
- WPF 自定义控件/自绘图表无法自动获得完美 UIA；需要 `AutomationPeer` 和人工验证。
- 第三方平台软件（抖音直播伴侣/B 站直播姬）自身的无障碍不在本应用控制范围；我们只能保证本应用和引导文案可访问。
- 内置语音识别/自动字幕不在 3.3.0；只做外部插件引导与模板。
- Win7 的 UIA/高 DPI 行为与 Win10/11 不同；不承诺完全一致。
- 老年模式不是“简化到只剩一个按钮”；它保留全部功能，只降低密度/认知负担。
- 不做“自动按年龄开启老年模式”；由用户选择。
