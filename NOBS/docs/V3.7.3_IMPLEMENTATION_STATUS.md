# V3.7.3 实现状态

> **版本**：`3.7.3` · **基线**：`3.7.2` · **日期**：2026-11-22
> **范围**：适配 OBS Studio 33.0.1（新插件布局 / 便携插件根 / 安装目录探测 / 插件包校验）。
> **发布说明**：[`../RELEASE_NOTES_v3.7.3.md`](../RELEASE_NOTES_v3.7.3.md)

---

## 1. 背景

OBS Studio 33.0.1 的官方 Windows 安装包已把第一方核心模块移到 `core\<module>\<module>.dll`，
并且**不再包含 `obs-plugins` 目录**；第三方插件统一使用
`<插件根>\<插件名>\<插件名>.dll + data\`。旧 `bin\64bit` 与 `obs-plugins\64bit` 布局仍能加载，
但会被插件管理器标记为 Legacy，OBS 34.0 起不再加载。

本版只改「插件 / 安装目录」相关路径与校验，不改 OBS WebSocket 协议、录制 / 推流写操作与设置文件格式。

## 2. 交付内容

| 类别 | 内容 |
|---|---|
| 安装目录探测 | `ObsLaunchCore.InstallRootFromExe` / `IsInstallRoot`：识别 `bin\64bit\obs64.exe`、`core`、`obs-plugins`、`plugins`；不再只认 `obs-plugins` |
| 插件扫描 | 同时展开 OBS 33 `<根>\<插件>` 与 OBS 32 `<根>\<插件>\bin\64bit` |
| 便携模式 | 新增 `<OBS 安装目录>\plugins` 扫描与「便携模式插件目录」来源标签 |
| 本机管理 | OBS 33 插件目录识别为完整单元，卸载 / 迁移时连同 `data\` 一起移动；便携模式插件先迁移再接管 |
| 插件安装 | 接受 OBS 33 顶层 DLL 布局；显式 32 位目录仍拒绝，PE 头继续复核 |
| 文案 | 插件安装小贴士、来源标签、接管错误提示中英同步 |
