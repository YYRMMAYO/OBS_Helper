## 二、免费 AI：双通道 + 内嵌密钥

### 需求

V1.7.0 的免费通道（Pollinations）在国内 13 次询问全部失败，不可用。本次：
- **换用智谱 GLM-4.7-Flash**（国内直连，官方免费档）；
- **保留 Pollinations** 作为国外免 Key 通道，用户自选；
- **两个模式都受同一套本地强限频**（每日 20 次 + 10 秒间隔，共用额度）。

### 实现

1. **通道模型**（`Services/Ai/AiSettingsService.cs`）：`FreeAiProvider { Zhipu, Pollinations }`，持久化 `freeProvider`（默认 zhipu）；端点 / 默认模型随通道切换（zhipu→`glm-4.7-flash`，pollinations→`openai`）。
2. **内嵌密钥**（`Services/Ai/FreeAiKeyProvider.cs` + `scripts/embed_free_ai_key.ps1`）：
   - 真实 Key **绝不进代码仓库**：构建时由脚本加密写入 `Assets/free_ai_key.json`（已 gitignore），随发布打包为内嵌资源；仓库只有脚本没有密钥，克隆仓库的人拿不到 Key；
   - **多重加密**：L1 每次构建随机 salt（密文互不相同）→ L2 PBKDF2-SHA256（20 万次迭代，pepper 拆两段）→ L3 AES-256-CBC + HMAC-SHA256（encrypt-then-MAC，先验 HMAC 再解密，fail-closed）→ L4 明文只在内存、用完清零；
   - 脚本与 C# 端参数严格一致，脚本自带加解密自校验；
   - `csproj` 用 `Condition="Exists(...)"`：文件缺失（开发机 / 未 embed）自动跳过内嵌，免费通道按「未内置」优雅回退本地。
3. **引擎**（`Services/Ai/FreeDiagnosticEngine.cs`）：按通道分流——智谱走 `HostBridge.AiChatWithKeyAsync`（内嵌密钥直接提供，不进机密存储）、Pollinations 走 `HostBridge.AiChatNoAuthAsync`（免 Key）；仍为单轮普通对话（不调工具）。
4. **UI**（`Views/SettingsPage.xaml(.cs)`）：免费面板新增「免费通道」选择（智谱 / Pollinations）；模型名默认随通道；智谱通道密钥未打包时显示警示并自动回退本地。

### 边界说明（诚实声明）

- 内嵌密钥是**混淆级**保护：安装包与源码都在用户手里，有决心的人可逆向提取。真正的防线是：免费档模型 + 应用内本地强限频（20 次/天 + 10 秒间隔）。Key 若被滥用，去智谱开放平台重新生成、重跑 embed 脚本出包即可。
- 加密算法选型：PowerShell 5.1（Windows PowerShell）无 AesGcm，故用 AES-256-CBC + HMAC-SHA256（encrypt-then-MAC），两端（PS5.1 / .NET 10）实现一致，实测互通。

## 三、更新模块：修 bug + 应用内下载 + 用户自选

### 1. 必现 bug（`Services/UpdateService.cs`）

`DownloadReleaseAssetAsync`：文件以 `FileShare.None` 打开且**未释放句柄**就调用 `IsValidPeExecutable`——该校验再次打开同文件必然共享冲突失败 → **每个下载完的安装包都被当成「损坏」删除**，应用内下载「下完就没了」。已修复：先完整写入 → 关闭句柄 → 再校验 PE 头。

**实测**：真实下载 V1.7.0 安装包（50 MB），下载完成后文件保留、校验通过。

### 2. 无反馈问题（`Controls/UpdateDialog.xaml.cs`）

旧版错误信息写在 `GithubProgressPanel`（Collapsed）里，用户看不到任何提示。已修复：`SetGithubStatus` 先展开状态面板再写文字，进度条仅在下载中显示。

### 3. 崩溃路径

- `SettingsPage.OnCheckUpdate`（async void 无 try/catch）→ 补 try/catch + 弹窗异常兜底，任何情况下不再把整个应用带崩；
- `UpdateDialog` 各 async void 处理器统一 try/catch；
- 移除超链接上无用的 `NavigateUri="{x:Static ...}"`（Uri 属性挂字符串，是运行时崩溃向量；点击处理实际用的是常量，绑定本身是死代码）。

### 4. 用户自选下载方式（`Controls/UpdateDialog.xaml(.cs)`）

弹窗内显式两种方式：**「打开蓝奏云下载」**（浏览器）与 **「应用内下载」**（GitHub Release，进度条 + 完成后自动启动安装），另加 **「GitHub Release 页」** 入口（浏览器看发布说明 / 历史版本）。

### 5. 网络健壮性（`Services/UpdateService.cs`）

`CheckAsync` 失败自动重试一次（国内访问 api.github.com 偶发超时/抖动）；`ReleasesPageUrl` 常量新增。

## 五、遗留说明

- Pollinations 通道可用性取决于国际网络；智谱通道依赖发布包内嵌密钥。
- 本地限频（20 次/天 + 10 秒间隔）为双通道共用；若未来需区分通道额度可扩展 `FreeQuotaState` 加 per-provider 维度。
- 蓝奏云链接（`DownloadUrl`）如失效需在 `UpdateService` 更新常量后重新出包。
