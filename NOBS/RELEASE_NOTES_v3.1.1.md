# OBS帮助助手 V3.1.1 发布说明

> **一句话**：提词器补上「手动上下移动」——工具栏按钮、拖动文字、滚轮与键盘都能上下移动，
> 还可以用 `Ctrl + 方向键` 微调提词器窗口的位置；顺手修掉了「自动滚到末尾只剩一片空白」。
> 其余功能、数据格式与升级链路与 V3.1.0 完全一致，可直接增量升级。

- 发布日期：2026-10-18
- 升级方式：应用内「检查更新」增量升级，或从 Release 页重新下载安装包 / 便携包（设置与脚本原样保留）
- 主构建：Windows 10 / 11（.NET 10） · 兼容构建：Windows 7 SP1+（.NET 6 + obs-websocket 4.x）
- 测试：1345 项单元测试全绿（本轮连续 3 轮全量 + 双构建 + 自检 + 静态检查）

## 本次修了什么

### 1. 提词器现在可以手动上下移动（P0）

V3.1.0 的提词器只承诺了「自动滚动 + 滚轮 + 方向键」，实际用起来有两个坑：

- 提词器窗口是**不抢焦点**的置顶窗（`ShowActivated=False`）：刚呼出时焦点还在 OBS 或主窗口上，
  按空格 / 方向键**没有任何反应**，看起来就像「这个提词器不能上下移动」；
- 工具栏里**没有任何上下滚动的按钮**，鼠标停在工具栏上时只能去滚动条区域滚轮，新手很难发现。

V3.1.1 补齐了四条相互独立、互不依赖的上下移动方式：

| 方式 | 怎么用 | 适用场景 |
| --- | --- | --- |
| 工具栏按钮 | 顶栏新增 `⤒`（回到开头）/ `▲`（上移一行）/ `▼`（下移一行） | 鼠标点一下就能动，不依赖键盘焦点 |
| 拖动文字 | 在正文区域按住鼠标上下拖动，内容跟着手指走（像拖动一张纸） | 想快速翻回上一段 / 往前找词 |
| 滚轮 | 鼠标停在正文上滚轮，一格约 72 px | 细调 |
| 键盘 | `↑` / `↓` 一行，`PgUp` / `PgDn` 一屏，`Home` 开头，`End` 末尾，空格暂停 / 继续 | 手已经在键盘上时最快 |

- **点一下正文就会激活提词器窗口**：之后再按空格 / 方向键立即生效，不用先点一下工具栏；
- 拖动文字时会临时暂停自动滚动，松手后继续，不会出现「手和计时器抢滚动位置」的抖动；
- 工具栏的整条背景都可以按住拖动窗口（以前只有左上角「提词器」三个字能拖）。

### 2. 提词器窗口可以用 `Ctrl + 方向键` 上下左右微调（P1）

- `Ctrl + ↑ / ↓ / ← / →`：窗口按 10 px 步长移动（比拖拽更容易对准镜头）；
- 移动范围始终夹在虚拟屏幕内，不会把窗口推到看不见的地方；
- 位置、尺寸在拖动 / 移动后 600 ms 自动保存（以前只在关闭窗口时保存），下次呼出原地恢复。

### 3. 自动滚到末尾不再停在「一片空白」上（P1）

- 以前滚动的上限是 `ScrollableHeight`，会把正文底部 220 px 的留白也滚进来：
  最后一行滑出画面后，屏幕上只剩黑色——看起来像「卡死」或「文字没了」；
- 现在滚动终点按**「最后一行正好停在阅读参考线上」**计算（`TeleprompterCore.ScrollEnd`），
  自动滚动到这里就停，手动也只能滚到这里；
- 同时把脚本末尾多余的空行 / 空格裁掉，避免最后一个「空行」占用滚动终点。

### 4. 其它

- 提示文案更新：`空格暂停 · ↑↓ / PgUp PgDn 滚动 · 拖动文字上下移动 · Ctrl+↑↓ 移动窗口`（中英文同步）；
- 新增 6 项单元测试：滚动终点、拖动位移、窗口移动夹取、脚本末尾空行，覆盖上面所有新数值逻辑；
- 版本号、安装包、增量包与知识库资产全部按 `3.1.1` 出包，升级链路不变。

## 兼容性与数据

- **设置 / 脚本 / 壁纸 / 模板 / 密钥**：格式与 V3.1.0 完全相同，升级不迁移、不丢数据；
- **热键**：`Ctrl+Alt+T` 呼出 / 隐藏、`Ctrl+Alt+P` 播放 / 暂停、`Ctrl+Alt+L` 点击穿透保持不变；
- **OBS 协议**：主构建 obs-websocket 5.x、Win7 兼容构建 4.x，均未改动；
- **更新通道**：正式版只认 `V主.次.修` tag；DEV 测试通道（纯数字 tag）规则不变。

## 已知边界（未变）

- 提词器从**显示器采集**中排除依赖 `WDA_EXCLUDEFROMCAPTURE`（Windows 10 2004+）；
  窗口采集 / 游戏采集天然不包含提词器，Win7 建议窗口采集或第二屏；
- 点击穿透开启后鼠标不再落到提词器上，只能用全局热键 `Ctrl+Alt+L` 关闭；
- `Ctrl + 方向键` 移动窗口需要提词器窗口处于激活状态（点一下正文即可）。
