## 二、功能变更：免费 AI 按通道独立限频

### 2.1 需求

「将智谱模型的每日总限次改为 10 次（强限制），外国 API 接口保留 20 次不变。」

### 2.2 实现

- `Services/Ai/FreeRateLimiter.cs`：
  - 原单一 `MaxFreePerDay = 20` 拆为 `ZhipuMaxPerDay = 10` / `PollinationsMaxPerDay = 20`（`MaxPerDay(provider)` 取值）；
  - `GetInfoAsync` / `TryConsumeAsync` 增加 `FreeAiProvider` 参数，按通道走独立存储键（`obshelper.ai.freequota.zhipu` / `.pollinations`），互不挤占；
  - 10 秒间隔保护（低频保护）保持两通道共用，不扣日额度。
- `Services/Ai/DiagnosticOrchestrator.cs`：`DiagnoseFreeAsync` 按当前选中通道取额/消耗；超额回退文案带通道名与对应上限。
- `Views/SettingsPage.xaml(.cs)`：说明文案更新（智谱 10 次/天、Pollinations 20 次/天）；限额展示按当前通道显示「已用 X / Y 次」。
- `Services/Ai/FreeAiKeyProvider.cs` / `FreeDiagnosticEngine.cs`：文档注释同步（智谱通道 10 次/天）。
- README（仓库根 + NOBS）：免费 AI 章节与包名（1.8.0 → 1.8.1）同步。

### 2.3 强限制语义

10 次为**本地强制**硬上限：每次发起请求前检查日计数（`state.Used >= MaxPerDay` 直接拒绝，失败重试也计数），计数持久化于 `prefs.json`、跨天清零；超过后自动回退本地引擎并说明原因。`prefs.json` 为荣誉制防线（可手改），与既有设计一致。

## 三、安全检查

### 3.1 智谱 API Key 泄露审计（结论：未泄露）

- `Assets/free_ai_key.json` 自引入以来**从未进入任何一次提交**（`git log --all -- NOBS/OBS_Helper.Wpf/Assets/free_ai_key.json` 无记录；`git rev-list --all --objects` 中该路径仅出现于 `scripts/embed_free_ai_key.ps1` 的文件名引用）；
- 用解密出的真实密钥对**全部 git 历史**（`git log --all -p`）与**当前工作区 1032 个文本文件**逐文件匹配：**零命中**；
- 工作区中仅存的密钥载体是 gitignore 的 `OBS_Helper.Wpf/Assets/free_ai_key.json`（加密密文，非明文），`NOBS/.gitignore` 与根 `.gitignore` 均包含忽略规则。

### 3.2 打包加密三遍交叉检查（结论：通过）

| 遍次 | 方式 | 结果 |
| --- | --- | --- |
| 第 1 遍 | 独立 C# 实现（Add-Type，与 embed 脚本/Provider 同参数的 PBKDF2 20 万次 + AES-256-CBC + HMAC-SHA256 encrypt-then-MAC）解密**真实** `free_ai_key.json` | HMAC 校验通过，解密成功；真实密钥 `dc9a…mmkq`（49 字符，智谱 Key 形态） |
| 第 2 遍 | 3 次随机测试密钥「加密 → 解密」端到端往返（每次独立随机 salt/IV） | 3/3 一致；篡改密文 1 字节 → HMAC 拒绝（fail-closed）PASS |
| 第 3 遍 | 参数一致性核对：`scripts/embed_free_ai_key.ps1` ↔ `FreeAiKeyProvider.cs`（pepper 两段拼接、fixedSalt、迭代 200000、密钥 64 字节切分、CBC/PKCS7、HMAC 覆盖 iv‖cipher）+ 真实运行时 `FreeAiKeyProvider.GetKey()` 对发布产物 DLL 的解密比对 | 参数逐项一致；运行时解密值与独立实现一致（见 V1.8.1 验证记录） |

### 3.3 更新模块复核（结论：V1.8.1 就绪）

- `Services/UpdateService.cs` 口径：检查更新读 GitHub **tags**（取可解析版本号最大值，兼容 `V1.8.1`/`v1.8.1`/`1.8.1`）；应用内下载读 **Releases**（取版本号最高且带 `OBS_Helper_Setup_*.exe` 资产的一条）；
