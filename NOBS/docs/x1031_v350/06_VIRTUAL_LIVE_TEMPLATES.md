# 虚拟主播直播间模板：配置补齐与 OBS 落地排版

## 1. 现状问题

- 已有 5 套 `vtuber-*` 模板，但只覆盖杂谈 / 游戏 / 电台 / 纪念回 / 竖屏 / 三件套。
- `vtuber-chat` 的虚拟形象区域 `x=1110..1830` 与聊天框 `x=1430..1860` **重叠 400px**，
  落地后聊天框压在人物身上，必须手工挪。
- 场景只给 `transform`，没有统一的标题 / 信息条 / 底部滚动条区域。
- 缺少歌回、学习陪伴、双人联动、手部机位等真实使用频率高的场景。

## 2. 设计参考（视觉）

参考方向来自常见 VTuber 直播画面结构（非特定作者素材）：

- **三分法**：主视觉区（人物）60–70%，聊天 / 信息 30–40%；
- **安全区**：四周留 40–60px，避免平台 UI 遮挡；
- **信息层级**：标题 > 当前活动 > 聊天 > 关注提示；
- **透明叠加**：边框 / 标题条 / 底栏独立成 `browser_source`，人物画面不被裁切。

> 不直接使用网上下载的图片素材，避免版权与分发问题；全部用 CSS / 几何绘制成
> `RoomOverlayAssets` 内置页面（离线、无远程请求）。

## 3. 模板调整

### 3.1 修正既有

| 模板 | 修改 |
| --- | --- |
| `vtuber-chat` | 人物缩到 760×760 @ (120,220)；聊天框 420×760 @ (1450,260)，不再重叠 |
| `vtuber-game` | 游戏画面 16:9 全屏；人物 420×420 右下；聊天 360×520 右上 |
| `vtuber-radio` | 人物 720×760 左侧；聊天 420×700 右侧；标题条顶部 |
| `vtuber-debut` | 倒计时居中；人物主视觉 900×900；标题安全区内 |
| `vtuber-vertical` | 1080×1920：人物 900×1000；聊天 940×420 底部；顶部标题 |

### 3.2 新增模板

| id | 名称 | 场景 | 用途 |
| --- | --- | --- | --- |
| `vtuber-karaoke` | 虚拟主播 · 歌回 | 唱歌 / 点歌 / 间奏 | 歌词区 + 人物 + 点歌信息 |
| `vtuber-study` | 虚拟主播 · 学习陪伴 | 专注 / 休息 | 番茄钟 + 人物 + 聊天 |
| `vtuber-collab` | 虚拟主播 · 双人联动 | 双人 / 嘉宾特写 | 双画面 + 双名条 |
| `vtuber-handcam` | 虚拟主播 · 手部机位 | 主画面 / 手部特写 | 画中画手部机位 |

### 3.3 模板卡片

- 图标改用 Tabler 几何（不再用 emoji）；
- 卡片显示「场景数 / 来源数 / 画布 / 标签」；
- 新增标签筛选：杂谈 / 游戏 / 歌回 / 学习 / 竖屏 / 三件套。

## 4. 落地验收

- 在 OBS 1080p 画布应用后：人物与聊天框无重叠；
- 所有 source 均在画布内（0 ≤ x, y ≤ 画布尺寸）；
- 浏览器源使用本地 `http://127.0.0.1:<port>/...`，无外网请求；
- 竖屏模板切换后画布为 1080×1920；
- `SceneTemplateCaptureCore` / `RoomOverlayCoreTests` 仍通过。
