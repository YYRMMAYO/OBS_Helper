# RELEASE NOTES — V2.8.2

> 发布日期：2026-08-26
> 主题：安全加固——码率计算器 UI 层数字限制 + 超限明示；故障警示链路审查
> 类型：修复（fix）

## 修复

### 码率计算器输入限制补全（UI 层）
- 问题：工具箱「推流带宽计算器」与「磁盘写入基准」的四个数字输入框
  （上行带宽 / 多路推流路数 / 单路码率 / 计划录像码率）在 UI 层没有任何限制，
  用户可以输入任意大的数字（如 1000 万）。核心层虽有钳制不会崩溃，
  但超限后静默按上限计算、不给任何提示，容易让用户误以为结果就是按自己输入的值算的。
- 修复：双层防护——
  - **第一道（UI）**：四个输入框加 `MaxLength` 长度上限与 `PreviewTextInput`
    数字过滤，只放行数字与小数点，键盘 / 粘贴的非法字符一律拦截；
  - **第二道（逻辑）**：保留并复用核心层 `ClampToInt` 钳制（上行 ≤10000Mbps、
    ≤32 路、单路 ≤100000kbps、磁盘基准码率 ≤1000000kbps），并在结果中追加
    「注意：输入超过上限 X，已按上限计算」明示，杜绝静默截断。

## 审查结论（本版随附的安全 / 故障警示审查）

- **故障警示区代码审查通过**：录制守护（`RecordWatchdogService`）、实时日志尾随预警
  （`LogTailerService` + `LogAlertThrottle`）具备完整防护——同类告警去重、90 秒抑制 +
  每小时限流、心跳重入护栏、只读脱敏、异常静默降级不影响主程序，无安全或可用性问题。
- 对照确认：控制台页端口输入已有同款数字过滤 + 1~65535 范围校验，本次将同等防护补齐到工具箱。
