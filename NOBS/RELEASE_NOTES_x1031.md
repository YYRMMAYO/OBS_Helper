# X1031 发布说明

## 一句话摘要

X 系列首个独立版本：换用极简「OBS helper」应用图标，插件、手机摄像头、虚拟主播模板与小窗控制一并补齐；X 系列从此只检测 GitHub 上的 X 标签，不再与 V 系列混更。

## 新增功能

- **X 系列独立更新通道**：X1031 只检测 GitHub 上 `X` 开头的标签；V3.6.0 之类的 V 标签不会提示给 X 用户。版本号在界面显示为 `X1031`。
- **全新应用图标**：黑色圆角底 + 白色 `OBS` 字标 + `helper` 小字 + 青绿重叠弧线；任务栏、窗口、托盘、安装包统一使用新图标。
- **插件广场 GitHub 加速引导**：插件页顶部可直接打开 Watt Toolkit（Steam++）官网，并提供「我已开启，重新检测」；失败时告诉用户下一步，而不是只报网络错误。
- **已安装插件列表双源合并**：现在同时显示「本应用管理」与「本机检测」；你自己放进 OBS 的插件也会出现，只读展示、不会被误删。
- **手机摄像头一键媒体服务**：mediamtx 固定 v1.21.3 + SHA-256，可在页面上直接安装；未连接 OBS 也能先启动媒体服务，连接后自动补建「手机摄像头」来源。
- **虚拟主播模板扩充到 10 套**：新增歌回、学习陪伴、双人联动、手部机位；修正杂谈模板人物与聊天框重叠的问题。
- **小窗控制重构**：新增保存回放、场景切换、麦克风 / 桌面音频静音、提词器、工作室模式与主窗口入口；失败原因直接显示在小窗状态行。
- **手机远程改提词稿**：手机「提词」页新增编辑框与「保存到电脑」；旧稿自动备份最近 5 份。
- **指引文档重写**：新增「5 分钟上手」，补充插件加速、手机摄像头、虚拟主播模板与手机改稿步骤；中英同步。

## 修复的问题

- 以前「已安装」只读本应用清单，用户用 OBS 自己装的插件完全不可见，页面还显示「还没有插件」；现在两个来源合并展示，并标注来源。
- 以前手机摄像头在未安装 mediamtx 时按钮不可用，且未连接 OBS 会直接启动失败；现在可一键安装，启动与 OBS 连接解耦。
- 以前虚拟主播「杂谈」模板人物区域与聊天框重叠约 400px；现在左右分区，落地即可用。
- 以前小窗只有录制 / 推流 / 虚拟摄像头三个按钮；现在全屏游戏时也能切场景、静音、存回放。
- 以前手机只能播放 / 暂停提词器，改一句话也要回电脑；现在手机可直接改稿并同步。

## 兼容性与升级

- 安装目录、程序集名、数据目录（`%LocalAppData%\OBS_Helper`）均未改变，可覆盖升级。
- 设置、场景模板、提词稿、手机配对记录保留。
- 增量包：X1031 为 X 系列首版，**不提供增量包**（与 V 系列版本号不连续），请使用完整安装包或便携包。
- 系统要求：Windows 10 / 11；Win7 兼容构建仍可运行，但手机 Wi-Fi 摄像头不支持 Win7。

## 已知边界

- X1031 不包含全局背景 UI 重构、手机连接页重排与功能中心体验优化；这些在 V3.5.0 中交付。
- 手机摄像头仍需用户在手机上安装支持 SRT / RTMP 的推流 App；浏览器在局域网 HTTP 下不能直接调用摄像头。
- 虚拟主播模板的 OBS 落地以 JSON 校验与坐标断言为准，未逐套做真机截图验收。
- 插件加速器是第三方工具，本应用不捆绑、不自动安装。

## 下载与校验

- 安装包：`OBS_Helper_Setup_1031.0.0.exe`
- 便携包：`OBS_Helper_Portable_1031.0.0.zip`
- Win7 兼容包：`OBS_Helper_Setup_1031.0.0_win7.exe`
- 资产 SHA-256 由 CI 在 Release 正文末尾自动追加，也可用 `SHA256SUMS.txt` 校验。
