## 三、必须人工测试（自动化覆盖不到）

1. **真实 OBS**：Live2D 采集（NDI / Spout2 / VTS 虚拟摄像头 / 窗口采集）、场景落地、布局位置。
2. **真实 VTube Studio**：API 开启、首次授权、模型目录、模型加载冷却。
3. **真实平台直推**：B 站 / YouTube / Twitch / Kick 等（需要账号与推流码）。
4. **虚拟摄像头路径**：抖音直播伴侣 / B 站直播姬的摄像头选择。
5. **插件安装**：真实 Release 资产的下载 / 安装 / 更新 / 卸载 / 回滚；未签名包；OBS 运行中拒绝。
6. **无障碍**：NVDA / Narrator 朗读、仅键盘、150% / 200% DPI、200% 文本、高对比、老年模式不裁切。
7. **Win7 兼容构建**：安装包能装、自检能过、开播页明确降级、不崩溃。
