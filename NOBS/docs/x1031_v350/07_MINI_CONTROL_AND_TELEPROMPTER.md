# 小窗控制重构与手机提词稿编辑

## 1. 小窗控制（MiniControlWindow）

### 1.1 现状

344px 宽、三个按钮（录制 / 推流 / 虚拟摄像头）+ 一行指标。新功能（场景、音频、重播、提词器、
工作室模式）都只能回主窗口，全屏游戏时体验断裂。

### 1.2 新信息架构

```
┌────────────────────────────────────────────┐
│ ● OBS Helper   [已连接]              — ✕  │
├────────────────────────────────────────────┤
│ [● 录制] [▶ 推流] [◉ 虚拟摄像头] [⤓ 重播] │
├────────────────────────────────────────────┤
│ 场景  ‹ 当前场景 ›   [切换 ▾]              │
│ 音频  🎙 麦克风 [静音]  🔊 桌面 [静音]     │
├────────────────────────────────────────────┤
│ 01:23:45 · 剩余 42 分钟 · 丢帧 0.2%        │
├────────────────────────────────────────────┤
│ [提词器] [工作室] [主窗口] [收起]          │
└────────────────────────────────────────────┘
```

### 1.3 交互

- 标题栏可拖拽；`✕` 只隐藏。
- 新增强调色：录制中红色、推流中蓝色、虚拟摄像头绿色。
- 「场景」下拉：来自 `AppServices.Obs.Scenes`，切换即时生效；无场景时禁用。
- 「音频」：取前两个音频输入（麦克风 / 桌面），按钮显示静音状态；没有音频时隐藏。
- 「重播」：`SaveReplayBufferAsync`，仅在缓冲区激活时可用。
- 「提词器」：打开/关闭提词器窗口（`TeleprompterService`）。
- 「工作室」：`ToggleStudioModeAsync`。
- 「主窗口」：`AppServices.Shell.ShowMainWindow()`。
- 失败：状态行显示中文原因，不弹主窗口 Toast。

### 1.4 技术约束

- 不新增常驻计时器：指标计时器只在「可见 + 录制/推流中」运行（沿用现有逻辑）。
- 状态刷新由现有 `RefreshState()` 统一驱动，新增控件全部在同一个方法里更新。
- 窗口高度可增长，最大不超过屏幕工作区 80%。

## 2. 手机提词稿编辑

### 2.1 协议

新增命令：

```json
{ "command": "teleprompter.set", "params": { "text": "新的提词稿…" } }
```

- 最低角色：`operator`；
- 不依赖 OBS 在线（与其它 `teleprompter.*` 一致）；
- 校验：非空、≤ 20,000 字符、去控制字符（保留换行 / 制表符）；
- 成功后调用 `TeleprompterService.SetScript`（内部原子写文件），并触发状态推送。

### 2.2 手机页面

在「提词」面板内新增：

- `<textarea id="pScript">` 多行编辑框（等宽字体、自动高度 30vh）；
- 「保存到电脑」按钮；
- 「从电脑刷新」按钮（重新 `state.get`）；
- 未保存更改提示 / 保存成功 toast；
- 只读角色（viewer）禁用编辑。

### 2.3 电脑端

`TeleprompterService` 已有脚本文件与窗口刷新事件；新增 `SetScript` 时：
1. 备份旧稿到 `teleprompter/backup-<时间>.txt`（保留最近 5 份）；
2. 原子写入；
3. 触发 `Changed` 事件，提词器窗口与手机快照同时刷新。

### 2.4 验收

- 手机改稿 → 电脑提词器 1 秒内显示新内容；
- 空稿 / 超长稿被拒绝并给出中文提示；
- 旧稿可在 `teleprompter/` 下找回；
- 手机断网重连后内容仍是电脑端最新稿。
