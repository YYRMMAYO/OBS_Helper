## 二、真实 bug 修复

**日志版本行解析失败**（`Services/Obs/ObsLogAnalyzer.cs`）：

- 原 `ReVersion` 正则只匹配 `OBS Studio X.Y.Z`，但 OBS 日志实际打印 `OBS 30.0.0 (64-bit, windows)`（不带 "Studio"），导致日志分析页的「环境概况」中版本与平台**永远解析为空**；
- 修复：把 `Studio` 改为可选段 `OBS(?:\s+Studio)?\s+...`，兼容两种写法；新增单测覆盖两种格式。

## 三、功能变更

### 3.1 单元测试工程（新增）

- 路径 `NOBS/OBS_Helper.Wpf.Tests/`，xUnit 2.9.2 + Microsoft.NET.Test.Sdk 17.12.0；
- 沿用旧版的「链接源文件」模式（`Compile Include + Link`），不引用 WPF 工程，规避 RID / UseWPF / SDK 冲突，测试运行在普通 net10.0 上；
- 覆盖：ObsAuth（鉴权协议）、LogSanitizer（脱敏）、ObsLogAnalyzer（规则+阈值+摘要）、MarkdownRenderer（XSS 安全）、UpdateService（版本解析）、ObsReconnectPolicy（退避）、DiagnosticSeverityMapper（严重度映射）；
- 结果：76 通过 / 0 失败。

### 3.2 CallBatch 批量请求（连接层）

- `ObsWebSocketClient.CallBatchAsync`：新增 Request Batch 能力，子请求按 id 回填到原顺序（并行执行下服务端可能乱序返回）；
- 抽出 `AwaitResponseAsync`（超时/取消语义复用）与 `ParseRequestResponse`（单条与批量共用解析）；
- `ObsConnectionService`：`RefreshAudioInputsAsync` 由 2N 次往返 → 1 次 CallBatch；`RefreshOutputsAsync` 由 3 次往返 → 1 次 CallBatch。

### 3.3 日志分析器新规则

| 规则码 | 严重度 | 内容 |
|---|---|---|
| LOG-GPU-HYBRID | Warning | 检测集成显卡渲染（Intel UHD/HD/Iris、AMD Radeon(TM) Graphics） |
| LOG-AUDIO-SAMPLERATE | Warning | 音频采样率不匹配（建议统一 48kHz） |
| LOG-STREAMKEY-LEAK | Warning | 日志中出现串流密钥（隐私提醒） |
| LOG-CRASH-MODULE | Critical | 崩溃报告定位肇事模块 |

### 3.4 单实例清理防误杀

- `App.xaml.cs` 新增 `IsOwnExecutable`：主模块路径与当前安装目录一致（或文件名恰为 `OBS_Helper.exe`）才清理；读不到主模块时宁可不清理也不误杀。

### 3.5 质量门禁

- csproj 加 `<AnalysisLevel>latest</AnalysisLevel>`；新增根 `.editorconfig`；构建 0 警告 0 错误。
