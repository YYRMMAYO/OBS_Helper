# OBS帮助助手 V3.4.0 发布说明

发布日期：2026-10-31 · 基线：V3.3.0（`c22c37f`）

版本主题：**手机联动**——把手机变成第二块屏幕、第二台摄像机、第二支麦克风；并补齐弹幕、字幕、复盘、切片、转推、硬件与团队协作能力。

## 功能中心（新增）
- 左侧导航新增「功能中心」与「手机联动」一级入口，手机联动作为主推模块置顶。
- 功能中心分为「本版新增」与「常用功能」两段：不仅收纳 V3.4.0 的 46 项能力，也收纳 V3.3.0 及更早的开播/录制、虚拟直播/插件、诊断/工具箱、外观/系统。
- 首页新增手机联动主推卡（扫码遥控 / 手机当摄像头 / 手机监看）与「查看全部新功能」。

## 新增

### 手机联动（M01~M12）
- 扫码配对（一次性 secret、120 秒 TTL、token 只存 SHA-256）、viewer/operator/admin 三种角色、命令白名单、限流、设备撤销。
- 手机遥控：场景切换、元素显隐、静音/音量、录制/回放/虚拟摄像头/演播室、提词器播放/速度/字号/镜像。
- 手机监看：480p JPEG 1~5 fps、Tally、录制/推流计时；页面隐藏即停。
- 补光/色卡/倒计时独立离线页；文件快传（50 MB、JPEG/PNG/MP4 魔数校验，用户确认后才进 OBS）。
- Wi-Fi 摄像头：mediamtx + SRT/RTMP + 回环 RTSP → OBS 媒体源，多机位布局/切换；音频随流与同步偏移。
- USB 引导：scrcpy / OBS Camera / Iriun 检测与步骤（不自动安装）。
- 多手机只读监看（最多 3 会话）、远程嘉宾房间/权限/踢人/录制同意。
- 手机通知/剪贴板上屏：仅 Android + ADB、每次显式授权、验证码/密码/卡号默认拦截、不持久化。

### 弹幕 / 互动 / 字幕
- B 站公开协议与 Twitch 匿名 IRC 只读聚合；去重/限流/断线重连；overlay（CSP、textContent、50 条上限）。
- 敏感词/刷屏预警与 CSV 导出；TTS 队列（SAPI）。
- 点歌/投票/抽奖/问答、礼物触发场景、投稿审核、直播日历、AI 回复建议（仅建议）。
- 本地实时字幕（WASAPI → VAD → whisper.cpp sidecar）、双语字幕（离线短语表）、弹幕翻译开关、语音控制（唤醒词+白名单+破坏性确认）。

### 智能 / 画质 / 分发 / 生态
- 复盘报告、封面候选、推流健康、构图检查、开播预案、事故回放。
- 高光切片/竖屏导出、转写检索、AI 导播建议、安全哨兵、音频链（降噪/压缩/增益+旁路）、多平台转推、rclone 归档。
- MIDI/脚踏板、WLED 灯光、观众看板、插件签名校验、装修市场应用/回滚、团队协作、AI 搭档（TTS+VTS 口型+AI 标注）。

## 安全与边界
- 所有局域网能力默认关闭；只绑私网、随机端口、私网来源校验、限流、可撤销、不做 UPnP/端口映射/自动防火墙规则。
- 手机不直连 OBS；不存在任意 OBS 请求透传。
- 主程序零 NuGet；重能力走外部进程；sidecar 未核验 SHA-256 前不自动下载。
- 远程嘉宾浏览器推流需要 HTTPS（安全上下文），本项目不内置证书：房间/权限已实现，媒体链路需自备 HTTPS/SFU（已记录 BLOCKED）。
