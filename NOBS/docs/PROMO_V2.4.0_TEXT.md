## 版本定位

**OBS 排障助手（OBS Helper）V2.4.0** —— Windows 原生 WPF 版「**数据生态扩充**」。

纯离线可用、隐私优先、零第三方依赖；本次更新聚焦两件事：

- **插件知识库 38 → 46 个条目（v1.1 → v1.2）**：新增「**工具 / 排障**」分类，收录本软件的官方 OBS 停靠面板插件 **OBS 排障助手（Dock 版）**；另新增 7 个精选，仓库全部逐一验证可达；
- **问题知识库 112 → 120 条（v1.6 → v1.7）**：覆盖 OBS 32.2 插件加载变更、Nahimic/RTSS 干扰、多显示器刷新率卡顿、Steam 版插件目录、启动缓慢二分定位、Device removed/GPU 挂起、通信活动降音量、码率不足马赛克等八篇排障指引。

V2.2 / V2.3 功能底座保持不变：插件目录外置热更新、本机插件体检（只读）、日志 × 插件嫌疑联动一键跳转、直达 Releases 下载（24h 缓存节流）、AI 插件性能预算提示、竖屏 / 多平台搭建向导、模板推荐插件标注、关注插件启动查新、界面纯文字设计语言、本机体检全盘定位，以及 V2.1 的增量更新 / 知识库独立更新 / 安装包自动清理。

## 这一版有什么新东西

### 1. 插件广场收录「OBS 排障助手（Dock 版）」🧩

*（图：插件广场 —— Dock 版作为「工具/排障」分类首条置顶展示）*

> **重大变化**：本软件的官方 OBS 插件版本已上线，**直播中出问题直接打开 OBS 里的 Dock 面板就能排查，不用切窗口。**

- **官方 OBS 停靠面板插件**，C++ / Qt6 原生、零运行时依赖，以停靠面板嵌入 OBS 主窗口；
- 提供「体检 / 日志分析 / 设置体检 / 系统信息」四大页签，**本地离线对齐官方 Log Analyzer 规则集**；
- 日志分析发现「元凶插件」时一键改名 `.disabled`，重启即验证；
- 仓库与 Releases 已逐一验证可达：`[YYRMMAYO/OBS_Helper_Plugin](https://github.com/YYRMMAYO/OBS_Helper_Plugin)`
- 详细宣传与英文版见 `PRNOBS/PROMO.md`（同仓库并入，详见文末「**桌面版 ↔ 插件版协同**」一节）

### 2. 插件知识库扩充：38 → 46 个（v1.2）

除 Dock 版外另新增 7 个精选条目（全部经 GitHub API 验证可达、非归档）：


| 分类       | 新增插件                  | 解决什么                     |
| -------- | --------------------- | ------------------------ |
| 音频       | **Win Capture Audio** | 按应用捕获游戏声音                |
| 音频       | **Dynamic Delay**     | 动态延迟补偿                   |
| 自动化      | **Scene Notes Dock**  | 每场景独立备注板                 |
| 自动化      | **Face Tracker**      | 人脸自动追踪                   |
| 自动化      | **PTZ Controls**      | PTZ 云台摄像机控制              |
| 多平台 / 竖屏 | **RTSP Server**       | OBS 输出变 RTSP 服务器，局域网拉流监看 |
| 输入 / 互动  | **Zoom to Mouse**     | Lua 脚本，显示器捕获跟随鼠标缩放聚焦     |


> 老版本（V2.2+）用户无需升级应用，启动即可静默获取新目录。

### 3. 问题知识库扩充：112 → 120 条（v1.7）

*（图：搜索问题 —— 120 条问题库 + 10 大分类 + 多平台标签）*

新增八篇排障指引，覆盖近期高频缺口主题：

- **崩溃 / 兼容性**：更新 OBS 后第三方插件加载失败（OBS 32.2 DLL 加载变更 + macOS Apple Silicon 迁移）；Nahimic / RivaTuner(RTSS) / Overwolf 等环境组件干扰；启动缓慢的安全模式对比 + 二分定位法
- **编码 / 性能**：推流中 Device removed / GPU 挂起（超频归零 → 减负 → 驱动重装）
- **卡顿 / 网络**：多显示器刷新率不一致的周期性掉帧；码率不足导致的马赛克画质（含丢帧率区分网络抖动与参数问题的判据）
- **基础配置**：Steam 版 OBS 的真实安装目录定位与用户级插件安装
- **音频**：开麦后游戏音量自动变小（Windows「通信活动」根治步骤）

> 知识库走分离热更新通道，启动静默/设置页/更新弹窗三入口；老版本用户不升级应用也能拿到新内容。

## 完整的桌面版能力（一张图速览）

### 🩺 智能诊断：免费的本地诊断助手

*（图：智能诊断 —— 免费 AI（内置）+ 8 项快速自检清单 + 日志分析入口）*

- **当前引擎**：「免费 AI（内置）」—— 本地诊断助手，按清单与日志逐项排查；
- **快速自检清单** 8 项：管理员身份运行、硬件编码、码率 ≤ 75% 上行带宽、捕获方式正确（双显卡统一 GPU）、48kHz 采样率统一、关闭 Chrome/Discord 硬件加速、有线网络推流、串流密钥正确；
- 文字输入「症状描述」即可让助手给出排查步骤与跳转入口；
- 连上本机 OBS 后**实时检查运行状态**，联动下方系统监控与日志分析。

### 📊 系统监控：每秒采样的实时曲线

*（图：系统监控 —— CPU/内存/网络/磁盘实时折线 + OBS 状态接入）*

- **CPU / 内存 / 网络上下行 / 磁盘剩余** 四项近 2 分钟实时折线，每秒采样；
- **OBS 运行状态**：连上本机 OBS 后自动接入，显示渲染 FPS、丢帧率、编码帧率与 OBS 报告的性能数据；
- 联动 AI 插件性能预算：空闲内存 < 500MB 或 CPU ≥ 80% 时给出个性化预警；
- 「前往智能诊断 →」 一键跳转。

### 🚀 直播搭建：6 步流程 + 进阶向导

*（图：直播搭建 —— 6 步流程 + 进阶向导（竖屏/多平台））*

- **6 步流程** 引导新手从 0 到开播：准备与权限 → 场景与来源 → 音频校对 → 推流设置 → 开播自检 → 多平台/竖屏；
- **进阶向导** 两条分步窗口（V2.2 起）：**双屏 9:16 双画布**（基于 Aitum Vertical 实测流程）、**多平台同时推流**（基于 Aitum Multistream，含带宽预算）；
- 步骤内按钮**直达对应知识库条目与插件广场卡片**。

### ⚙️ 设置：自动检测 OBS 目录 + 知识库独立更新

*（图：设置 —— 自动检测 OBS 配置目录 + 知识库版本/独立更新 + 备份/导入/导出）*

- **自动检测** OBS 配置目录（`%APPDATA%\obs-studio`），支持备份 / 导入 / 导出 / 重置；
- **场景模板** 一键管理；
- **关于区** 直接显示应用版本、问题库版本、问题库更新日期，并提供「检查更新」「检查知识库更新」按钮；
- **知识库独立更新**：说明本地覆盖文件 + 内嵌兜底 + 远程双通道（GitHub raw 主通道 + Release 资产兜底）的分离热更新机制，密钥全程在本机加密存储与请求时回传。

## 桌面版 ↔ 插件版协同

> 同一团队、两条产品线，**共享知识库数据、定位互补**。


| 维度       | 🖥 桌面版（WPF）                                                 | 🧩 插件版（Dock）                                                                          |
| -------- | ----------------------------------------------------------- | ------------------------------------------------------------------------------------- |
| **载体**   | 独立 Windows 应用                                               | 嵌入 OBS 主窗口的停靠面板                                                                       |
| **技术栈**  | C# / WPF / .NET 10（自包含）                                     | C++ / Qt6（复用 OBS 运行时）                                                                 |
| **依赖**   | 零 NuGet / 零 WebView2                                        | 零运行时依赖                                                                                |
| **核心场景** | 详细阅读 / 搜索 / 配置管理 / 模板落地                                     | **直播中**快速体检 / 日志分析 / 系统信息                                                             |
| **知识库**  | 120 条问题 + 46 插件                                             | 离线对齐 Log Analyzer 规则集                                                                 |
| **写操作**  | 备份导出可选                                                      | **只读**（唯一写操作：用户主动「一键禁用」元凶插件）                                                          |
| **安装**   | 安装包 / 便携包 / 增量包                                             | `OBS_Helper_Dock_Setup_v*.exe` 双击安装 → 重启 OBS                                          |
| **下载**   | [Releases](https://github.com/YYRMMAYO/OBS_Helper/releases) | [Plugin Releases](https://github.com/YYRMMAYO/OBS_Helper_Plugin/releases)             |
| **宣传文档** | 本文档                                                         | `[PRNOBS/PROMO.md](https://github.com/YYRMMAYO/OBS_Helper/blob/main/PRNOBS/PROMO.md)` |


**推荐组合**：

- **桌面版** 装在主控机上（用来搜索、阅读、配置、模板落地）；
- **插件版** 装在直播机上（OBS 开着就能查，不用切窗口）；
- 两者共享同一份问题知识库（GitHub 双通道热更新），直播中遇到问题在 Dock 面板快速定位，复杂排查回到桌面版深度阅读。

## 历史底座：V2.1 / V2.2 / V2.3 关键能力回顾

> 没有这些底座，V2.4.0 的「数据生态扩充」就无从谈起——以下能力全部保留并继续打磨。

- **V2.1.x**：增量更新（自上一版本以来**仅下载变更文件**，SHA-256 逐文件校验，失败自动回退完整安装包）、知识库分离更新（应用内更新弹窗「仅更新知识库」+ 启动静默 + 设置页三入口）、安装包自动清理（按 `OBS_Helper_*` 命名严格识别，绝不触碰其它文件）
- **V2.2.0**：插件广场升级为「全链路」——本机已装插件体检（只读）、直达 Releases 下载（GitHub API + 24h 双层缓存 + 在途请求合并）、AI 插件性能预算提示、关注插件启动查新；日志分析 × 插件嫌疑联动（提取肇事 DLL 名，命中广场条目直接跳转）；竖屏/多平台搭建向导；场景模板推荐插件标注（`requiresPlugins` 字段）
- **V2.3.0**：本机插件体检**全盘定位**（手动指定 → 运行中进程 → 注册表 HKLM/HKCU 双视图 → 全盘固定驱动器常见布局 + Steam 全库扫描，覆盖 D/E 盘等非系统盘）；界面风格统一（**全面去 emoji**，纯文字 + 品牌色徽标）
