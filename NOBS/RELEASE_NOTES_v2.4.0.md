# OBS 排障助手 V2.4.0 发布说明

> 发布主题：**数据生态扩充** —— 插件广场收录 OBS 排障助手 Dock 版 ·
> 插件目录扩充到 46 个（v1.2）· 问题库扩充到 120 条（v1.7）· 知识库热更新直达老版本

## 新增内容

### 1. 插件广场新增「工具 / 排障」分类，收录 OBS 排障助手 Dock 版
- **OBS 排障助手（Dock 版）**：本软件的官方 OBS 停靠面板插件
  （C++ / Qt6 原生、零运行时依赖），以停靠面板嵌入 OBS 主窗口，
  提供「体检 / 日志分析 / 设置体检 / 系统信息」四大页签；
  本地离线对齐官方 Log Analyzer 规则集，支持「元凶插件」一键禁用，
  与桌面端形成互补——直播中出问题直接在 OBS 里查，不用切窗口。
- 仓库与 Releases 已逐一验证可达：
  <https://github.com/YYRMMAYO/OBS_Helper_Plugin>

### 2. 插件知识库扩充：38 → 46 个条目（v1.1 → v1.2）
除 Dock 版外另新增 7 个精选条目（全部经 GitHub API 验证仓库可达、非归档状态）：
- **音频**：Win Capture Audio（按应用捕获游戏声音）、Dynamic Delay（动态延迟补偿）；
- **自动化**：Scene Notes Dock（每场景独立备注板）、Face Tracker（人脸自动追踪）、
  PTZ Controls（PTZ 云台摄像机控制）;
- **多平台 / 竖屏**：RTSP Server（OBS 输出变 RTSP 服务器，局域网拉流监看）；
- **输入 / 互动**：Zoom to Mouse（Lua 脚本，显示器捕获跟随鼠标缩放聚焦）。

知识库走分离热更新通道：**老版本（V2.2+）用户无需升级应用即可收到新目录。**

### 3. 问题知识库扩充：112 → 120 条（v1.6 → v1.7）
新增八篇排障指引，覆盖近期高频缺口主题：
- **崩溃 / 兼容性**：更新 OBS 后第三方插件加载失败（含 32.2 DLL 加载变更与
  macOS Apple Silicon 迁移）；Nahimic / RivaTuner(RTSS) / Overwolf 等
  环境组件干扰；启动缓慢的安全模式对比 + 二分定位法；
- **编码 / 性能**：推流中 Device removed / GPU 挂起（超频归零 → 减负 → 驱动重装）；
- **卡顿 / 网络**：多显示器刷新率不一致的周期性掉帧；码率不足导致的马赛克画质
  （含丢帧率区分网络抖动与参数问题的判据）；
- **基础配置**：Steam 版 OBS 的真实安装目录定位与用户级插件安装；
- **音频**：开麦后游戏音量自动变小（Windows「通信活动」根治步骤）。

## 改进
- 插件广场目录 note 字段同步说明 Lua 脚本类条目 `dlls` 可为空数组，
  「本地插件体检」匹配逻辑不受影响。

## 质量保障
- 全部新增插件仓库逐一通过 GitHub API 可达性校验（含归档状态过滤），
  无重复 id、无未知分类；
- 新增问题条目 id 无重复、related 引用全部指向已存在条目；
- 单元测试全部通过；JSON 结构经两遍交叉检验（构建期解析 + 独立脚本复核）。

## 升级说明
- 2.2.x / 2.3.x 用户可在应用内直接增量更新；也可从 Release 页下载完整
  安装包 / 便携包。
- 插件目录 v1.2 与问题库 v1.7 均支持独立热更新：老版本用户启动后会静默获取，
  无需升级应用本体。
