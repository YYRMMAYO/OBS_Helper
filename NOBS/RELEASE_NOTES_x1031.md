# X1031Y2 发布说明

## 一句话摘要

X1031Y2 在 **X1031** 的基础上同步 **V3.5.2 及此前全部内容**（X 系列专属应用图标除外），并把插件广场与开源依赖中心真正做成「应用内一键配置」：插件卡片 / 粘贴仓库可以直接拉取最新 Release，开源依赖也能在应用内下载、校验、解压并自动接入；本机检测到的插件新增卸载、迁移与接管管理；问题库精简到 208 条并补齐分类；同时做了一轮安全加固。

> 内部版本：`1031.2.0`；标签：`X1031Y2`。X 更新检查只认 `X*` 标签，`X1031Y2 > X1031`。

## 新增功能

- **插件卡片「一键配置」**：在应用内查询最新 Release、挑 Windows x64 包、下载、SHA-256 校验（有摘要时）、解压安装；保留「下载页」作为手动渠道。
- **粘贴仓库直拉**：`owner/repo` 或完整 GitHub 地址粘贴后按回车 / 点「一键配置」即可安装，不必先去浏览器下载再回来。
- **下载前网络确认**：自动拉取前提示先打开 Watt Toolkit（Steam++）的 GitHub 加速，或确认网络可用；失败时重新露出加速引导。
- **开源依赖一键配置**：FFmpeg / rclone / whisper / MediaMTX 都可以在应用内查最新 Release、下载、校验、安全解压、定位 exe 并写入依赖目录；仍保留「选择已下载文件」「下载页」「仓库」三条手动路径。
- **本机插件管理**：本机检测到的插件不再只读——
  - **卸载**：整目录移入 `%LocalAppData%\OBS_Helper\plugins\local-backups`，不硬删；
  - **迁移**：用户级 ⇄ 全局级，或 OBS 安装目录 → 用户级；
  - **接管管理**：只登记、不移动文件，之后可更新 / 回滚 / 卸载；
  - **打开文件夹**：直接定位插件目录。
- **问题库精简与更新**：212 → 208 条，版本 2.2 → 2.3；删除 9 条重复 / 低价值条目，新增插件一键配置、依赖配置、录制状态不同步、录制文件被占用、本机插件迁移 / 卸载 5 条；补齐 `sources` / `performance` / `virtualcam` / `encoder` 4 个分类。

## 同步 V3.5.2 与前序内容

- 录制 / 直播状态可信度修复：停止录制后电脑端与手机端不再一直显示「录制中 / 直播中」；手机状态灯区分直播与录制；批量状态查询改用 obs-websocket 5.x 的 `RequestBatch`（op 8 / 9）。
- 毛玻璃、字体自定义、启动动画与点击反馈、手机连接页重排、功能中心等前序 UI 内容全部包含。
- **唯一例外**：X 系列继续使用 X 专属应用图标，不切换为 V 系列图标。

## 安全加固

- `installed.json` 的卸载 / 回滚增加已知插件根校验，防止被篡改的清单把任意目录当成插件目录移走。
- 插件与依赖下载只接受 HTTPS + GitHub 官方资产域；重定向后的最终域名同样校验。
- GitHub 提供 `sha256:` 摘要时强制匹配；依赖下载限制 512 MB，解压限制 2 GB / 20000 条目。
- sidecar 与增量包解压增加条目数 / 解压总量上限，保留 zip-slip 与符号链接拒绝。

## 修复的问题

- 以前插件卡片只有「下载」，用户仍要去浏览器找安装包；现在卡片直接「一键配置」。
- 以前开源依赖中心只有 mediamtx 能自动装；现在 FFmpeg / rclone / whisper / MediaMTX 都能在应用内拉取。
- 以前本机检测到的插件只能看，页面还写着「不会卸载或改动」；现在可以卸载、迁移、接管管理。
- 以前问题库有 4 个分类只被条目引用、未在分类表声明，首页会落到「其他」；现在分类表补齐到 14 个。

## 兼容性与升级

- 安装目录、程序集名、数据目录（`%LocalAppData%\OBS_Helper`）均未改变，可覆盖升级。
- 设置、场景模板、提词稿、手机配对记录、壁纸库、已安装插件清单全部保留。
- 系统要求不变：Windows 10 / 11；Win7 兼容构建仍可运行，但依赖一键配置与手机 Wi-Fi 摄像头不建议在 Win7 使用。
- 增量包：X1031 → X1031Y2 版本连续（`1031.0.0` → `1031.2.0`），可按 CI 的基准资产生成增量包；若基准资产不可得则使用完整安装包。

## 已知边界

- 扁平布局插件（DLL 直接放在插件根）不能整目录迁移或接管，只能卸载单个 DLL；建议卸载后用「一键配置」重装成新布局。
- 依赖一键配置读取 GitHub 最新 Release；上游没有 Windows 成品包时会提示改用「下载页」。
- GitHub 未提供摘要的旧资产仍可下载，但结果会标记「未校验 SHA-256」。
- 全局级迁移 / 卸载需要管理员权限，应用不会自动提权。
- 安装包与便携包仍未做 Authenticode 代码签名。

## 下载与校验

- 安装包：`OBS_Helper_Setup_1031.2.0.exe`
- 便携包：`OBS_Helper_Portable_1031.2.0.zip`
- Win7 兼容包：`OBS_Helper_Setup_1031.2.0_win7.exe`
- 资产 SHA-256 由 CI 在 Release 正文末尾自动追加，也可用 `SHA256SUMS.txt` 校验。

# X1031 发布说明

## 一句话摘要

X 系列首个独立版本（本次为重置版）：换用极简「OBS helper」应用图标，插件、手机摄像头、虚拟主播模板与小窗控制一并补齐；更新检测明确为「X + 日期码」，同一天再版用 Y1 / Y2 / Y3 递增，并且更新弹窗会直接展示 GitHub Release 的更新说明。

## 新增功能

- **X 系列独立更新通道**：X1031 只检测 GitHub 上 `X` 开头的标签；V3.6.0 之类的 V 标签不会提示给 X 用户。
- **X 版本号规则**：`X` 后面的四位是日期 `MMdd`（`X1031` = 10 月 31 日）；同一天再次发版追加 `Y1`、`Y2`、`Y3`…（如 `X1031Y2`）。更新检测先比日期，日期相同再比 Y 序号。
- **更新说明直显**：X 系列检测到新版本后，更新弹窗会从 GitHub Release 拉取本版更新说明并直接展示；拉取失败不影响检查与下载。
- **全新应用图标**：黑色圆角底 + 白色 `OBS` 字标 + `helper` 小字 + 青绿重叠弧线；任务栏、窗口、托盘、安装包统一使用新图标。
- **插件广场 GitHub 加速引导**：插件页顶部可直接打开 Watt Toolkit（Steam++）官网，并提供「我已开启，重新检测」；失败时告诉用户下一步，而不是只报网络错误。
- **已安装插件列表双源合并**：现在同时显示「本应用管理」与「本机检测」；你自己放进 OBS 的插件也会出现，只读展示、不会被误删。
- **手机摄像头一键媒体服务**：mediamtx 固定 v1.21.3 + SHA-256，可在页面上直接安装；未连接 OBS 也能先启动媒体服务，连接后自动补建「手机摄像头」来源。
- **虚拟主播模板扩充到 10 套**：新增歌回、学习陪伴、双人联动、手部机位；修正杂谈模板人物与聊天框重叠的问题。
- **小窗控制重构**：新增保存回放、场景切换、麦克风 / 桌面音频静音、提词器、工作室模式与主窗口入口；失败原因直接显示在小窗状态行。
- **手机远程改提词稿**：手机「提词」页新增编辑框与「保存到电脑」；旧稿自动备份最近 5 份。
- **指引文档重写**：新增「5 分钟上手」，补充插件加速、手机摄像头、虚拟主播模板与手机改稿步骤；中英同步。

## 修复的问题

- 以前「已安装」只读本应用清单，用户用 OBS 自己装的插件完全不可见，页面还显示「还没有插件」；现在两个来源合并展示，并标注来源。
- 以前手机摄像头在未安装 mediamtx 时按钮不可用，且未连接 OBS 会直接启动失败；现在可一键安装，启动与 OBS 连接解耦。
- 以前虚拟主播「杂谈」模板人物区域与聊天框重叠约 400px；现在左右分区，落地即可用。
- 以前小窗只有录制 / 推流 / 虚拟摄像头三个按钮；现在全屏游戏时也能切场景、静音、存回放。
- 以前手机只能播放 / 暂停提词器，改一句话也要回电脑；现在手机可直接改稿并同步。
- 以前 X 系列的版本比较只认日期码，同一天再版无法区分先后；现在按「日期 → Y 序号」两级比较，`X1031Y2` 会正确识别为高于 `X1031`，`Y10` 也高于 `Y2`。
- 以前更新提示里的版本号一律带 `V` 前缀，X 版本会显示成 `V1031`；现在按系列显示为 `X1031` / `X1031Y2`，V 系列仍显示为 `v3.5.0`。

## 兼容性与升级

- 安装目录、程序集名、数据目录（`%LocalAppData%\OBS_Helper`）均未改变，可覆盖升级。
- 本次 X1031 为重置版：tag `X1031` 指向修正后的提交，安装包 / 便携包文件名仍为 `1031.0.0`，可直接覆盖上一份 X1031。
- 设置、场景模板、提词稿、手机配对记录保留。
- 增量包：X1031 为 X 系列首版，**不提供增量包**（与 V 系列版本号不连续），请使用完整安装包或便携包。
- 同日再版（`X1031Y1`、`X1031Y2`…）会使用 `1031.1.0`、`1031.2.0` 等内部版本出包，更新说明仍归档在 `RELEASE_NOTES_x1031.md`。
- 系统要求：Windows 10 / 11；Win7 兼容构建仍可运行，但手机 Wi-Fi 摄像头不支持 Win7。

## 已知边界

- X1031 不包含全局背景 UI 重构、手机连接页重排与功能中心体验优化；这些在 V3.5.0 中交付。
- 手机摄像头仍需用户在手机上安装支持 SRT / RTMP 的推流 App；浏览器在局域网 HTTP 下不能直接调用摄像头。
- 虚拟主播模板的 OBS 落地以 JSON 校验与坐标断言为准，未逐套做真机截图验收。
- 插件加速器是第三方工具，本应用不捆绑、不自动安装。

- 安装包：`OBS_Helper_Setup_1031.0.0.exe`
- 便携包：`OBS_Helper_Portable_1031.0.0.zip`
- Win7 兼容包：`OBS_Helper_Setup_1031.0.0_win7.exe`
- 资产 SHA-256 由 CI 在 Release 正文末尾自动追加，也可用 `SHA256SUMS.txt` 校验。
