# V3.7.2 发布说明

## 一句话摘要

V3.7.2 是 **UI 视图更新版**：黑夜模式显示 **A · 导播台**（机柜黑、信号青、圆角面板、图标导航、tally 与时间码），白天模式显示 **C · 排版手册**（纸白、信号蓝、发丝线分节、编号目录、37 px 细体大标题）。两套皮肤共用同一路由与页面逻辑，切换不丢焦点、不重连 OBS、不影响录制/推流。全量 **1902 项单元测试**、**37 项无界面自检**、**50 张双皮肤截图自检**通过。

## 新增与改进

### 1. 双主题皮肤（A · 导播台 / C · 排版手册）

- **解析规则**：不新增「皮肤」开关。`主题=黑夜 → A`、`主题=白天 → C`、`跟随系统` 由系统明暗决定；不会出现第四种组合。
- **A · 导播台**：`#0B0D10` 机柜黑、信号青 `#38E0C0`、4–8 px 圆角、填充卡片、图标导航、顶部 `OFF AIR / ON AIR` tally + 时间码、等宽读数。
- **C · 排版手册**：`#FCFCFA` 纸白、信号蓝 `#1F3BFF`、直角按钮、透明卡片 + 仅上边发丝线、`01–16` 编号目录、37 px/300 细体页标题、黑色主操作按钮。
- **运行时切换**：只替换资源令牌，不重建页面；焦点、滚动位置、输入内容、OBS 连接与录制/推流状态全部保留。

### 2. 导航与标题

- 左侧导航收敛为同一份路由数据：A 渲染「图标 + 文字」，C 渲染「编号 + 文字」，编号跨分组连续（01–16）。
- C 的编号读屏名称为「第 01 项，首页」，当前项带「当前页」状态；编号不是快捷键。
- 设置页左栏同样支持编号目录（01–13）。
- 页标题：A 17 px/600；C 37 px/300，并在标题前显示当前页目录序号。

### 3. 组件形态随皮肤切换

- 卡片：A 填充 + 全边细线 + 轻投影；C 透明 + 上边发丝线、无投影。
- 按钮：A 信号青实心 / 深色底描边；C 墨黑实心 / 白底黑框，全部直角。
- 状态药丸：A 圆角填充；C 直角描边；仍保持「图标 + 文字 + 颜色」三重编码。
- 分段选择（主题 / 字号 / 语言）：A 信号青选中；C 墨黑底白字选中。
- 输入框 / 下拉框：交互边界改为 `LineStrong`（A `#6B768C` / C `#111`），满足非文本对比 3:1。

### 4. 设置页与强调色

- 外观页新增「界面风格」说明，实时显示当前是「黑夜 · 导播台」还是「白天 · 排版手册」。
- 强调色默认跟随皮肤（A 信号青 / C 信号蓝）；点选色板后固定为用户选择，并提供「恢复主题默认强调色」。
- C 下圆角固定为直角：圆角下拉框禁用并给出说明，避免「改了没效果」。

### 5. 自定义背景与壁纸

- 默认关闭（`bgMode=default`），两套皮肤使用各自底色。
- 用户开启纯色背景时：C 保持原色；A 自动压暗（88% 机柜黑 + 12% 用户色），避免浅色正文不可读，同时不出现「黑顶栏接灰底」的突兀色阶。
- 顶栏与导航始终使用不透明皮肤表面，壁纸只出现在内容区，标题不会再被壁纸冲掉。
- 图片壁纸的铺放、压暗、模糊、轮播、减少动画行为保持不变。

### 6. 无障碍

- 换肤后通过实时区域播报「已切换到黑夜/白天模式」，只播报这一句，不重读整页。
- 高对比优先于皮肤：A/C 都按高对比色板覆盖文字、背景、边框与状态色。
- 焦点环 2 px + 偏移；编号目录、当前页、连接徽章、Toast 的读屏语义保持。
- 新增 11 项皮肤解析 / WCAG 对比度单测（正文 4.5:1、交互边界 3:1、高对比 7:1）。
- **未验证**：NVDA / Narrator 实测、UIA 自动化、真机 150%/200% DPI；发布说明不宣称「已支持屏幕阅读器」。

### 7. 首页手册式重排

- 参照排版手册设计板重排首页：顶部实时数据条（时钟 / 连接 / 录制 / 推流 / FPS / CPU）、`01 / 手机联动` 大字号 hero + 手机联动侧栏、`02 / 简单录像` 与 `STREAM / 简单开播` 并排、`03 / 导播计时器` 大号读数、`04 / 欢迎使用`、`05 / 问题分类` 与 `06 / 我的收藏`。
- 分节用编号 + 发丝线组织，不再用一张大卡片套所有入口；卡片内部重复标题已移除。
- 右侧「手机联动」面板整块可点、可键盘进入；二维码仍在「手机联动」页生成，首页不创建临时配对会话。
- 数据条是真实数据：连接 / 录制 / 推流 / FPS / CPU 来自 OBS，计时读数来自计时器设置；离开首页即停表。

### 8. 截图自检能力

- 新增 `OBS_SHOT=1`：应用内逐页渲染 A/C 两套皮肤截图，输出到 `%LocalAppData%\OBS_Helper\shots`，并写入 `shot-progress.log` / `shots.txt`。
- 覆盖 23 条路由 × 2 套皮肤 + 设置外观屏 + 自定义背景对照屏，共 50 张。
- `OBS_SHOT_LIMIT=<n>` 可只跑前 n 条路由，便于快速冒烟。

## 修复的问题

### 1. 设计板与现有主题脱节

- **以前**：只有「浅色 / 深色」两套配色，布局、圆角、导航、标题完全一样，无法体现 A/C 两种排版语言。
- **现在**：皮肤决定卡片/按钮/导航/标题/签名元素的形态，黑夜与白天是两套可辨识的视觉语言。

### 2. 自定义浅色背景让黑夜模式白字消失

- **以前**：用户把纯色背景设为浅色时，夜间顶栏与正文仍用浅色文字，直接不可读。
- **现在**：顶栏/导航使用不透明皮肤表面；A 下自定义纯色背景自动压暗。

### 3. 设置子导航编号显示 `00`

- **以前**：设置页复用主导航模板后没有写序号，C 皮肤下所有设置项显示 `00`。
- **现在**：设置子导航按目录顺序写入 `01–13`。

### 4. 自定义背景在深色顶栏上方透出浅色亮边

- **以前**：顶栏的背景写在带 `Padding` 的内层，13/24 px 的 padding 区域仍透明；开启自定义浅色背景时，深色顶栏上方会透出一圈浅色亮边。
- **现在**：背景铺到顶栏最外层 `Border`，`Padding` 只作用于标题与按钮 —— 深色、浅色与图片背景模式下都不再有亮边。

### 5. 截图自检的白边与选中态偏差

- **以前**（本轮开发中）：截图渲染窗口含非客户区，底部出现白边；C 的分段选择沿用品牌蓝。
- **现在**：渲染窗口根内容；C 的分段选择改为墨黑底白字。

## 兼容性

- 设置文件兼容 V3.7.1：`theme / accent / bgMode / fontScale / highContrast / reduceMotion` 等字段不变；新增 `accentCustom`，缺省为「跟随皮肤」。
- 旧用户升级后：`黑夜 → A`、`白天 → C`；自定义壁纸与强调色文件/设置不删除。
- OBS WebSocket 协议、录制/推流参数与写操作语义不变。
- 主构建（Windows 10/11，.NET 10）与 Win7 兼容构建（.NET 6）共用同一份源码。

## 升级建议

- 想体验导播台风格：主题选「黑夜」。
- 想体验排版手册风格：主题选「白天」。
- 跟随系统时，Windows 深色 → A，浅色 → C。
- 如果觉得 A 下自定义背景被压暗：这是为了正文可读性；可在「外观 → 背景」里改回默认底，或切到 C 保持原色。

## 已知边界

1. 本轮采用「统一视觉树 + 皮肤令牌/模板」，未做技术方案中的「每页双 XAML」；理由与后续计划见 `docs/V3.7.2_UI_DESIGN_GUIDE.md` §10。
2. 两套皮肤的眼动/读屏实测、真机高 DPI 复核尚未完成。
3. 迷你小窗、计时窗、提词器只跟随皮肤语义色，未做两套结构。
4. C 的 37 px 标题在中文环境会回退到 YaHei Regular，字重可能比设计板略粗。
