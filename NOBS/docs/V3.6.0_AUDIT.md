## 5. 不可行项与替代方案

| 项目 | 不可行原因 | V3.6.0 的处理 |
|---|---|---|
| Authenticode 代码签名 | 需要开发者本人的代码签名证书与私钥，仓库内没有，无法代生成 | 保留 `build.ps1 -SignPfxPath`；发布说明继续如实写「未签名」；不伪报已签名 |
| 真 LLM 回复 / AI 搭档 | 需要用户 API Key、计费、提示词与内容安全；离线不可用 | 保留本地模板 / 规则；文案标「模板 / 规则」；不写成「已接入 LLM」 |
| 在线主题市场 | 需要服务端、作者体系、审核与分发 | 保留本地 JSON 主题包导入；不写「在线市场」 |
| 联机团队协作 | 需要账号、服务端、权限与实时同步 | 保留本地角色/邀请演练；标「本地」 |
| 手机浏览器直接当摄像头 | `getUserMedia` 需要可信 HTTPS 安全上下文，局域网 HTTP 不可用 | 保留 Larix / OBS Camera 推流 + 二维码；不承诺浏览器直采 |
| Twitch / YouTube 自动观众统计 | 需要 OAuth、平台 API 配额与审核 | 保留 B 站公开人气 + 手动回填；不伪造其他平台数据 |
| 完整繁体中文 / 日语 | 文案表 3500+ 键，需逐条翻译与校对；本版无合格译者与验收能力 | 不新增半成品语言；保留 `LanguageRegistry` 扩展点与回退提示 |
