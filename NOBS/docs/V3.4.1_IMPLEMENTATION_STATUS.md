# V3.4.1 实现与验收状态（2026-10-31）

基线 `aaaf619`（V3.4.0）。

## 已实现并通过自动验证

- **手机页空白修复**：词表改为显式 `{ key: [zh, en] }` 注入；新增单测回读注入 JSON 与词表逐项比对；页面启动校验词表，异常时显示可读提示。
- **刷新恢复**：配对 token 持久化（localStorage → sessionStorage → 内存回退）；刷新自动重连；无凭据显示重新扫码提示；401 清理 token；页面与电脑端均显示版本号。
- **跨品牌兼容**：旧内核 `closest` / `NodeList.forEach` 兜底；ES5 看门狗在脚本解析失败或缺少 `fetch`/`Promise`/`WebSocket` 时显示提示；安全区 `constant()`、`-webkit-sticky`、`aspect-ratio` 降级。
- **手机页重做**：浅色 / 深色 / 跟随系统，深色底色 `#1a1e24`；17px 正文；360px 起自适应；44–52px 触控目标；推流开始/停止、提词上移/下移、只读禁用、连接中占位。
- **停止输出误报**：`StopRecordAsync` / `StopStreamAsync` 幂等化 —— 已停止时先核对，失败后刷新输出状态，确认已停止即按成功处理（OBS 501 竞态）。
- **手机错误映射**：区分未连接 / OBS 拒绝（附原始说明）/ 执行异常；提词器不再依赖 OBS 在线。
- **托盘崩溃**：所有气泡走 `ShowBalloon` 安全封装，空正文回退标题，异常仅记日志。
- **开源依赖中心**：插件页新增 FFmpeg / rclone / whisper.cpp / MediaMTX，一键直达官方 GitHub Releases；一键配置支持本机有界查找、路径持久化、MediaMTX 复制进 sidecar 目录。
- **功能中心登记**：新增 `deps` 模块（路由 `plugins`），中英文案齐备。
