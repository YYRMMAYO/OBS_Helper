# V3.7.0 发布说明

## 一句话摘要

V3.7.0 把 V3.6.0 明确列入 V3.7 待办的 **16 项可落地能力全部补齐**：计时器 CSV / 首页恢复卡 / 设置页分区 / 托盘状态，控制台场景搜索、日志筛选、错误码查知识库、连接诊断向导，托盘菜单自定义、热键一键恢复、安全模式、插件查询指数退避，以及首屏同步 IO 清理。全量 **1870 项单元测试**与 **37 项无界面自检**通过。

## 新增功能

### 1. 计时器补全

- **CSV 导出**：计时记录除 TSV 外可一键复制 CSV，Excel 直接打开；字段含序号、开始时间、模式、计划、实际、超时。
- **首页上次计时卡**：显示上次模式、计划时长与记录数，一键进入计时页。
- **设置页计时器分区**：默认时长、显示小时、捕获排除、OBS 自动开始/停止、超时提示音集中配置；可一键恢复计时器默认热键。
- **托盘计时状态**：托盘菜单顶部显示「计时器：05:12（运行中）」；点击回到计时页。
- **关闭行为**：应用退出时主动释放计时器（隐藏计时窗、停止叠加服务、保存设置与记录）；主窗关闭到托盘时计时窗保持。

### 2. 控制台与日志

- **场景 / 来源搜索**：控制台新增搜索框，同时过滤场景列表与当前场景来源；清空即恢复。
- **日志筛选**：「错误及以上 / 警告及以上」+ 关键字（标题 / 证据 / 建议 / 问题 id），只影响展示。
- **错误码查知识库**：首页数据加载错误旁新增「查解决办法」，把错误码带入搜索页。
- **连接诊断向导**：连接失败时展开三步排查（WebSocket 开关与端口、密码、防火墙），并可复制 `netstat` 端口检查命令。
- **录制命名预览**：V3.6.0 已有，本版复核模板变量、非法字符与实时示例均正常。

### 3. 托盘、热键与安全模式

- **托盘菜单自定义**：小窗控制、提词器、回放缓存/存片、录制打点四项可分别显隐。
- **热键一键恢复**：热键卡新增「恢复默认键位」，覆盖录制/推流/虚拟摄像头/存片/打点/小窗/提词器/计时器全部默认值，并立即重新注册。
- **安全模式启动**：连续 2 次未正常退出后，下一次启动自动禁用壁纸与动画并提示；正常退出会清零计数。设置页可重新开启壁纸/动画。
- **应用内更新日志**：设置 → 关于新增「查看本版更新」，直达当前 Release 页。
- **最近录制健康检查移出 UI 线程**：`File.Exists` 放到后台，列表内容未变时不重复检查。

### 4. 插件查询稳定性

- **并发上限 2**：GitHub Release 查询从全串行改为最多 2 个并发，缩短插件广场角标等待。
- **指数退避**：连续失败按 10s → 20s → 40s … 封顶 5 分钟冷却；成功后立即清除失败记忆。
- **冷却角标**：处于冷却期的插件卡片显示「查询冷却中」，不再只有空白。

## 修复的问题

### 1. V3.6.0 待办遗漏

- **以前**：V3.6.0 发布说明明确列出「插件查询批量退避、首屏同步 IO、安全模式、热键重设、应用内更新日志、N 系列其余补强」未完成。
- **现在**：除不可行项外，本轮把可落地的 16 项全部补齐；审计与实现状态见 [`V3.7.0_AUDIT.md`](docs/V3.7.0_AUDIT.md) 与 [`V3.7.0_IMPLEMENTATION_STATUS.md`](docs/V3.7.0_IMPLEMENTATION_STATUS.md)。

### 2. 计时器首次热键与关闭残留

- **以前**：`Ctrl+Alt+H` 必须先访问计时页才能创建窗口；应用退出时计时器服务没有显式释放。
- **现在**：窗口工厂在 `AppServices.TimerClock` 初始化时就位；`App.OnExit` 调用 `TimerClockOrNull()?.Dispose()`，隐藏窗口并停止叠加服务。

### 3. 控制台与日志的查找成本

- **以前**：场景/来源多时要逐行找；日志报告只能从头读；连接失败只有一行原因。
- **现在**：场景/来源可搜索、日志可按严重度与关键字筛选、连接失败给出可执行三步。

## 兼容性与升级

- 版本号：`3.6.0` → `3.7.0`，可覆盖升级，无需卸载旧版。
- 安装目录、程序集名、数据目录（`%LocalAppData%\OBS_Helper`）不变；设置、记录、书签、模板、提词稿、手机配对、壁纸库、插件清单全部保留。
- 新增数据键：`app.crashStreak`（安全模式计数）、`obshelper.shell` 下四个托盘显示开关；删除或改回默认即可恢复。
- 热键默认值不变；新增「恢复默认键位」按钮。热键冲突仍会显示具体失败原因。
- 系统要求不变：Windows 10 / 11；Win7 兼容构建仍可运行，但安全模式/托盘/计时器等不改变 Win7 边界。

## 已知边界

- **仍不可行的 6 项**：Authenticode 代码签名（无证书）、真 LLM 回复/搭档（需 API Key、计费与内容安全）、在线主题市场（需服务端）、联机团队协作（需账号/服务端）、手机浏览器直接当摄像头（需可信 HTTPS）、Twitch/YouTube 自动观众统计（需 OAuth/配额）。这些不写成「已支持」。
- **安全模式是启发式**：只按「未正常退出次数」判断，不分析具体崩溃原因；进入后只关闭壁纸与动画，不重置用户设置。
- **插件查询仍受 GitHub 匿名限额**：并发 2 与指数退避降低压力，但 60 次/小时/IP 的硬限额仍可能触发；冷却期角标只提示，不阻塞手动下载。
- **计时器叠加层只绑回环**：不提供局域网/公网访问；手机远程需先配对。
- **未做 Authenticode 签名**：SmartScreen 仍可能提示未知发布者。
- **无障碍**：本版新增控件均有可访问名称与键盘路径，但仍未用 NVDA / Narrator 实测；详见 [`ACCESSIBILITY.md`](../ACCESSIBILITY.md)。
