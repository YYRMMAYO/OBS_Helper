## 二、抖音 OBS 推流现状与内容修正

### 核实结论（检索日 2026-08，多来源交叉）

1. 抖音官方 PC 直播唯一合法推流工具是**抖音直播伴侣**；网页开播的「OBS 推流」入口与推流码获取流程已下线（`zhibo.douyin.com` 域名已不存在，`douyin.com/zhibo` 为 JS 空壳页）。
2. 收紧时间线：2020–2022 逐步收紧第三方推流；2024 年后社区只剩「从直播伴侣抓推流码喂给 OBS」的灰色路径（违反平台规则，有封号风险）。
3. 合法替代方案：**直播伴侣 + OBS 虚拟摄像头 / NDI**（OBS 画面转发给直播伴侣采集），或直接用直播伴侣内置采集。

## 三、迷你小窗功能（新增）

### 功能

- 置顶小窗，一键开始 / 停止「录制 / 推流 / 虚拟摄像头」，按钮状态随 OBS 实时刷新，未连接时禁用。
- 整窗可拖拽；位置记忆到 `prefs.json`（`obshelper.mini`），多屏按保存点所在屏夹取。
- 入口：托盘菜单「小窗控制（录制 / 推流）」+ 全局热键（默认 `Ctrl+Alt+M`，设置页可改键 / 停用）。
- 点击 ✕ / Alt+F4 只隐藏不销毁，再次呼出立即可用；应用退出时安全释放。

### 代码审查发现与修复（全部已修）

| # | 位置 | 问题 | 严重度 | 修复 |
| --- | --- | --- | --- | --- |
| 1 | `MiniControlWindow.xaml.cs` 隐藏路径 | 点 ✕ / Alt+F4 隐藏绕过 `SavePosition`，「记住位置」只在托盘 / 热键切换或退出时生效 | 中（功能一致性） | 新增 `UserHide` 钩子，由服务注入 `SavePosition`，覆盖全部隐藏路径 |
| 2 | `MiniWindowService.RestorePosition` | 用 `SystemParameters.WorkArea`（仅主屏）夹取，多屏保存的位置会被拉回主屏 | 中（多屏体验） | 改用 `Screen.FromPoint` 按保存点所在屏的工作区夹取 |
| 3 | `MainWindow.xaml.cs` 自检用例 | 自检二次 Toggle 会把测试窗口位置写进用户真实 `prefs.json` | 低 | `SavePosition` 增加 `App.HeadlessTest` 守卫，自检不落盘 |
| 4 | `MiniWindowService.OnObsStateChanged` | 退出途中 Dispatcher 关闭时 `BeginInvoke` 可能抛异常 | 低 | try/catch 静默忽略 |

### 已验证无问题

- 线程模型：托盘（托盘线程）与 `WM_HOTKEY`（UI 线程）都经 `Dispatcher.BeginInvoke` 才调用 `Mini.Toggle()`；Obs `StateChanged` 由服务统一转回 UI 线程刷新按钮，无跨线程 UI 访问。
- 生命周期：单实例惰性窗口；✕ / Alt+F4 取消并隐藏；`Stop()` 先置 `AllowClose` 再 `Close()`；`Closed` 退订 `StateChanged` 并清引用，`_subscribed` 防重复订阅，无泄漏。
- 热键：新 id `0xC105` 唯一，原有 id 不变；旧 `prefs.json` 无 `miniWindow` 键时通过属性初始化器回退默认 `Ctrl+Alt+M`，无需迁移。
- 资源：`GhostButton` / `CaptionText` / `OkBrush` / `WarnBrush` / `SurfaceBrush` / `LineBrush` / `TextBrush` / `FontSizeBase` 均已在主题字典定义；`check_resources.py` 全绿。
