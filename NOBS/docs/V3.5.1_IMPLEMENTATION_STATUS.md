## 4. 已知边界：代码签名

本版**未做 Authenticode 代码签名**。签名需要开发者本人的代码签名证书与私钥（`.pfx` + 密码）；
仓库内没有该证书，本地自签名证书不会被其他机器信任，也不能消除 SmartScreen 的「未知发布者」提示。
拿到证书后可直接重跑：

```powershell
.\build.ps1 -SignPfxPath .\codesign.pfx -SignPfxPassword <密码>
```

## 5. 手机改稿说明

手机端「提词 → 编辑提词稿 → 保存到电脑」发送 `teleprompter.set`。电脑端在
`MobileCommandRouter` 收到后调用 `TeleprompterService.SetScript`：先备份旧稿（最近 5 份），
再原子写 `%LocalAppData%\OBS_Helper\teleprompter\current.txt`，最后通过 `Application.Current.Dispatcher`
刷新已打开的提词器窗口。窗口尚未打开时也会写入文件，下次呼出即为新稿。
