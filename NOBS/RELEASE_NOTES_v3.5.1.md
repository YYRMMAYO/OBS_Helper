# V3.5.1 发布说明

## 一句话摘要

V3.5.1 是一次以「界面图标」和「手机改提词稿」为主的修复版：设置页与功能中心的详情图标改为正确的描边渲染并按标题重新配图；手机端修改提词稿后可以即时同步到电脑上的提词器窗口；设置页与反馈页新增支付宝 / 微信赞助码。

## 修复的问题

- **详情图标只剩一个圆点**：设置页右侧头部与功能中心模块卡此前用 `Fill` 渲染描边几何，圆 / 方框被填成实心色块（语言与地区页只剩一个圆点）；现在统一用 `Stroke` 渲染，与左侧导航保持一致。
- **图标与标题不匹配**：语言用放大镜、外观用模板、录制用星芒、热键用仪表盘、数据用拼图、关于用感叹号气泡……这些复用已经全部换成语义匹配的 Tabler Icons（MIT）：地球、调色板、托盘、摄像机、双向箭头、键盘、芯片、数据库、归档、罗盘、信息圆等。
- **手机远程改提词稿失败**：手机命令在 TcpListener 的线程池线程上执行，却直接操作 WPF 提词器窗口，后台线程访问 UI 会抛异常并被路由吞成「操作失败」。现在 `TeleprompterService` 的所有窗口操作与状态事件都切回 UI Dispatcher；手机保存后电脑提词器立即刷新，即使窗口尚未打开也会写入脚本文件，下次呼出即为新稿。

## 新增功能

- **赞助开发**：设置页「关于」与帮助与反馈页「关于本工具」新增支付宝 / 微信两个独立收款码（从原图中单独裁出，只保留二维码本体），并明确标注：**赞助不会解锁任何特殊功能，也不会改变软件内的任何权限，只是支持软件的正常开发**。二维码随程序集打包，离线可扫，不上传任何信息。

## 兼容性与升级

- 安装目录、程序集名、数据目录（`%LocalAppData%\OBS_Helper`）均未改变，可覆盖升级。
- 设置、场景模板、提词稿、手机配对记录、壁纸库保留。
- 增量包：V3.5.1 与 V3.5.0 的版本号连续，可生成增量包；实际是否生成以 CI 的基准资产为准。
- 系统要求：Windows 10 / 11；Win7 兼容构建仍可运行。
- 更新通道：V 构建只检测 `V*` 标签；X 系列（`X1031` / `X1031Y2`）只检测 `X*` 标签。

## 已知边界

- 安装包与便携包仍未做 Authenticode 代码签名：需要开发者本人的代码签名证书与私钥，当前仓库没有该证书；因此 SmartScreen 仍可能提示「未知发布者」。这不是可以通过本地自签名解决的问题（自签名证书不会被其他机器信任）。
- 手机改稿仍要求手机与电脑在同一局域网，且电脑端「手机联动」服务已开启并完成配对。

## 下载与校验

- 安装包：`OBS_Helper_Setup_3.5.1.exe`
- 便携包：`OBS_Helper_Portable_3.5.1.zip`
- Win7 兼容包：`OBS_Helper_Setup_3.5.1_win7.exe`
- 增量包：`OBS_Helper_Update_3.5.1.zip`（基准资产可得时）
- 资产 SHA-256 由 CI 在 Release 正文末尾自动追加，也可用 `SHA256SUMS.txt` 校验。
