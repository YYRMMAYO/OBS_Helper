# OBS 排障助手 · 安全与代码审查报告

审查日期：2026-08-03
范围：`OBS_Helper.Client`（Blazor WASM）、`OBS_Helper.Win`（WebView2 桌面壳 + Inno 安装包）、
`OBS_Helper.Mac`（Tauri v2 桌面壳）、`content/`、`build.ps1`、CI。

---

## 一、整体结论

应用为**离线、本地优先**工具：UI 与数据（`problems.json`）随包发布，运行时**不发起任何网络请求**。
威胁面很小。本次审查发现 6 项可改进点（无高危漏洞），均已修复并写入 `docs/SECURITY.md`。

---

## 二、审查项与结果

### 已确认安全（无需改动）
- **XSS**：所有文本经 Razor 渲染，Blazor 默认对 `@变量` 做 HTML 转义，不存在注入点。
- **依赖**：仅 `Microsoft.AspNetCore.Components.WebAssembly` 与 `Microsoft.Web.WebView2`，均为官方运行时，无第三方高危库。
- **密钥/隐私**：仓库与代码内无任何 API Key / 密钥 / Token；无遥测、无远程后端。
- **数据完整性**：`problems.json` 为打包内容，非运行时远程拉取，不存在远程篡改入口。

### 发现与修复（6 项）
| # | 位置 | 问题 | 严重度 | 修复 |
| --- | --- | --- | --- | --- |
| 1 | `OBS_Helper.Mac/src-tauri/tauri.conf.json` | `security.csp: null`，未设内容安全策略 | 中 | 配置严格 CSP（仅 `self`/`ipc`，`wasm-unsafe-eval`，`form-action 'none'`，`frame-ancestors 'none'`） |
| 2 | `OBS_Helper.Mac/src-tauri/src/main.rs` | 未限制导航、未关 devtools；多开了无用的 `macos-private-api` 特性 | 中 | 增加导航白名单（`localhost`/`asset:`）；移除 `macos-private-api`；加 `navigation` 特性 |
| 3 | `OBS_Helper.Win/MainForm.cs` | WebView2 未关闭 DevTools / 右键菜单 / WebMessage；外链未拦截 | 中 | 关闭调试相关能力；`NewWindowRequested` 将外链交系统默认浏览器打开 |
| 4 | `OBS_Helper.Client/Pages/ProblemDetail.razor` | 外链未校验协议，理论上可被篡改数据注入 `javascript:`/`data:` | 低 | 新增 `IsSafeUrl`，仅放行 `http/https`；非安全链接渲染为禁用态 |
| 5 | `OBS_Helper.Client/Services/BookmarkService.cs` | `EnsureLoaded` 以 `_bookmarks.Count==0` 判断，已清空收藏时会重复读取并覆盖内存状态，造成“收藏丢失”错觉；`catch {}` 吞异常无注释 | 低 | 改用 `_loaded` 标志；`catch (Exception)` 并注释说明静默降级 |
| 6 | `MainLayout` / 搜索 / 助手输入框 | 缺少无障碍语义（landmark 角色、skip-link、input label、焦点轮廓） | 低（可访问性） | 补 `<header>/<main>/<nav>` 角色 + `aria-label`、skip-link、`.visually-hidden` 标签、`type="search"`、全局 `:focus-visible` |

### 构建/打包缺陷（顺带修复）
- `OBS_Helper.Win/OBS_Helper_Setup.iss` 中 `LicenseFile` 与额外 LICENSE 源路径写成 `..\..\LICENSE`，
  相对 `OBS_Helper.Win` 实际解析到 `F:\`，导致 Inno 构建失败。已修正为 `..\LICENSE`。
- `build.ps1` 便携包步骤使用 `Compress-Archive -Force` 会先触发环境安全删除钩子删除旧包；
  已改为「仅当旧包存在才删除」再打包，避免对不存在文件删除导致的失败关闭。

## 三、UI 结构优化（本次一并完成）

1. **语义化结构**：`MainLayout` 使用 `role="banner"`/`content`/`navigation` 与 `<main id="main-content" tabindex="-1">`，新增跳转链接。
2. **表单可访问性**：搜索 / 助手输入框加 `id` + 视觉隐藏 `<label>` + `type="search"`。
3. **控件关联**：`ProblemDetail` 步骤复选框 `<label for>` 与 `<input id>` 关联，编号加 `aria-hidden`。
4. **键盘可见焦点**：全局 `:focus-visible` 轮廓；导航按钮加 `aria-label`。
5. 代码层面未破坏既有组件复用结构（`ProblemCard` 仍被 5 个页面共用）。

---

## 四、残余风险与建议（非本次阻断项）

- **Windows 安装包 / exe 未代码签名**：CI 未签名，首次运行可能触发 SmartScreen。建议后续用 Authenticode 证书在 CI 签名。
- **macOS 包未签名 / 公证**：当前为未签名包，需用户在「隐私与安全性」手动允许。`build-mac.sh` 已增加通过环境变量
  `MAC_SIGN_IDENTITY` / `MAC_NOTARY_KEYCHAIN_PROFILE` 开启 Developer ID 签名 + 公证的能力（不传则仍产出未签名包）。
- **WebView2 远程调试端口**：已关闭 DevTools + WebMessage 收敛；若后续内置固定运行时，建议附加 `--disable-remote-debugging`。
