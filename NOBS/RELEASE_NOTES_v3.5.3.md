# V3.5.3 发布说明

## 一句话摘要

V3.5.3 把 **X 系列 `X1031Y2` / `X1031Y3` 的全部内容同步回 V 系列**（X 系列专属应用图标除外）：插件和开源依赖都能在应用内一键配置，本机插件可以卸载 / 迁移 / 接管；手机摄像头补齐推流二维码、推流检测与防火墙放行；实时字幕的 whisper 与推荐模型也能一键装好。同时修复 GitHub Release 资产重定向导致的插件 / 依赖下载全部失败的问题。

## 新增功能

### 1. 插件广场：应用内一键配置

- 精选插件卡片从「下载页」升级为「一键配置」：应用内查询最新 Release、挑 Windows x64 包、下载、SHA-256 校验（上游提供摘要时）、安全解压并安装。
- 仓库输入框支持直接粘贴 `owner/repo` 或完整 GitHub 地址，按回车 / 点「一键配置」即可拉取，不必先去浏览器下载再回来。
- 自动拉取前先提示打开 Watt Toolkit（Steam++）的 GitHub 加速或确认网络可用；失败时重新露出加速引导与「下载页」手动路径。

### 2. 开源依赖：一键安装并自动接入

- FFmpeg / rclone / whisper.cpp / MediaMTX 都可以在依赖中心查询最新 Release、下载、校验、安全解压、定位 exe，并写入依赖目录。
- 新增依赖准备器（`DependencyProvisioner`）：功能页发现依赖未就绪时，点一次即可完成「下载 → 校验 → 解压 → 写入路径」，已就绪则直接复用，不重复下载。
- 直播互动（字幕 / 切片）、画质与分发（转推 / 归档）等页面在安装完成后自动填入路径，不用再手抄目录。
- 保留「选择已下载文件」「下载页」「仓库」三条手动路径，网络不可用时仍有退路。

### 3. 本机插件管理

- 本机检测到的插件不再只读，支持：
  - **卸载**：一插件一目录整体移入 `%LocalAppData%\OBS_Helper\plugins\local-backups`，不硬删，可手动放回；
  - **迁移**：用户级 ⇄ 全局级，或 OBS 安装目录 → 用户级；
  - **接管管理**：只登记不移动文件，之后可走一键配置更新 / 回滚 / 卸载；
  - **打开文件夹**：直接定位插件目录。
- OBS 运行中一律拒绝卸载；目标已存在、无写权限、扁平布局都会给出明确原因，不再笼统失败。

### 4. 手机摄像头：从「显示地址」到「能用起来」

- **推流二维码**：把 SRT 地址生成二维码，手机扫码即可导入 Larix Broadcaster / OBS Camera。
- **检测手机推流**：查询 MediaMTX 本地 API，页面直接显示「已收到手机推流 / 尚未收到」，不再只能干等。
- **一键放行防火墙**：只对 sidecar 目录内的 `mediamtx.exe` 添加私网入站规则，UAC 提权；失败时给出手动 `netsh` 命令。
- **WebRTC 视频监看**：摄像头链路启用 MediaMTX WebRTC，页面给出视频监看地址与 OBS WHIP 推流地址；OBS 30.2+ 可把节目画面推到 MediaMTX，手机浏览器看到的是视频流而不是截图。
- 手机配对第 6 台设备时，手机端明确显示「最多 5 台设备，请先在电脑端移除旧设备」。

### 5. 实时字幕与归档

- **whisper 推荐模型一键下载**：固定 URL + 固定 SHA-256 + 200 MB 上限，落到 `%LocalAppData%\OBS_Helper\sidecars\models\ggml-base.bin`，字幕页自动填入；校验失败不落盘、不覆盖已有模型。
- **录制结束自动归档（Q05）**：勾选「录制结束后自动归档」后，OBS 录制从进行中变为停止时自动调用 rclone 上传；默认关闭，失败写日志并保留手动归档入口。
- **历史录像索引**：切片页可扫描录像目录中的 mp4 / mkv / mov / flv / ts，按修改时间倒序展示；只做文件级索引，不读取视频内容。

### 6. 功能中心：运行环境准备与状态位

- 新增「运行环境准备」卡片：集中列出 FFmpeg / rclone / whisper / MediaMTX / 模型 5 个组件的状态与一键按钮，用户不必先找依赖中心。
- 模块卡新增「实验性 / 规划中 / 本地」状态位（稳定项不额外标注），共覆盖 18 项能力，并在说明中提示与完整实现的差距。
- 直播日历（C10）与观众看板（E06）改为本地落盘，重启后不再丢数据。

### 7. 安全加固

- `installed.json` 的卸载 / 回滚增加已知插件根校验，防止被篡改的清单把任意目录当成插件目录移走。
- 插件与依赖下载只接受 HTTPS + GitHub 官方资产域，302 重定向后的最终域名同样校验；GitHub 提供 `sha256:` 摘要时强制匹配。
- 依赖下载限制 512 MB，解压限制 2 GB / 20000 条目；sidecar 与增量包解压同样增加条目数 / 解压总量上限，保留 zip-slip 与符号链接拒绝。
- whisper 模型只允许 HTTPS + Hugging Face 官方域名（`huggingface.co` / `*.huggingface.co` / `hf.co` / `*.hf.co`），边写边算 SHA-256，校验失败删除临时文件。

## 修复的问题

### 1. 插件 / 依赖一键下载全部失败

- **以前**：GitHub 已把 Release 资产下载从 `objects.githubusercontent.com` 迁到 `release-assets.githubusercontent.com`；旧白名单只允许前者，302 之后的最终域名校验直接拒绝，所有插件下载在写盘前失败，几 MB 的依赖也会被误报成「文件过大」。
- **现在**：插件 / 依赖 / sidecar 三处白名单都放行 `release-assets.githubusercontent.com`，并保留 `github-releases.githubusercontent.com` 兼容旧重定向；按真实下载结果返回失败原因。
- **可诊断**：HTTP 非 2xx、最终域名被拒、体积超限、异常时都会记录 host、状态码、上限与异常类型，不再静默返回失败。
- **回归测试**：三处白名单补齐单元测试，覆盖新 CDN 域、旧 CDN 域、恶意域名与空值。

### 2. 下载类的连带修复

- 真实插件包里的 `bin/`、`data/` 目录条目不再被当成「无扩展名文件」拒绝；带目录结构的真实插件包可以正常安装。
- 依赖 / 插件下载失败时不再统一显示「下载失败或文件过大」，而是按真实原因（域名被拒 / 体积超限 / 摘要不匹配 / 网络异常）给出提示。

### 3. 功能中心宣传与实现不一致

- 功能中心为 18 项能力增加状态位：M04 标「规划中」，C07 / S09 / E03 / E04 等标「实验性」，C10 / E06 标「本地」；稳定项不额外标注。用户能直接看出哪些能力与完整实现有差距。
- 逐项「宣传 vs 实现」对照（18 行）与证据路径写入 [`docs/x1031_v350/12_X1031Y3_FEATURE_CENTER_READINESS.md`](docs/x1031_v350/12_X1031Y3_FEATURE_CENTER_READINESS.md)。**本版没有逐条改功能名**：`AI 回复建议`、`AI 导播`、`装修市场`、`团队协作`、`录制检索`、`构图检查` 等名称保持不变，靠状态位与说明提示边界；改名 / 真实现列入 Y4。

## 兼容性与升级

- 版本号：`3.5.2` → `3.5.3`，可覆盖升级，无需卸载旧版。
- 安装目录、程序集名、数据目录（`%LocalAppData%\OBS_Helper`）均未改变；设置、场景模板、提词稿、手机配对记录、壁纸库、已安装插件清单全部保留。
- **V 系列继续使用原应用图标**：本版同步 X1031Y2 / X1031Y3 的功能，但不采用 X 系列专属字标图标；X 构建仍由 `XSeriesIcon` 使用 `appicon_x.ico`，两条构建链互不影响。
- 系统要求不变：Windows 10 / 11；Win7 兼容构建仍可运行，但依赖一键配置、WebRTC 监看与手机 Wi-Fi 摄像头不建议在 Win7 使用。
- 增量包：`3.5.2` → `3.5.3` 版本连续，可按 CI 的基准资产生成增量包；若基准资产不可得则使用完整安装包。

## 已知边界

- **依赖下载仍受 GitHub / Hugging Face 网络影响**：本机实测 MediaMTX 依赖全包下载在 49% 时因网络过慢中止，但 302 → `release-assets.githubusercontent.com` → 写盘路径已验证。
- **未做真实手机硬件复测**：手机配对、推流检测、WebRTC 监看使用移动视口与本地服务验证，未逐台真机复测；手机浏览器在局域网 HTTP 下仍不能直接调用摄像头，需要 Larix / OBS Camera 推流。
- **宣传强于实现的边界仍在**：LLM 回复 / 搭档、真 AI 导播、在线主题市场、联机团队协作、Twitch / YouTube 自动观众统计、手机浏览器直接当摄像头仍未接入；可自行完成的配置项见根 README 的「自行接入指引」，需要应用层开发的项不提供公开步骤。
- **历史录像只做文件索引**：不读取视频内容，不做历史字幕 / 语音检索。
- **功能中心审查是代码级初审**：未在真机 / 真网络逐项复现，标「未验证」的项不能当成验收报告。
- **安装包与便携包仍未做 Authenticode 代码签名**：SmartScreen 仍可能提示「未知发布者」。

## 下载与校验

- 安装包：`OBS_Helper_Setup_3.5.3.exe`
- 便携包：`OBS_Helper_Portable_3.5.3.zip`
- Win7 兼容包：`OBS_Helper_Setup_3.5.3_win7.exe` / `OBS_Helper_Portable_3.5.3_win7.zip`
- 增量包：`OBS_Helper_Update_3.5.3.zip`（基准资产可得时）
- 资产 SHA-256 由 CI 在 Release 正文末尾自动追加，也可用 `SHA256SUMS.txt` 校验。
