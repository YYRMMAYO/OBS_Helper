# OBS 排障助手 V2.1.0 发布说明

> 发布主题：**增量更新 + 知识库分离更新 + 安装包自动清理**

## 新增功能

### 1. 增量更新（以后更新不用再整包下载）
- 构建脚本新增「增量包」生成：比对上一版本完整文件清单，只打包**变更的文件**。
  本次 2.0.0 → 2.1.0 的增量包仅约几 MB（对比整包约 230MB）。
- 更新弹窗新增 **「增量更新全部功能」** 按钮：下载增量包 → 逐文件 SHA-256 校验 →
  自动重启应用完成替换（安装版自动申请一次管理员授权，便携版直接应用）。
- 任一环节失败自动回退提示，不会把应用改坏；跳版本时自动提示改用完整安装包。

### 2. 安装包自动清理
- 应用启动后自动扫描临时目录 / 下载 / 桌面，删除本应用**旧的**安装包与增量包
  （Setup / Portable / Update / Manifest 每类保留最新一份）。
- 只识别 `OBS_Helper_*` 命名产物，绝不触碰其它文件；下载完成安装后也会顺手清理一次。

### 3. 知识库分离更新（问题库可以独立更新，不再等应用发版）
- 问题库改为存放到 `%LocalAppData%\OBS_Helper\data\problems.json`，程序内置版本作为兜底种子。
- 更新方式三选一：启动时静默自动更新（6 小时节流）/ 设置页「检查知识库更新」/ 更新弹窗「仅更新知识库」。
- 远程源双通道：GitHub raw（主，随仓库提交即时生效）+ GitHub Release 资产（兜底）。
- 知识库版本与程序版本完全解耦，单独更新知识库不需要重装应用。

### 4. 知识库扩充（v1.4 → v1.5，95 → 110 条）
2026-08 网络调研增补 15 条高频问题：
- 直播中随机音画不同步（音频缓冲 / 设备时间戳）
- 麦克风声音处理链（降噪 → 门限 → 压缩 → 限制）
- 串流密钥安全与泄露处置
- 已连接但平台端无画面 / 离线
- 不打扰观众的推流带宽测试
- 虚拟摄像头无法使用 / 黑屏排障
- 同一场景多个捕获源互相干扰
- 摄像头画面模糊 / 卡顿
- 配置损坏后备份与重置
- Windows 游戏模式 / GPU 满载导致掉帧
- 关键帧间隔（Keyint）设置与平台转码
- 动态码率应对网络波动
- 统计面板三指标解读（丢帧 / 渲染延迟 / 编码过载）
- 录像文件过大与磁盘空间管理
