## 3. 不可行（本版仍不做）

| 项目 | 原因 | V3.7 处理 |
|---|---|---|
| Authenticode 代码签名 | 需要开发者证书与私钥，仓库内没有 | 保留 `-SignPfxPath`；发布说明如实写「未签名」 |
| 真 LLM 回复 / 搭档 | 需要用户 API Key、计费、内容安全与提示词工程；离线不可用 | 保留本地模板/规则；不写成「已接入 LLM」 |
| 在线主题市场 | 需要服务端、作者体系、审核与分发 | 保留本地 JSON 主题包导入 |
| 联机团队协作 | 需要账号、服务端、权限与实时同步 | 保留本地角色/邀请演练 |
| 手机浏览器直接当摄像头 | `getUserMedia` 需要可信 HTTPS 安全上下文，局域网 HTTP 不可用 | 保留 Larix / OBS Camera 推流 + 二维码 |
| Twitch / YouTube 自动观众统计 | 需要 OAuth、平台 API 配额与审核 | 保留 B 站公开人气 + 手动回填 |
