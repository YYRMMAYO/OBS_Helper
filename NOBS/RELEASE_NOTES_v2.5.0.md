# V2.5.0 发布说明 —— 排障闭环增强版

发布日期：2026-08-23

V2.5.0 聚焦「从发现问题到解决问题」的闭环：把全球 OBS 社区最高频的三类故障
（编码过载、掉帧、双显卡黑屏）从"提示一句"升级为"按当前设置给出处理顺序"，
并把事故预防前移到开播 / 开录之前。

## 一、日志分析三大分诊升级

### 1. 掉帧三分类主因判定

OBS 的三类丢帧统计病因完全不同：渲染滞后 = GPU 压力，编码滞后 = 编码器瓶颈，
网络丢帧 = 上行带宽。分析器现在会对比三者占比，直接生成
「掉帧主因判定：XX占比最高」的结论条目并关联对应知识库方案，
避免用户按错误方向折腾设置。

### 2. 编码过载分诊（按当前设置定制）

命中编码过载时，不再只给一句"降低设置"，而是结合日志头部解析出的
编码器 / 显卡厂商 / 帧率 / 输出分辨率，生成编号的处理顺序：

- x264 + N 卡 → 第 1 步就是改用 NVIDIA NVENC H.264；
- NVENC 过载 → P7 预设降到 P5/P4 + 游戏帧率锁低于刷新率；
- 帧率 ≥ 50 → 提示降帧到 30 直接减半工作量；
- 输出分辨率 ≥ 1080p → 提示降档到 720p 最立竿见影。

### 3. 双显卡错位检测

从日志枚举全部显卡适配器并与 OBS 实际选用的适配器比对：

- 用核显渲染而独显在位 → 警告「双显卡错位」，直达知识库「笔记本双显卡」条目；
- 已用独显 → 给一条确认级提示，帮用户放心排除这个变量。

## 二、插件加载失败 × OBS 版本联动

OBS 32.2 首发重写 Windows 插件 DLL 加载逻辑后，大量带依赖的插件首启加载失败
（32.2.1 / 32.2.2 已修复）。当日志同时出现插件加载失败且 OBS 版本低于 32.2.2 时，
单独输出「先升级补丁版」的提示条目——这是性价比最高的解法，
避免用户先去折腾重装插件。「插件导致崩溃」知识库条目同步补充该首推步骤。

## 三、录前自检（只读）

诊断页新增「录前自检」面板，一键只读核对当前 Profile 配置：

| 检查项 | 命中问题时的关联条目 |
| --- | --- |
| 录制格式是否防崩溃的 MKV | rc-mkv |
| 录制路径是否有效 | rc-nofile |
| 录制盘剩余空间是否充足 | rc-disk-space |
| 是否仍在使用 x264 软件编码 | enc-overload |
| 音频采样率是否统一 48kHz | av-sample |
| 麦克风 / 辅助音源是否启用 | au-mic |

只读不改任何文件；任何一项未通过都可直接跳转知识库分步方案。
多数「录完才发现没声 / 文件损坏」的事故可以在开播前拦截。

## 四、插件广场 StreamFX 迁移矩阵

StreamFX 已实质停更且在 OBS 30+ 兼容性持续恶化。插件广场新增迁移面板，
五大常用功能一键直达维护活跃的替代插件：

| StreamFX 功能 | 替代插件 |
| --- | --- |
| 背景模糊 / 景深虚化 | Composite Blur |
| 形状 / 渐变遮罩 | Advanced Masks |
| 3D 变换 / 透视旋转 | 3D Effect |
| 描边 / 辉光 / 投影 | Stroke Glow Shadow |
| CRT / VHS 复古特效 | Retro Effects |
