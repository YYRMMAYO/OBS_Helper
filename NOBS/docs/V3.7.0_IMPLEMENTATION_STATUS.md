## 4. 不可行项（本版仍不做）

- Authenticode 代码签名（无证书）。
- 真 LLM 回复 / 搭档（需 API Key、计费与内容安全）。
- 在线主题市场（需服务端、作者体系与审核）。
- 联机团队协作（需账号、服务端与实时同步）。
- 手机浏览器直接当摄像头（`getUserMedia` 需要可信 HTTPS）。
- Twitch / YouTube 自动观众统计（需 OAuth 与平台配额）。

## 4. 已知边界

- 安全模式按「未正常退出次数」判断，不分析具体崩溃原因。
- 插件查询仍受 GitHub 匿名限额；冷却角标只提示，不阻塞手动下载。
- 计时器叠加层只绑回环；手机远程需先配对。
- 未做 Authenticode 签名，SmartScreen 可能提示未知发布者。
- 无障碍为代码级适配 + 静态检查，未经 NVDA / Narrator 实测。
