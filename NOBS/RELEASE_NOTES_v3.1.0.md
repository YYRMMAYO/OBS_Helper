# OBS帮助助手 V3.1.0 发布说明

> **版本**：V3.1.0（minor，功能增强版）
> **基线**：V3.0.0
> **构建**：`net10.0-windows` 主构建 + `net6.0-windows` Win7 兼容构建
> **日期**：2026-10-18

---

## 一句话

壁纸从「选一张图」升级为**可管理的壁纸库 + 可调显示 + 轮播**；一键录制真正只剩**一次点击**
（OBS 没开就自动开、没连就自动连、连上就自动录）；新增**提词器**、倒计时、录像命名模板、
静音提醒、UI 设计令牌与一个可关闭的小彩蛋。

---

## 新功能

### 1. 个性化壁纸（P0）

- **壁纸库**：多图导入、复制到 `%LocalAppData%\OBS_Helper\wallpapers\`、按 SHA-256 去重、
  缩略图选择、删除、重启后保持。
- **导入**：文件选择器（可多选）+ 拖拽到设置页；支持 JPG / JPEG / PNG / BMP / TIF / TIFF，
  单张 ≤ 50 MB；不支持 WebP / AVIF / HEIC 时明确提示转换格式。
- **显示方式**：填充 / 适应 / 居中 / 平铺（平铺为 P1，已实现）。
- **可读性**：压暗 0–80%（默认浅色 15% / 深色 40%），低于 10% 给提示但不强制阻止；
  高对比模式强制关闭壁纸。
- **轮播**：30 秒 / 1 分钟 / 5 分钟 / 15 分钟 / 30 分钟 / 1 小时；随机顺序一轮内不重复；
  窗口最小化 / 非激活时暂停，恢复后从当前张继续。
- **过渡**：300 ms 淡入淡出；「减少动画」开启时直接切换。
- **旧设置迁移**：现有 `bgImage` 绝对路径首次启动自动导入壁纸库；文件不存在则回退默认底并提示一次。
- **容错**：文件丢失 / 损坏 / 超大 / 格式不支持 / 磁盘写入失败都有可见提示，不崩溃、不静默。

### 2. 一键启动 OBS + 默认 WebSocket（P0）

- **OBS 未启动**：首次给一次说明（继续并记住 / 每次都问 / 我自己开），之后一键直达；
  不再每次点击都弹确认。
- **OBS 已启动但未连接**：自动连接（`EnsureConnectedAsync`：单飞、75 秒上限、每秒重试、
  可取消、OBS 退出立即返回），不再要求用户先去控制台点「连接」。
- **连接成功后**：自动落地录制参数并 `StartRecord`；文件通道已落地时跳过二次写入。
- **v4 旧协议**：保持 V3.0.0 行为 —— 跳过 `SetProfileParameter`，直接开录。
- **失败分类**：找不到 OBS / 启动失败 / 端口未开 / 握手失败 / 需要密码 / 密码错误 / 超时 /
  取消 / OBS 退出 / 开始录制失败，每类都有至少一个可执行出口（重试 / 去设置 / 打开 OBS / 输入密码）。
- **进度**：分阶段显示「正在连接 / 已等待 N 秒 / 正在应用 / 正在开录」，可随时取消。
- **倒计时**：可选 0 / 3 / 5 / 10 秒，倒计时中可取消，默认无声音。

### 3. 提词器（P0）

- 独立顶层窗口：置顶、无边框、可拖动、可缩放、记忆位置与尺寸。
- 滚动：自动滚动 / 空格暂停 / 滚轮 / 方向键微调 / Home 回到开头；速度 10–200 px/s。
- 排版：字号、行高、字色、背景不透明度、左右边距、阅读参考线。
- 镜像：水平 / 垂直（供提词器玻璃 / 半反半透镜）。
- 点击穿透：开启后鼠标落到下层应用，仍可用全局热键 `Ctrl+Alt+L` 关闭。
- 多屏：工具栏循环切换显示器；位置 / 尺寸 / 字号 / 速度 / 透明度 / 镜像 / 穿透状态自动保存。
- 内容：纯文本编辑 / 粘贴 / 导入 `.txt` / `.md` / 自动保存草稿；不联网、不上传。
- 热键：`Ctrl+Alt+T` 呼出 / 隐藏，`Ctrl+Alt+P` 播放 / 暂停，`Ctrl+Alt+L` 点击穿透。
- 入口：顶栏「提词器」按钮、托盘菜单。
- **场景联动**：脚本里用 `## 场景名` / `# 场景名` / `[场景名]` 分段，切场景时只滚动提词器，
  **不自动切 OBS 场景**。
- **捕获兼容向导**：窗口采集 / 游戏采集天然不包含提词器；显示器采集在 Windows 10 2004+ 尝试
  `SetWindowDisplayAffinity(WDA_EXCLUDEFROMCAPTURE)`；不支持时明确给出窗口采集 / 第二屏建议。

### 4. 补充功能与视觉（P1）

- **录像命名模板**：`{date}` `{time}` `{datetime}` `{scene}` `{profile}` `{resolution}` `{fps}` `{ext}`；
  非法字符净化、长度上限、同名自动加序号；改名失败保留原文件。
- **录制中静音提醒**：音频输入静音 ≥ 8 秒或音量 < -55 dB ≥ 10 秒时托盘提醒；
  **只提醒，不自动取消静音、不改音量**；同一输入一次会话只提醒一次。
- **UI 视觉刷新 1.0**：新增间距 / 圆角 / 动效设计令牌（`Spacing*` / `CornerRadiusXl` /
  `MotionFast` / `MotionSlow`），新页面优先引用；19 页全量重设计留到 3.2。
- **彩蛋**：主窗口输入 KONAMI 码 `↑↑↓↓←→←→BA` 解锁隐藏配色「午夜青」；
  纯本地、无声音、可关闭；高对比 / 减少动画下不产生动画。

## 行为变更（升级必读）

1. **一键录制不再每次确认**：V2.9.4 承诺的「拉起 OBS 前必确认」改为「首次一次说明 + 记住选择」；
   设置页可改回「每次都问」或「我自己开 OBS」。这是本版唯一有意的行为变更。
2. **`AutoConnect` 默认值改为 true**：只影响新安装 / 未写过该键的配置；旧配置明确写了 `false`
   的用户保持 `false`。启动自动连接只在 OBS 已在运行时尝试。
3. **壁纸存储位置变化**：`bgImage` 绝对路径会在首次启动时导入 `wallpapers\` 并使用相对库文件名；
   原 `bgImage` 字段保留作为兼容字段，原文件不会被删除或修改。
4. **数据目录、`AppId`、exe 名不变**：升级覆盖安装即可，`prefs.json` / `secrets.dat` /
   录制档案继续沿用。

## 未交付 / 已知边界

### 本版未交付（按计划 §12.6 的推荐方案）

- **开播检查清单**：已有录前自检（`PreflightCheckService`）覆盖麦克风 / 场景 / 磁盘 / GPU 等项，
  本版没有新增独立的「开播 10 秒倒计时清单」UI；留到 3.1.x。
- **AI 自动直播 MVP**：用户自带 API + 规则 + OBS 白名单动作的完整安全设计需要约 15 人日，
  按计划推荐放到 3.2；本版不内置任何 API、不放开本机/内网端点、不做自动推流。
- **补充有趣功能 6~12**（自动归档 / 录制日历 / 成就 / 报告导出 / 封面标题 / 彩排 / AI 复盘）：
  按计划放到 3.1.x。
- **19 页全量视觉重设计**：本版只做令牌 + 新页面；全量留到 3.2。

### 已知边界

- **提词器捕获排除不是 100%**：窗口采集 / 游戏采集天然不包含提词器；显示器采集在
  Windows 10 2004+ 才可能排除，部分采集后端会留下黑块；Win7 不支持，建议窗口采集或第二屏。
- **一键录制不能替用户完成 OBS 自己的 UI**：首次启动向导、崩溃恢复提示、显卡驱动初始化
  仍需用户在 OBS 窗口里完成；obs-websocket 服务被关闭 / 端口被改 / 密码未知时，应用只能给出
  分类错误与出口，不能「隔空」修好。
- **壁纸大图**：显示解码上限 3840 px、缓存最多 3 张；导入 4K 图时 UI 不冻结，但超大图
  （接近 50 MB / 16384 px）仍会占用较多内存。
- **录像命名模板**：优先在停止后重命名（不写 OBS 的 `FilenameFormatting`），
  因此 OBS 界面里的文件名与实际文件名可能短暂不同；改名失败保留原文件。
- **真实 OBS 矩阵未在本机构建环境中验证**：本版验证以单测、双构建、Headless 自检、
  静态检查为主；OBS 28+ / 31.x / 32.x、OBS 27 + obs-websocket 4.9、便携版、密码错误、
  首次向导等真机场景需按计划 §4.9 / §12.1.4 的矩阵人工复核。
- **安装包未签名**：本机无 Authenticode 证书，Windows SmartScreen 可能提示未知发布者。
- **Win7 兼容构建**：.NET 6 已停止安全更新；它是「必须跑 Win7」时的退路，新机器请用主构建。

## 升级方式

- 安装版：直接覆盖安装（`AppId` 未变，Inno 识别为升级）；
- 便携版：解压覆盖，保留 `data\` 与 `%LocalAppData%\OBS_Helper\`；
- 增量包：`OBS_Helper_Update_3.1.0.zip`（由构建脚本生成，逐文件 SHA-256 校验）。
