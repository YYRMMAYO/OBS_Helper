# OBS 排障助手 V2.3.0 发布说明

> 发布主题：**插件生态打磨** —— 界面风格统一（全面去 emoji）· 本机体检全盘定位 ·
> 插件目录扩充到 38 个 · 知识库 v1.1 热更新直达老版本

## 新增功能

### 1. 本机插件体检：全盘定位 OBS 安装目录（不再只搜 C 盘）
- **多信号安装目录定位**重写：手动指定（便携布局反推）→ 运行中进程 →
  注册表卸载项（HKLM 双视图 + WOW6432Node + HKCU 用户级，`InstallLocation`
  缺失时用 `DisplayIcon` 反推）→ **全盘固定驱动器常见布局**
  （`{盘}:\Program Files\obs-studio`、`{盘}:\Program Files (x86)\obs-studio`、`{盘}:\obs-studio`）。
  OBS 装在 D/E 盘等非系统盘的用户，本机体检从此不再漏扫。
- **Steam 版全库扫描**：解析各 Steam 根的 `steamapps/libraryfolders.vdf`
  （注册表 SteamPath 定位任意盘的 Steam 本体），覆盖安装在非默认库的 OBS
  （如 `D:\SteamLibrary\steamapps\common\OBSStudio`）。
- 「设置 → OBS 配置管理」的手动指定目录现在对体检生效：符合便携布局
  （`<安装目录>\config\obs-studio`）时自动反推安装目录参与扫描。

### 2. 插件知识库扩充：28 → 38 个条目（v1.0 → v1.1）
新增 10 个维护活跃、Releases 可直达下载的精选插件：
- **自动化**：Source Switcher（来源自动轮播）、Media Controls（媒体控制面板）、
  URL Source（API/URL 数据上屏）；
- **视觉特效**：Freeze Filter（画面冻结保险丝）、Retro Effects（CRT/VHS 复古特效）；
- **AI 智能**：Auto Subtitle（讯飞实时中文字幕，国内直连）;
- **音频**：Waveform（高精度实时波形可视化）；
- **多平台 / 竖屏**：Source Dock（来源投独立窗口监看）、Spout2 输入输出（与
  TouchDesigner / Resolume 等 GPU 纹理互通）；
- **录制 / 后期**：Replay Source（回放缓冲即时重播）。

收录前逐一验证仓库可达性与 Releases 资产；「直达下载」按钮全部有效。
知识库走分离热更新通道：**老版本（V2.2+）用户无需升级应用即可收到新目录。**

### 3. 界面风格统一：插件板块全面去 emoji
- 插件广场页与全部联动入口（日志分析 / 智能诊断 / 场景模板 / 搭建向导 /
  模板推荐插件行）统一为纯文字 + 品牌色徽标风格，与全应用设计语言一致；
- 分类筛选 chips 与分区标题不再渲染知识库自带的 icon 字段——即使外部热更新的
  目录数据仍带旧图标，界面也不会再出现 emoji（字段保留以兼容旧版数据解析）；
- 涉及清理：搜索框 / 体检面板图标、「重新扫描」「下载」「关注」按钮前缀符号、
  分类 chips 与分区标题的 emoji 图标、跨页跳转链接的 🧩 前缀、向导窗口标题图标等。

## 改进与修复
- 本机体检候选目录合并逻辑抽出为纯函数（`PluginScanLocations`）并补齐单元测试，
  扫描顺序 = 优先级语义：实际安装目录 → 安装根 → Steam 库 → 用户目录，大小写不敏感去重。
- 体检失败提示文案更新为「已尝试全盘常见位置与 Steam 库」，并保留手动指定目录指引。
- 构建产物自检脚本误报修复：`selftest_result.txt` 不再污染增量包比对基准
  （清单生成阶段本已排除，发布校验时同步清理发布目录残留）。

## 质量保障
- 单元测试 147 个全部通过（新增候选目录构建 / Steam libraryfolders.vdf 解析 /
  盘符布局映射共 7 个用例）；
- 应用自检（17 条路由含参数化导航）17 PASS / 0 FAIL；
- 38 个插件仓库逐一通过 GitHub API 可达性校验，无重复 id、无未知分类；
- 增量包发布校验 PASS：2.2.0 → 2.3.0 模拟升级后全文件 SHA-256 比对一致（269 文件）。

## 升级说明
- 2.1.x / 2.2.x 用户可在应用内直接增量更新（本次增量包约 1.3MB）；也可从
  Release 页下载完整安装包 / 便携包。
- 插件知识库 v1.1 支持独立更新：老版本用户启动后会静默获取新目录，
  无需升级应用本体。
