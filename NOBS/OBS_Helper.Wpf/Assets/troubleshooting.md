# OBS 直播排障与使用指引

> 适用版本：V3.5.1 / X1031（两者使用方法一致，区别只在更新通道）。
> 遇到问题可先按「5 分钟上手」走一遍；仍无法解决时，用应用内的「🩺 诊断」做智能分析，
> 或在「🎛️ 控制台」连接 OBS 实时查看状态。

## 零、5 分钟上手

第一次打开软件，按这个顺序做，能少走很多弯路：

1. **连接 OBS**：打开 OBS →「工具 → WebSocket 服务器设置」→ 勾选「启用 WebSocket 服务器」，
   记下端口与密码；回到本应用「设置 → OBS 连接」填入并测试。连接成功后左下角会变绿。
2. **用手机遥控**：打开「手机联动 → 遥控」→ 点「生成配对码」→ 手机扫码。
   手机与电脑必须连同一个 Wi-Fi；打不开时先检查 Windows 防火墙是否允许专用网络。
3. **套一个场景模板**：打开「模板 / 虚拟直播 → 直播间」→ 选一个模板 →「应用到 OBS」。
   应用后会出现在 OBS 的场景列表里，再按提示替换摄像头、麦克风与虚拟形象。
4. **试录 10 秒**：回到首页点「简单录像」→ 开始 → 10 秒后停止 → 确认文件能播放。
   这一步能提前发现编码器、磁盘与权限问题。
5. **需要提词**：点顶栏「提词器」→ 粘贴稿件 → 开始滚动；
   手机上「提词」页可以直接改稿，保存后电脑端立即更新。

> 建议先把「设置 → 外观 → 背景」换成一张自己的图片：V3.5.0 起背景会覆盖整个窗口。

## 一、先做一次快速自检

1. 确认 OBS 为**官方最新稳定版**（非测试版、非修改版）——只从
   [官网下载页](https://obsproject.com/zh-cn/download) 或
   [GitHub 发布页](https://github.com/obsproject/obs-studio/releases/latest) 获取；
   OBS 完全免费，没有付费版，搜索引擎广告位与「软件下载站」里的仿冒包常见捆绑安装器与木马。
   安装前可核对数字签名是否为 `OBS Project Corporation`。
2. 以**管理员身份**运行 OBS（部分采集与权限场景必须）。
3. 关闭占用资源的后台程序（浏览器多标签、游戏、其他录屏软件）。
4. 在「设置 → 输出」中把**编码器**先切回 `x264` / `软件(CPU)`，排除显卡驱动问题。
5. 打开「🎛️ 控制台」确认 OBS 是否真正在推流 / 录制。

## 二、黑屏 / 无信号

- **显示器捕获黑屏**：右键来源 →「属性」→ 勾选「使用反作弊兼容性」，或改用「窗口捕获 / 游戏捕获」。
- **游戏捕获黑屏**：以管理员运行 OBS；游戏改为「无边框窗口化」；关闭游戏内覆盖（Discord、Steam、Overwolf）。
- **采集卡黑屏**：确认分辨率 / 帧率与 OBS 来源设置一致，先试 `1920x1080, 60fps`。
- **浏览器源黑屏**：关掉「本地文件」改用网址，或在来源属性取消「硬件加速」。
- **虚拟形象不显示**：确认 Live2D / VTube Studio 已在推流；没有 NDI 时改用「窗口采集」抓取
  VTube Studio 窗口，或在「虚拟直播 → 形象」里点「Live2D 一键配置」。

> 多数黑屏与「权限 / 抗作弊 / 硬件加速」有关，优先排查这三项。

## 三、编码过载 / 卡顿掉帧

症状：状态栏出现**掉帧（渲染 / 编码）**，画面一顿一顿。

- 降低**输出分辨率**与**帧率**：如 `1280x720, 30fps`。
- 降低**比特率**：720p 建议 `2500–4000 kbps`，1080p 建议 `4500–6000 kbps`。
- 编码器选 **GPU 硬编**（NVENC / AMD / Intel QSV）减轻 CPU 负担。
- 在「设置 → 高级」中关闭「动态比特率」「重投」等附加项。
- 用任务管理器确认是否 CPU / GPU 跑满；跑满就继续降画质。

```text
中端机建议起步配置：
输出：1280x720, 30fps
视频：编码器 NVENC, 比特率 4000, 关键帧间隔 2s
高级：色彩格式 NV12, 色彩空间 709
```

## 四、音画不同步 / 爆音

- 采样率统一为 **48kHz**（OBS 与系统声音设置保持一致）。
- 桌面音频与麦克风分别检查；爆音多为**采样率不匹配**或**缓冲过小**。
- 手机摄像头有延迟时，在「手机联动 → 摄像头 → 音频同步偏移」里填毫秒数（-500 ~ 500）。
- 推流延迟高造成的「不同步」通常是**网络**问题，见下一节。

## 五、推流失败 / 连接超时

```text
常见报错：
- Failed to connect to server  → 地址 / 密钥错误，或服务端不可达
- Timed out                    → 网络不稳，或防火墙拦截 1935 / RTMPS
- Authentication failed        → 流密钥错误
```

- 核对**服务器地址**与**流密钥**（从直播平台「推流设置」复制，勿手输）。
- **平台策略**：部分平台（如抖音）已不再提供 OBS / 第三方 RTMP 推流入口，官方只支持其自带直播伴侣。
  此时不是网络问题，改用官方工具开播即可（想要 OBS 画面，用虚拟摄像头 / NDI 转发给直播伴侣）。
- 优先使用 **RTMPS**（平台默认），避免 1935 端口被封。
- 关闭系统防火墙 / 杀毒对 OBS 的限制，或更换网络（手机热点排查）。
- 用「🎛️ 控制台」查看 `stream` 状态与连接耗时。

## 六、插件广场与 GitHub 加速（V3.5.0 新增）

插件目录、搜索与下载都依赖 GitHub，国内网络可能一直转圈或下载失败。

1. 打开「插件广场」，顶部会看到「访问 GitHub 不稳定？先开启加速器」。
2. 点「下载 Watt Toolkit（Steam++）」，安装并打开，勾选 **GitHub 加速**。
3. 回到应用点「我已开启，重新检测」；显示「GitHub 连接正常」后再搜索 / 安装。
4. 不想用第三方加速器时，也可以使用自己的代理；本应用不捆绑、不自动安装任何加速器。

**已安装插件不显示？** V3.5.0 起「已安装」列表同时显示：

- **本应用管理**：可回滚 / 卸载，记录来源与 SHA-256；
- **本机检测**：你自己放进 OBS 的插件，只读展示，本应用不会改动。

如果两边都为空，先到「设置 → OBS 路径」确认安装目录是否正确。

## 七、手机联动与手机摄像头（V3.5.0 重做）

### 手机遥控

- 电脑与手机连同一个 Wi-Fi；应用只绑定私网地址，默认关闭、随时可撤销。
- 「生成配对码」会自动启动服务；二维码 120 秒内有效，过期重新生成。
- 手机打不开页面：检查 Windows 防火墙是否允许 `OBS_Helper.exe` 访问**专用网络**；
  公司 / 酒店 Wi-Fi 常开启客户端隔离，改用手机热点。
- 撤销设备：在「设备」页点「撤销」，手机端会立即掉线。

### 手机当摄像头

手机浏览器在局域网 HTTP 下**不能直接调用摄像头**（浏览器安全限制），
必须用支持 SRT / RTMP 的推流 App（如 Larix Broadcaster）。正确顺序：

1. 点「手机联动 → 摄像头」→「下载并安装」媒体服务（mediamtx，MIT，约 28 MB）。
2. 点「启动摄像头链路」，记下屏幕上的 SRT / RTMP 地址。
3. 手机安装推流 App，把地址完整粘进去（包含随机 key），开始推流。
4. OBS 已连接时，应用会自动创建「手机机位」场景与「手机摄像头 cam1」来源；
   未连接 OBS 也可以先启动媒体服务，连上后会自动补建来源。
5. 没画面时：确认手机已开始推流、地址没漏字符、防火墙放行 mediamtx、端口未被占用。

> Win7 不支持 Wi-Fi 摄像头，请改用 USB 采集卡或手机厂商的虚拟摄像头。

## 八、虚拟主播模板与 Live2D（V3.5.0 扩充）

- 「虚拟直播 → 直播间」现有杂谈、游戏、歌回、学习陪伴、双人联动、手部机位、竖屏、
  纪念回与开播/暂离/下播三件套。
- 应用模板后会创建场景与来源；虚拟形象默认按 **NDI → Spout → 摄像头 → 窗口采集** 回退。
- 没有 NDI 时，最简单的做法是用「窗口采集」抓 VTube Studio 窗口，再在 OBS 里裁切。
- 聊天框、装饰边框是本地 `127.0.0.1` 页面，不联网；要换成自己的聊天 widget，
  在来源属性里把 URL 换掉即可。
- 模板落地后如果位置不合适，直接在 OBS 里拖动；下次应用同一模板会重新按模板坐标摆放。

## 九、提词器（含手机改稿，V3.5.0 新增）

- 顶栏「提词器」打开窗口；支持镜像、字号、速度、回到开头、点击穿透。
- 手机「提词」页新增编辑框：改完点「保存到电脑」，电脑端提词器立即更新；
  点「从电脑刷新」可放弃手机上的未保存修改。
- 旧稿会自动备份到 `%LocalAppData%\OBS_Helper\teleprompter\backup-*.txt`，保留最近 5 份。
- 提词器滚动不影响 OBS；场景切换时可自动滚到 `## 场景名` 对应段落。

## 十、用「日志分析」定位根因

1. 打开「📜 日志」。
2. 让 OBS 复现问题后，在 OBS「帮助 → 日志文件 → 上一次启动的日志」导出，拖入本应用。
3. 应用会自动脱敏并分析，给出**量化滞后比**与异常点，可直接送给「🩺 诊断」。

## 十一、用「控制台」实时查看

「🎛️ 控制台」通过 obs-websocket 连接 OBS，可查看：

- 当前**场景**与来源
- **音频**电平、静音、音量
- **录制 / 推流 / 虚拟摄像头**状态
- 实时**统计**（帧率、码率、丢帧、CPU）

> 写操作（切场景、开关推流等）会要求二次确认，避免误触。

## 十二、安全与隐私提示

- 本应用**离线优先**，默认不连外网；仅在「设置」中手动开启「免费 AI」或「云端大模型」才会对外请求。
- 云端密钥由**桌面壳加密保存**（Windows DPAPI），不会明文落盘。
- 日志在分析前会**自动脱敏**（密钥、路径、Token、IP 等），可放心使用。
- 手机联动只绑定私网、默认关闭、随机端口、一次性配对码；手机永远拿不到 OBS 密码、推流码与 API Key。

## 十三、仍无法解决？

- 打开「🩺 诊断」输入现象，获取分步建议。
- 查阅官方文档：
  - OBS 中文知识库：https://obsproject.com/zh-cn/kb
  - 日志分析器：https://obsproject.com/analyzer
- 到 OBS 官方论坛或社区按「现象 + 日志」提问，附上日志分析结论会更快得到帮助。
