# V3.7.3 发布说明

## 一句话摘要

V3.7.3 是 **OBS Studio 33 适配版**：对齐最新稳定版 **OBS Studio 33.0.1**，识别 OBS 33 新的「一插件一目录」布局（`<插件名>\<插件名>.dll + data`）、便携模式插件根，并修正 OBS 33 安装包不再包含 `obs-plugins` 后安装目录探测不到、33 风格插件包被误判为「没有 64 位 DLL」的问题。旧 `bin\64bit` 与 `obs-plugins\64bit` 布局继续兼容。

## 新增与改进

### 1. OBS 33 插件布局识别

- **新布局**：OBS 33 起第三方插件放在 `<插件根>\<插件名>\<插件名>.dll`，语言文件与规则放在同级的 `data\` 下。
- **本机体检**：插件页的只读扫描现在同时展开 OBS 33 的 `<插件根>\<插件名>` 与 OBS 32 的 `<插件根>\<插件名>\bin\64bit`，两种安装方式都能被列出。
- **管理动作**：卸载 / 迁移 / 接管把 OBS 33 的插件目录当作完整单元处理，`data\` 会随插件一起移动或备份，不会只搬走一个 DLL。
- **旧布局**：OBS 33 仍会加载 `bin\64bit` 与 `obs-plugins\64bit`，本版继续识别；OBS 34 起官方不再加载旧布局，升级前建议按插件页提示迁移。

### 2. OBS 33 便携模式插件根

- 新增扫描 `<OBS 安装目录>\plugins`（OBS 33 便携模式的标准插件根），与 `%AppData%\obs-studio\plugins`、`%ProgramData%\obs-studio\plugins` 使用同一套新布局。
- 本机体检的来源标签新增「便携模式插件目录」；便携模式插件可先「迁移到用户级」，再在应用内接管 / 更新 / 卸载。

### 3. OBS 33 安装目录探测

- OBS 33 的安装包**不再包含 `obs-plugins` 目录**（核心模块改放 `core\`）。原先只靠 `obs-plugins` 判断安装根，会让 OBS 33 用户探测不到安装目录。
- 现在按 `bin\64bit\obs64.exe` / `core\` / `obs-plugins\` / `plugins\` 多种布局识别安装根；从运行中进程与注册表 `DisplayIcon` 反推时都会先归一到真正的安装根，而不是停在 `bin\64bit`。

### 4. 插件包安装兼容 33 布局

- OBS 33 风格插件包的 DLL 直接位于包内插件目录顶层，路径里没有 `64bit` / `x64`。本版不再因此拒绝安装。
- 仍会排除明确标成 32 位的目录（`32bit` / `32` / `x86` / `win32`），并继续逐个 DLL 复核 PE 头是否为 x64 或托管程序集。

### 5. 插件安装提示与文档

- 插件页「安装小贴士」更新为 OBS 33 的插件根与布局，并说明旧布局在 OBS 33 中标记为 Legacy、OBS 34 起不再加载。
- README 的 OBS 适配基线从 32.2.2 更新为 33.0.1，插件广场 / 本机体检说明同步新布局与便携模式。

## 修复的问题

### 1. OBS 33 新装插件在本机体检里「消失」

- **以前**：只展开 `<插件根>\<插件名>\bin\64bit`，OBS 33 把 DLL 放在 `<插件根>\<插件名>` 顶层，扫描结果为 0。
- **现在**：两种布局一起展开，OBS 33 插件正常出现在本机体检与管理列表中。

### 2. OBS 33 安装目录探测不到

- **以前**：安装包已无 `obs-plugins`，从 `DisplayIcon` 上溯时找不到安装根；从进程启动时还会停在 `bin\64bit`。
- **现在**：按 `bin\64bit\obs64.exe` / `core` / `plugins` / `obs-plugins` 识别，并统一返回安装根。

### 3. OBS 33 风格插件包被拒绝安装

- **以前**：`ValidateDllLayout` 要求路径里出现 `64bit` / `x64`，33 布局的 `plugin.dll` 直接报「没有 64 位 DLL」。
- **现在**：接受顶层 DLL，架构交给 PE 头复核；显式 32 位目录仍拒绝。

### 4. 便携模式插件漏扫

- **以前**：只扫用户级与全局级插件根。
- **现在**：补上 `<OBS 目录>\plugins`，并在来源标签中区分「便携模式插件目录」。

## 兼容性与升级

- 设置文件、OBS WebSocket 协议、录制 / 推流写操作语义均不变，可直接增量升级。
- 继续支持 OBS 28–32 的旧插件布局；OBS 33 的两种布局同时识别。
- 旧的 `bin\64bit` 布局在 OBS 33 中仍由官方加载（插件管理器标记 Legacy），OBS 34 起才移除；本版不强制搬迁。
- 主构建（Windows 10/11，.NET 10）与 Win7 兼容构建（.NET 6）共用同一份源码。

## 已知边界

1. 本版按 **OBS Studio 33.0.1 官方安装包的真实文件布局**实现与验证，未在装有 OBS 33 的机器上逐项点击「安装 / 卸载 / 迁移」全流程。
2. 日志分析规则仍以 OBS 32.2.2 的真实日志为核对基线；OBS 33.0.1 的日志格式未逐条重新采样，规则命中结果以实际日志为准。
3. 便携模式插件需要先迁移到用户级，才能在应用内接管；应用不会直接改写 `<OBS 目录>\plugins` 下的插件清单。
4. 发布产物未做代码签名，SmartScreen 可能提示未知发布者。
